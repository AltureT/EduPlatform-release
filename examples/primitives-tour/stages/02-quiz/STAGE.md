### 段 2 · 质数小测

> 核心教学事件：每个学生独立做完三道小题（单选、判断、填空）并提交；教师揭晓后，全班同时看到自己的得分、每题对错与解析，大屏上看到每题的正确率。

**A 展示**
- 大屏投什么：揭晓前每题一行"已答 n / 已提交 m"横条（第 1 / 2 / 3 题）+ 提交 N/M（在线），不显示正确率、平均分与作答分布（免得大屏提前泄露答案）；揭晓后每题一行正确率横条 + 平均分，点某题展开该题的作答分布，正确项高亮并显示正确答案
- 学生屏幕看什么：一题一页，顶部"第 i / 3 题"，单选 / 判断是大按钮、填空是输入框，底部"上一题 / 下一题 / 提交"；提交后显示"已提交，等待揭晓"与自己的作答；揭晓后显示得分、每题对错、正确答案与解析
- 教师按什么按钮、在什么时点按：提交得差不多时在演示页点"揭晓"；讲完按"进入下一段"（见 E）
- 教师是否需要看某个学生的实时画面 / 挑人上来讲：不需要；统计视图点行可看该生逐题作答

**B 学生做什么**
- 动作是什么：逐题作答，最后一题点"提交"
- 有几步，步与步之间是否有先后：三题，可前后翻看、改答案，提交前都在本机
- 提交后能不能改：不能（只提交一次）；揭晓后未提交的也不能再交
- 做不对时平台给什么反馈：揭晓前不给对错；揭晓后逐题显示对错、正确答案与解析

**C 采集**
- 记什么字段：每人 `answers`（题号 → 作答）、`submittedAt`、`elapsedMs`（进入本段到提交的用时）；揭晓时每人补写 `score`、`total`、`results`（逐题对错）；班级 `answerKey`、`explanations`、`revealedAt`（揭晓时写）
- 记到人、记到组、还是只记到班：到人 + 到班（揭晓时的答案与解析）
- 课后要不要回看 / 进个人报告：可回看（揭晓后回看仍显示结果；揭晓时仍未提交的显示"已揭晓，未提交"）；进个人报告：我的得分（与全班中位数对比）、错题号

**D 统计**
- 教师统计视图看哪几列：姓名、已提交、得分、错题号、用时；顶部摘要：提交 N/M、平均分、最难的题；点行看逐题作答与对错
- 什么情况要提醒教师走过去：进入本段 3 分钟仍未提交
- 要不要排行 / 推荐分享：不排行；推荐分享列得分最高、提交最早的 5 人

**E 推进条件**
- 教师按"下一段"时要满足：在线学生提交率 ≥ 70%（离线不计入分母）
- 不满足时：软提示（一键继续 / 可强制推）

**匹配原语**：quiz

**页面样式**：focus

#### 实现要点

全部由原语提供，本目录只有配置（`stage.config.js`，`primitive: 'quiz'`，`showResultTo: 'reveal'`）。答案与解析写在每题的 `answer` / `explain` 上，原语加载时把它们移进保密选项，学生端在揭晓前收不到。
