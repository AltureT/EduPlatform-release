# primitives/_shared/

原语作者用的共享件，不对阶段公开（阶段目录不要引用这里的文件）。`gate.js` 的 `declarativeGate(spec, predicates)` 把 `options.gate` 的声明式门槛（`false`、`{ submitted: 0.7, soft: true }`、`{ submitted: 'all' }`、`{ correct: 0.6 }`，以及留给 code / data-analysis 的 `ran` / `testsPassed` / `image`；code / data-analysis 的 `submitted` 是"上交过最终稿"）转成 `gate(ctx)`；分母是在线学生，原语只提供每个指标的判断函数；`validateGateSpec(spec, allowed)` 在 options 校验时用。`StatsPage.jsx` 是所有原语 `TeacherStats.jsx` 的统一骨架：原语声明 `columns`、`summary`、`rowDetail`，骨架负责"姓名"列、摘要芯片、`AlertBar`、`DataTable` 与点行的 `DetailModal`，不自带 `<Page>`（统计视图的 table 模板由外壳套）。`CodeStats.jsx` 是 code / data-analysis 共用的统计视图（含"已上交"列与"最终稿 / 最近运行"行详情）；`FinalSubmit.jsx` 是两者共用的"上交最终稿"按钮 + 状态行 + 确认框，`finalRecord()` 拼最终稿载荷（当前代码 + 最近一次运行结果）。`prompt.js` 的 `validatePrompt(options)` 与 `PromptText.jsx` 是 vote / quiz / free-text 共用的正文槽（P4，`options.prompt`：1–2000 字纯文本，空行分段、段内换行保留，放在视图 `Page.Main` 最前面）。

P6（代码段教学功能规格）：`TaskList.jsx` 是 code 的要求清单与 data-analysis 的任务清单共用的"勾选 + 提示 ▾"（勾选状态由原语视图传 `checked` / `onToggle`）；`taskItem.js` 的 `validateTaskItem(field, t, i, hintMax)` 校验条目（字符串或 `{ text, hint }`），`taskText` / `taskHint` 取文字与提示。`SolutionPanel.jsx` 是学生题目栏的"参考答案"面板（班级记录 `solution` 非空时显示，可放大），同文件的 `PublishSolutionBtn`（未公布：`ConfirmAdvanceBtn` 两次确认"公布参考答案给学生"；已公布："撤回参考答案"）与 `publishedHint(ts)` 给两种原语的大屏用。`CodeStats.jsx` 另收 `starters`（code 多份起始代码的名字）：行详情"起点：…"、摘要"起点 A n · B m"；记录带 `afterSolution` / `final.afterSolution` 时两列后缀"（答案后）"。
