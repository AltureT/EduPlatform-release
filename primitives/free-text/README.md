# free-text · 自由作答

一到三道开放题，学生在文本框里写短文、看着字数计数提交（缺省可以改）。大屏显示题目与提交 N/M；教师在统计页点行看全文，点"投到大屏"把这位学生的作答（署名）大字投到演示页，"取消展示"收回。教师统计页、推进门槛、3 分钟未提交提醒、个人报告条目（各题原文）、分享推荐（提交最早的 5 人）全部自动有。

与 share 组件的分工：share 是学生之间互看的分享墙；free-text 的"投到大屏"是教师单向挑一份展示。

## options

| 键 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `prompts` | 1–3 题 | 必填 | 每题 `{ id?, title, placeholder?, min?, max? }`，也可直接写字符串（即 `title`）；见下表 |
| `prompt` | 字符串 1–2000 字 | 无 | 各题共用的正文 / 材料（短信原文、案例）：学生页在标题下、文本框之前显示，大屏在未投屏时显示在题目之前（投屏时大屏只放该生作答）；纯文本，可多行（空行分段）。**题目一句话放 `prompts[].title`，材料放 `prompt`**（注意 `prompt` 与 `prompts` 是两个键） |
| `canChange` | 布尔 | `true` | 提交后能否改（按钮变为"更新"，以最后一次为准） |
| `gate` | 声明式门槛 | `{ submitted: 0.7, soft: true }` | `false` 或 `{ submitted: 0.7 \| 'all', soft }`；阶段写 `gate(ctx)` 函数则以函数为准 |
| `idleAlertMs` | 毫秒 | `180000` | 进入本段多久未提交就提醒教师；`0` 不提醒 |

每道题：

| 键 | 缺省 | 说明 |
|---|---|---|
| `id` | `p1`、`p2`… | 字母、数字、`-`、`_`，1–32 位，不重复 |
| `title` | 必填 | 题目 1–200 字 |
| `placeholder` | 无 | 文本框里的灰字提示，1–200 字 |
| `min` | `0` | 至少多少字（0 到 `max`） |
| `max` | `300` | 最多多少字（1–5000） |

字数按字符计（一个汉字、一个 emoji 都算 1），去首尾空白后计。学生端超上限或不到下限时计数标红、按钮不可点；服务端同样校验，超长拒绝并回"第 k 题超出字数上限（已写 n 字，最多 max 字）"。全部题都空着不能提交。

采集：每人 `{ answers, submittedAt }`（`answers` 为题目 id → 原文，已去首尾空白）；班级记录 `featured`：投屏时写 `{ name, answers, at }`——`answers` 是投屏那一刻该生各题原文的**快照**，大屏读快照，该生之后再"更新"不会改动大屏（统计页行详情会多一个"投最新版本"，点了再投一次取最新）；取消展示为 `null`。`teacher:feature { name | null }` 只允许投已提交的学生。**注意**：快照含学生名与原文，班级记录会发给全班——大屏上本来就署名展示，不是额外泄露（契约 §三 的例外）；但不要把 free-text 的班级记录拿去做匿名用途。

页面样式固定 `focus`：单题时题目进标题区、文本框撑满面板；多题时标题为阶段名，各题纵向排列在面板里（面板内滚动）。原语的 `layout` 是静态值，不能按题数切到 `stack`。

模拟片段 `__tests__/simulate.js`：`play` 让每个虚拟学生为每题写一段满足 min / max 的文字后提交；`loadAction` 每次写一份新文字再提交（`canChange` 为 `false` 时第二次起以服务端的"已提交"回执为准）；调用方没传 `ctx` 时只写第一题 `p1`。

## 示例

```js
// stages/05-why/stage.config.js
export default {
  id: 'prime-why',
  label: '说说理由',
  primitive: 'free-text',
  options: {
    prompts: [
      { id: 'why', title: '你是怎么判断一个数是不是质数的？', placeholder: '写出你的方法', min: 5, max: 200 },
      { id: 'ask', title: '关于质数，你还想知道什么？', max: 100 },
    ],
  },
};
```

目录里只要 `STAGE.md` 和这个文件。要追加提醒写 `alerts: [...]`（id 不能是 `idle`）；要换学生页就在阶段目录放自己的 `Student.jsx`；`collect`、`subPhases`、`layout` 由原语决定，不能写。

## 什么时候不该用 free-text

- 学生要互相看、点赞、评论 → 用 share 组件的分享墙（可以接在 free-text 之后）。
- 要按关键词自动判对错 → 用 `quiz` 的填空题。
- 超过三道题、要分步骤、要上传图片或代码 → 自写阶段，代码题用 `code`。
