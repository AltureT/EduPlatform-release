# 框架地图

> 版本：v0.2 · 2026-09-27（K7 框架自描述；C5 课程本地组件）
> 读者：打开本目录的任何 AI 开发工具（Claude Code、Codex、Cursor、Windsurf、Copilot、Trae、Cline、Roo Code、Gemini CLI、Qwen Code 等）。教师不需要读。
> 作用：一页说清这个平台是什么、哪些能复用、哪些能自定义、哪些不能动。细节以各行指向的文档为准。

## 一、这是什么

- 课堂互动平台：教师电脑在教室局域网里跑一个服务，大屏投教师端，学生用平板浏览器加入；一节课是一串"阶段"（段），由教师在教师端推进——教师驱动的阶段状态机。
- **做课 = 在 `lessons/<id>/` 下写一门课程，不是改平台。** 平台本身（内核、原语、组件、脚本、文档、skill）对每节课都一样，升级时整体换新。
- 本目录就是"平台目录"：根上同时有 `package.json` 与 `管理台.command`，所有命令都在这里执行。

## 二、三层与目录

| 层 | 目录 | 你能做什么 | 不能做什么 |
|---|---|---|---|
| 内核（不能动） | `kernel/`、`scripts/`、`docs/`、`skills/` | 读；用 `#kernel/client/index.js` 导出的组件与令牌（`docs/05`）；用 `ctx` / `cctx`（`docs/02`）；跑 `npm run` 各命令 | 改任何文件；绕过契约直接 import 内部路径 |
| 可复用：原语（配置即用） | `primitives/<type>/`（`vote` / `quiz` / `free-text` / `code` / `data-analysis`） | 在 `stage.config.js` 写 `primitive` + `options`（各原语 README 的 options 表） | 改原语源码；给原语段加字段（`collect` / `subPhases` / `layout` / `sandbox`） |
| 可复用：可选组件（开关即用） | `components/<id>/`（`sandbox` / `mirror` / `share` / `inbox` / `report` / `coach`） | `lesson.config.components` 打开、给选项；阶段顶层写组件字段（如 `coach: true`） | 改组件源码 |
| 课程自定义 | `lessons/<id>/`（`lesson.config.js`、`stages/*/`、`components/*/`、`教学设计.md`、`平台规格.md`、`进度.md` 等） | 一切：自写段的 `Student.jsx` / `TeacherDemo.jsx` / `TeacherStats.jsx` / `server.js` / `stage.config.js`（按 `docs/02`）；这节课自己的组件 `components/<cid>/`（跨段或旁挂的功能，与平台组件同形，按 `docs/06`）；`theme`、附加文件（数据表、起始代码、图片） | 写接口地址与密钥、自己连外网 AI（用 `ctx.ai`）、固定定位 / 像素高度（`check:ui`） |
| 运行数据（不碰） | `data/`、`backups/`、`.env`、`vendor/`、`node_modules/`、`dist/`、`版本.json` | — | 手改（`.env` 只由 `npm run new:lesson` 与管理台写；`版本.json` 是发布包自带的清单，改了检查就失真） |

另外：

- `examples/<课>/` 是示例课，照着写的范本（`examples/minimal` 最小、`examples/primitives-tour` 五种原语与课程组件范本 `components/gallery/`、`examples/python-intro` 与 `examples/anti-fraud` 是完整课）。读和抄都行，不要改。
- 根上的 `index.html`、`vite.config.js`、`package.json` 属于内核层；`CLAUDE.md`、`AGENTS.md`、`GEMINI.md`、`QWEN.md`、`.cursor/`、`.windsurf/`、`.github/`、`.trae/`、`.clinerules/`、`.roo/` 是各 AI 工具的入口文件，内容相同，也属平台文件。 根上的 `管理台.command` / `管理台.bat`、`README.md`、`.env.example` 属于平台自带、不受保护但也不该改。
- 平台缺某个能力：先看能不能自写段（一段内）或课程组件（跨段、旁挂，`lessons/<id>/components/`，`docs/06`）；都做不到才告诉教师，记进 `lessons/<id>/平台规格.md` 的"后续定制"，先用简化做法——不要改平台文件绕过。

### 一段课怎么落地

- **原语段**：阶段目录只要 `STAGE.md`（阶段卡）+ `stage.config.js`（`primitive: 'vote'` 等 + `options`）。题目、答案、门槛都写在 `options` 里；答案保密由平台处理。
- **自写段**（`primitive: null`）：`stage.config.js` + `server.js`（`export function register(ctx)`）+ `Student.jsx` + `TeacherStats.jsx`（+ 可选 `TeacherDemo.jsx`、`__tests__/`）。只从三个公开入口引用内核：`#kernel/server/schema.js`、`#kernel/client/index.js`、`#kernel/test-utils/index.js`；已打开的组件按 `docs/02` §一 的组件入口引用；段与段之间不互相 import。
- 视图根是 `<Page template="…">`（五种页面样式：`focus` / `split` / `tiles` / `table` / `stack`，见 `docs/04`）；颜色、字号、间距只用 `var(--…)` 令牌，换颜色只改 `lesson.config.js` 的 `theme`（`docs/05`）。
- 要 AI 点评 / 生成：只在 `server.js` 里 `ctx.ai.chat`（`docs/02` §三"调 AI"），地址、模型、密钥由教师在管理台"设置"页填；学生页不调 AI。

## 三、从哪开始

| 要做的事 | 读什么 |
|---|---|
| 做一节课、改一节课、上课前检查 | 完整读 `skills/SKILL.md`，按它一环一环做 |
| 对话里贴进来的是"阶段审查清单" | 只按那份清单审查，不做课 |
| 只看某一段怎么写（`stage.config.js`、`ctx`、视图 hooks、测试） | `docs/02-阶段模块契约.md` |
| 阶段卡长什么样 | `docs/01-教学设计模板_阶段卡版.md` |
| 页面长什么样、教师说法对哪种页面 | `docs/04-页面模板图鉴.md` |
| 样式：令牌、可用组件、主题色 | `docs/05-样式约定.md` |
| 某个原语的 options | `primitives/<type>/README.md`（总表 `primitives/README.md`） |
| 某个组件怎么开、上课时在哪 | `components/README.md`（coach 另有 `components/coach/README.md`） |
| 给这节课做一个自己的组件（作品墙、分层挑战、互评……） | `docs/06-组件契约.md`，范本 `examples/primitives-tour/components/gallery/` |

## 四、机器检查（写完必须过）

- `npm run check:lesson -- lessons/<id>/lesson.config.js`：课程校验（配置、阶段卡、事件、保密、界面规则、AI 接口，以及平台文件改动检查）。有"错误"先改完；报"平台文件被改过"说明平台文件被动过，把改动挪回课程目录。
- `npm run check:ui`：界面规则（固定定位、像素尺寸、vh / vw、@media 等）。
- `npm run simulate -- --lesson lessons/<id>/lesson.config.js --students 5`：模拟一班学生上完整节课，末行 `=== RESULT: PASS (exit 0) ===`。
- `npm test`：平台自身的测试（开发仓库里有；发布包不带测试）。
- 自写段、课程组件自己的测试：`node --test lessons/<id>/stages/NN-<段id>/__tests__/server.test.js`、`node --test lessons/<id>/components/<cid>/__tests__/server.test.js`。

## 五、升级会怎样

- 新版本整体覆盖"内核 / 原语 / 组件"三层与 `docs/`、`skills/`、根上的入口文件；`lessons/`、`data/`、`backups/`、`.env`、`vendor/` 保留。
- 所以改平台文件的功夫升级就没了。要改平台，请教师到发布仓库提需求（地址在 `README.md`）。
- 发布包里的 `版本.json` 记着每个平台文件的指纹（`protected`）；`check:lesson` 与管理台据它发现平台文件被改动、缺失或多出，并提示"重新解压发布包覆盖这些目录即可恢复（课程、数据、`.env` 不会丢）"。
