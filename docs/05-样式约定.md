# 样式约定

> 版本：v0.1.1 · 2026-09-27（U6：`CodeView` 与 `--code-*` 令牌）；v0.1 · 2026-09-26（S1）
> 读者：生成阶段代码的 AI。教师只看下面三句。
> 依据：界面整理规格 §2–§6、契约 §四"页面与布局"与 §十、`docs/04-页面模板图鉴.md`；令牌以 `kernel/client/global.css` 与 `kernel/client/theme.js` 为准，本文与之不一致时以代码为准。

1. 页面外壳（顶栏、底部操作条）、五种页面模板、按钮样式由平台固定，每节课长得一样。
2. 每一段只往模板的命名区域里放内容，不自己排版。
3. 颜色、间距、字号只用平台的令牌；教师要换颜色时只改主题色，不改布局。

## 一、令牌（写法 `var(--名字)`）

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--sp-1` `--sp-2` `--sp-3` `--sp-4` `--sp-5` `--sp-6` | 4 / 8 / 12 / 16 / 24 / 32 px | 内边距、外边距、间隔；小间隔用 1–3，块与块、卡片内边距用 4–6；布局原语 `gap={1…6}` 就是它们 |
| `--fs-min` | 13 px | 字号下限，任何文字不得更小（下面各字号取 rem 值与它的较大者） |
| `--fs-2xs` / `--fs-xs` | 0.75 / 0.8125rem | 角标、极小注记 / `Chip`、表格内小字、标签 |
| `--fs-sm` | 0.875rem | `hint`、次要说明、按钮文字 |
| `--fs-md` | 1rem | **正文缺省**：题干、选项、输入框文字 |
| `--fs-lg` / `--fs-xl` | 1.125 / 1.375rem | 段内小标题、强调的一句 / 页面标题（`<Page title>` 已用，阶段不另写） |
| `--fs-display` / `--fs-jumbo` | 2 / 3rem | 大数字（得分、计数）/ 教师大屏上的特大数字、倒计时 |
| `--brand` / `--brand-soft` | 深蓝 / 8% 浅底 | 主按钮底色、顶栏标志、进度条缺省色、选中态 / 选中项背景 |
| `--accent` / `--accent-soft` | 陶土橙 / 10% 浅底 | 强调、正在进行、提示，`Btn variant="accent"` / 提示条底 |
| `--good` `--bad` `--warn` 及 `-soft` | 绿 / 红 / 琥珀 | 对与完成 / 错与未通过 / 注意与快到时间；`-soft` 是同色浅底（`Chip` 底色） |
| `--ink` / `--ink-soft` / `--ink-dim` | 近黑 / 灰褐 / 浅灰 | 正文文字 / 次要文字、说明 / 占位、未开始、禁用 |
| `--surface` / `--surface-alt` / `--bg` | 白 / 米白 / 暖白 | 卡片、面板、输入框底，深色按钮上的字 / 浅底块（侧区、输出、`soft` 按钮）/ 页面底（外壳已用） |
| `--border` / `--border-strong` | 10% / 20% 墨色 | 细分隔线 / 输入框与 `ghost` 按钮边框 |
| `--shadow` / `--shadow-soft` / `--overlay` | — | 浮起的面板 / 卡片轻阴影 / 弹层遮罩（`Overlay` 自带，阶段不写） |
| `--radius` / `--radius-sm` | 14 / 10 px | 卡片、面板、输入框 / 按钮、小块 |
| `--control-h` / `--control-h-sm` | 40 px（触屏 44）/ 32 px | 一切可点元素（按钮、输入框、可点的行）的高 / 只用于顶栏芯片与表格内按钮 |
| `--control-h-lg` | 58–78 px | 只在教师端（`.teacher-app`）定义：大屏上的大按钮 |
| `--row-h` | 40 px | 表格行高（`--header-h` `--actionbar-h` 是外壳的，阶段不用） |
| `--font-mono` | 等宽字体栈 | 自写段里要等宽的文字（报错行、编号）写 `fontFamily: 'var(--font-mono)'`；展示代码直接用 `<CodeView>` |
| `--code-keyword` `--code-string` `--code-comment` `--code-number` `--code-def` `--code-builtin` `--code-operator` `--code-variable` `--code-bg` | 紫 / 红 / 棕 / 绿 / 蓝 / 靛 / 灰褐 / 同 `--ink` / 同 `--surface-alt` | 代码配色：`<CodeView>` 与编辑器已用，阶段不直接写 |

教师端（`.teacher-app` 内）字号令牌按投影放大，写法不变；教师端另有 `--base` `--heading` `--data-num` `--card-pad`。

## 二、能用的组件（`import { … } from '#kernel/client/index.js'`）

布局原语与页面模板（只收契约 §十 列出的 props，不收 `style`）：

| 名字 | 用途 | 写法 |
|---|---|---|
| `Page` | 每个学生页与演示页的根；五模板 `focus` `split` `tiles` `table` `stack` | `<Page template="split" title="读数据" hint="3/5">` |
| `Page.Main` / `Page.Side` / `Page.Aside` / `Page.Actions` | 主体 / 第二块 / 次要说明 / 主按钮（进底部操作条） | `<Page.Actions><Btn>提交</Btn></Page.Actions>` |
| `Fill` | 占满剩余高度（输入框、编辑区） | `<Fill scroll>…</Fill>` |
| `Split` | 页面内两栏，窄屏上下；`resizable` 可拖宽 | `<Split ratio="3:2">{左}{右}</Split>` |
| `Tiles` / `Tile` | 自动换行的磁贴网格 / 一格 | `<Tiles min="200px"><Tile title="A组">…</Tile></Tiles>` |
| `Stack` / `Row` | 纵向排列 / 横向排列（自动换行） | `<Row gap={2}>…</Row>` |
| `Scroll` | 内部滚动容器 | `<Scroll>{长列表}</Scroll>` |
| `useNarrow()` | 是否窄屏（< 900 px），代替 `@media` | `const narrow = useNarrow();` |
| `Overlay` | 唯一允许的弹层：`dialog` `panel` `drawer` `menu` | `<Overlay variant="dialog" label="确认">…</Overlay>` |

`ui/` 基础组件：

| 名字 | 用途 | 写法 |
|---|---|---|
| `Btn` | 按钮；`primary` `accent` `ghost` `soft`，尺寸 `md`（缺省）/ `lg` / `sm` | `<Btn variant="ghost">重做</Btn>` |
| `Card` | 白底圆角卡片 | `<Card>…</Card>` |
| `Chip` | 小标签；`tone` 取 `brand` `accent` `good` `warn` `bad` 等 | `<Chip tone="good">已交</Chip>` |
| `Bar` | 横向进度条 | `<Bar value={3} max={5} />` |
| `HelpTip` | 包住任意元素，悬停时显示说明气泡 | `<HelpTip text="数据的平均水平">均值</HelpTip>` |
| `GroupTag` | 分组色点 + 组名 | `<GroupTag label="第2组" />` |
| `ConfirmAdvanceBtn` | 点两次才生效的按钮（次要的二次确认操作） | `<ConfirmAdvanceBtn onAdvance={reset}>清空</ConfirmAdvanceBtn>` |
| `CodeView` | 只读展示代码（Python 高亮，颜色走 `--code-*`）；`size` `sm` / `md`，`wrap` 折行，`maxLines` 截断 | `<CodeView code={src} size="sm" />` |
| `StepBar` `ViewToggle` | 在 `ui/` 里，但是外壳内部件，公开入口不导出，阶段不用 | — |

教师统计页另有 `DataTable` `DetailModal` `AlertBar` `BarDistribution` `ProgressBadge`，props 见契约 §十。

## 三、自写段的写法规则

- 行内样式里的颜色、字号、间距、圆角只写 `var(--…)`：不写 `#2B3A55`、`rgb(…)` 这类颜色，不写 `fontSize: 15` / `'15px'`。
- 尺寸只用 `maxWidth`、`flex`、`gap`；高度交给 `<Page>`、`<Fill>` 与布局原语。
- 标题写在 `<Page title>`（一行灰字写 `hint`），不自写 `<h2>`。
- 学生端主按钮放 `Page.Actions`；教师演示页的 `Page.Actions` 只放次要按钮（"进入下一段"由平台提供）。
- 可点元素的高用 `var(--control-h)`（`Btn` 已是）；自写表格行高用 `var(--row-h)`。
- 展示代码用 `<CodeView>`（高亮、等宽、保留缩进），不要裸 `<pre>`；代码颜色是 `--code-*` 令牌（可在 `lesson.config.theme` 覆盖，见 §四）。
- `npm run check:ui` 会拦下这七条（行尾 `// check-ui-ignore-line` 可豁免单行，须说明理由）：
  1. `position: fixed | absolute`（弹层用 `Overlay`）
  2. 样式里数值 `height` / `minHeight` / `width` 超过 64 px（`maxWidth` / `maxHeight` 允许）
  3. JSX 属性 `height={300}` / `width="300"` 超过 64（`canvas` `svg` `img` `video` `iframe` 除外）
  4. `vh` / `vw` 单位（含 `dvh` `svh` `lvh`）
  5. `@media`（窄屏判断用 `useNarrow()`）
  6. `Student.jsx` / `TeacherDemo.jsx` 顶层 return 不是 `<Page>`
  7. `TeacherStats.jsx` / `TeacherDemo.jsx` / `TeacherActions.jsx` 里出现 `advance(`（推进在外壳操作条）
  8. 原语目录里有 `TeacherDemo.jsx`（演示视图就是学生页，教师按钮放 `TeacherActions.jsx`）

## 四、教师要定制时

唯一入口：`lesson.config.js` 的 `theme`，键是 `theme.js` 的 camelCase 键，平台把它写到对应令牌（`surfaceAlt` → `--surface-alt`）。共 33 个键：

- 颜色（19）：`bg` → `--bg`、`ink` → `--ink`、`inkSoft` → `--ink-soft`、`inkDim` → `--ink-dim`、`brand` → `--brand`、`brandSoft` → `--brand-soft`、`accent` → `--accent`、`accentSoft` → `--accent-soft`、`good` → `--good`、`goodSoft` → `--good-soft`、`bad` → `--bad`、`badSoft` → `--bad-soft`、`warn` → `--warn`、`warnSoft` → `--warn-soft`、`surface` → `--surface`、`surfaceAlt` → `--surface-alt`、`border` → `--border`、`borderStrong` → `--border-strong`、`overlay` → `--overlay`
- 代码配色（9，U6）：`codeKeyword` → `--code-keyword`、`codeString` → `--code-string`、`codeComment` → `--code-comment`、`codeNumber` → `--code-number`、`codeDef` → `--code-def`（函数 / 类的定义名与调用名）、`codeBuiltin` → `--code-builtin`（只指 True / False / None 这类常量）、`codeOperator` → `--code-operator`、`codeVariable` → `--code-variable`（缺省 = `--ink`）、`codeBg` → `--code-bg`（缺省 = `--surface-alt`）；`<CodeView>` 与编辑器共用
- 圆角（2）：`radius` → `--radius`、`radiusSm` → `--radius-sm`；阴影（2）：`shadow` → `--shadow`、`shadowSoft` → `--shadow-soft`；等宽字体（1，U6）：`fontMono` → `--font-mono`
- **允许**：改颜色、圆角、阴影、等宽字体（上面的键）。
- **不允许**：改布局与模板、字号（尤其下限 `--fs-min`）、控件高度（`--control-h` 等）、间距、外壳；`theme` 里不写这些键。
- 教师说"换个颜色 / 主题色"→ 改 `brand`（顶栏标志与主按钮）与 `accent`（强调），例：`theme: { brand: '#1F4E79', accent: '#C0504D' }`。两色要够深：主按钮上是白字，`brand` 在步骤条里又当文字色压在 `--bg` 上，深浅宜接近 `--ink`；教师给的是浅色（浅黄、浅绿）就取同色系更深的一档，并告诉教师。
- 改了 `brand` / `accent` 时，`brandSoft` / `accentSoft` 一并换成同色的 `rgba(r, g, b, 0.08)` / `0.1`，否则选中项浅底仍是默认色。
- 教师要的超出上面这些（换版式、放大字号、改按钮位置）→ 不改，在 `进度.md`"待办与后续定制"记一行 `- 后续定制：段 <N> / <要的> / 平台样式固定`，告诉教师这节课先用平台样式。
