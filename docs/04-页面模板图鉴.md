# 页面模板图鉴

> 版本：v0.1 · 2026-09-25（U4）
> 读者：skill（生成阶段代码的 AI）与教师。教师看每节的一句话和截图就够；代码部分给 AI。
> 依据：界面整理规格 §3.5（五个模板与命名区域）、契约 v0.7.2 §四"页面与布局"、§十 `Page` 一行；令牌、可用组件与定制口径见 `docs/05-样式约定.md`。
> 用法：教学设计阶段卡（docs/01）的"页面样式"栏五选一，写进 `stage.config.js` 的 `layout`；`Student.jsx` 根元素是 `<Page>`，内容只往命名区域里放。

所有页面共用同一个外壳：**顶栏**（品牌、阶段导航 / 步骤条、组件入口）→ **横幅区**（回看、提示，没有时不占高）→ **内容区**（下面五个模板之一）→ **底部操作条**（主按钮，`Page.Actions` 的内容出现在这里）。模板只决定内容区怎么分块，外壳不变。

命名区域（按模板出现）：

| 区域 | 放什么 | 说明 |
|---|---|---|
| `title` / `hint`（`<Page>` 的属性） | 题目、阶段名；一行灰字（字数、进度） | 标题区有底线；阶段不再自己写 `<h2>` |
| `Page.Main` | 本页主体 | 所有模板都有；纵向排列，里面的 `<Fill>` 能撑到可用高度 |
| `Page.Side` | 第二块内容（输出、名单、推荐） | 只有 `split`、`table` 用；浅底、细边 |
| `Page.Aside` | 次要说明 | 在 Main 下方，虚线分隔，最多占 30% 高 |
| `Page.Actions` | 主按钮（提交、保存） | 渲染到外壳底部操作条，不在页面里 |

截图说明：三种视口 1366×768（机房宽屏）、1024×768（平板横屏）、768×1024（平板竖屏，窄屏 < 900 px）。截图与度量（`metrics.json`，全部 `fitsVertically: true`、无横向溢出）在开发仓库 `docs/rehearsal/ui/` 下，发布包不含；本图鉴只保留文字与代码。

## focus · 聚焦一件事

**一句话**：一道题、一段文字、一张图——整页只做一件事，内容放在居中的一块面板里。

- **适合**：单选 / 多选题、读一段材料、看一张图、写一小段话；教师演示视图（缺省就是 focus，内容纵向居中、不加面板）
- **不适合**：要同时看两块内容（代码 + 输出 → `split`）；多张并列卡片（→ `tiles`）；分几步往下做（→ `stack`）
- **区域**：只有 `Page.Main`。面板最大宽 960、水平居中、顶对齐。**面板高度随内容**：Main 里没有 `<Fill>` 时面板按内容高（选项少时不会留一大片空白）；放了 `<Fill>`（如作答框）时面板撑满可用高度

```js
// stage.config.js
export default { id: 'vote', label: '投票', layout: 'focus' /* , gate, collect … */ };
```

```jsx
// Student.jsx
import { useStudentStage, Btn, Page, Tiles } from '#kernel/client/index.js';
export default function Student() {
  const { myData, send } = useStudentStage('vote');
  return (
    <Page title="下列哪个数是质数？">
      <Page.Main><Tiles min="140px">{['A', 'B', 'C'].map((k) => (
        <Btn key={k} aria-pressed={myData?.choice === k} onClick={() => send('student:vote', { choice: k })}>{k}</Btn>))}
      </Tiles></Page.Main>
    </Page>
  );
}
```

## split · 左右两栏

**一句话**：两块内容并排看——宽屏左右（3 : 2），窄屏上下。

- **适合**：写代码看结果（`<PyRunner>` 自带编辑器 + 输出两栏）、题目 + 作答、图 + 表、名单 + 操作（教师课前页）
- **不适合**：只有一块内容（→ `focus`）；三块以上并列（→ `tiles`）
- **区域**：`Page.Main`（左 / 上，占 3 份）+ `Page.Side`（右 / 下，占 2 份，浅底）。不写 `Page.Side` 时不分栏，Main 占满全宽（`PyRunner` 这类自己分两栏的组件就这样用）；窄屏时 Side 为空也只显示 Main

```js
// lesson.config.js 须打开代码沙盒组件，否则 PyRunner 无法运行：components: ['sandbox']（或 { id: 'sandbox', packages: [...] }）
// stage.config.js
export default { id: 'hello', label: '第一行代码', layout: 'split', sandbox: { starter: 'print("你好")' } };
```

```jsx
// Student.jsx
import { useState } from 'react';
import { Page } from '#kernel/client/index.js';
import { PyRunner } from '@components/sandbox/index.js';
export default function Student() {
  const [code, setCode] = useState('print("你好")');
  return <Page title="打印一句话"><Page.Main><PyRunner stageId="hello" code={code} onChange={setCode} /></Page.Main></Page>;
}
```

## tiles · 磁贴墙

**一句话**：若干张同类卡片自动排成网格，宽屏多列、窄屏单列。

- **适合**：个人报告的各段、名单、选项墙、作品展示；谢幕页（内核缺省就是 tiles，组件的谢幕槽位各是一张磁贴）
- **不适合**：卡片之间有先后顺序（→ `stack`）；只有一张卡（→ `focus`）
- **区域**：只有 `Page.Main`，里面直接放若干 `<Tile title>`（不要再包一层 `<Tiles>`）；每列最小宽 260 px，放得下几列就几列

```js
// stage.config.js
export default { id: 'gallery', label: '作品墙', layout: 'tiles' };
```

```jsx
// Student.jsx
import { useStudentStage, Page, Tile } from '#kernel/client/index.js';
export default function Student() {
  const { classData } = useStudentStage('gallery');
  return (
    <Page title="大家的作品">
      <Page.Main>{(classData.works ?? []).map((w) => <Tile key={w.name} title={w.name}>{w.text}</Tile>)}</Page.Main>
    </Page>
  );
}
```

## table · 表格 + 侧栏（教师统计，外壳自动）

**一句话**：一张全班数据表，右侧 300 px 放推荐 / 邀请；窄屏时侧栏收进底部"推荐 ▾"抽屉。

- **适合**：教师统计视图——**固定就是 table，由外壳自动套**，`TeacherStats.jsx` 只返回 `AlertBar` + `DataTable`（+ 点行的 `DetailModal`），不写 `<Page>`
- **不适合**：学生视图（学生端一屏不滚动，长表格放不下；学生要看名单用 `tiles`）
- **区域**：`Page.Main` = 提醒条 + 表格（表内滚动、表头固定）；`Page.Side` = 组件的 `teacherSidebar`（没有提供者时不占位）。窄屏时组件入口（镜像、收件箱）收进操作条"更多 ▾"，菜单里有内容才显示

```js
// stage.config.js（统计视图不用写 layout）
export default { id: 'vote', label: '投票', alerts: [{ id: 'idle', when: (s, now) => s.choice == null && now - s.enteredStageAt > 180_000, text: '3 分钟未提交' }] };
```

```jsx
// TeacherStats.jsx（不是 <Page>，外壳套 table）
import { useTeacherStage, AlertBar, DataTable } from '#kernel/client/index.js';
export default function TeacherStats() {
  const { roster, perStudent, alerts } = useTeacherStage('vote');
  const rows = roster.map((s) => ({ ...s, choice: perStudent[s.name]?.choice ?? '—' }));
  const columns = [{ key: 'name', label: '姓名' }, { key: 'choice', label: '选项' }];
  return <><AlertBar alerts={alerts} /><DataTable columns={columns} rows={rows} rowKey="name" offlineKey="connected" /></>;
}
```

## stack · 自上而下几步

**一句话**：单列从上往下排——先读题，再作答，最后看结果；最大宽 960。

- **适合**：有先后顺序的几步（读材料 → 作答 → 看反馈）、一问一答的小流程
- **不适合**：两块内容要对照着看（→ `split`）；一件事就够（→ `focus`）
- **区域**：只有 `Page.Main`，内容按书写顺序纵向排列；需要某一块撑满剩余高度（如作答框）时包 `<Fill>`，其余按内容高。`<Fill>` 是纵向 flex 容器，里面的 `textarea` 要写 `style={{ flex: 1 }}` 才会跟着撑满（`flex` 允许，不能写像素高度）

```js
// stage.config.js
export default { id: 'read', label: '读一读', layout: 'stack' };
```

```jsx
// Student.jsx
import { useStudentStage, Page, Tile, Fill } from '#kernel/client/index.js';
export default function Student() {
  const { myData } = useStudentStage('read');
  return (
    <Page title="读材料，回答问题">
      <Page.Main><Tile title="材料">……</Tile><Fill><textarea aria-label="作答" style={{ flex: 1 }} /></Fill>{myData?.feedback && <Tile title="反馈">{myData.feedback}</Tile>}</Page.Main>
    </Page>
  );
}
```

## 教师说法 → 模板

| 教师在阶段卡里的说法 | 页面样式 |
|---|---|
| "学生选一个答案" / "看一段材料" / "写一句话交上来" | `focus` |
| "写代码看结果" / "左边题目右边作答" | `split` |
| "看每个人的报告" / "作品墙" / "名单" | `tiles` |
| "我看全班进度" / "谁没交" | `table`（教师统计视图，外壳自动，不用选） |
| "先读题再作答再看结果" / "分三步做" | `stack` |

拿不准时：一件事 → `focus`；两块对照 → `split`；很多张同类卡 → `tiles`；有先后顺序 → `stack`。
