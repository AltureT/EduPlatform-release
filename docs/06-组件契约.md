# 组件契约

> 版本：v0.4 · 2026-10-01（v0.4：T9a 教师端——`teacherToolbar` 从顶栏移到底部操作条（`slots.teacherToolbarOrder` 排先后）、新槽位 `teacherPrelogin`（课前页状态行）、状态不当按钮摆；v0.3：T9b 槽位 `studentDock` 与标题元数据 `dockTitle`、`useDock()`；v0.2：C7 教师专属存储 `cctx.teacherData`；v0.1：2026-09-27 C5 课程本地组件）
> 读者：AI。教师不需要读。
> 作用：一页说清一个"组件"长什么样——跨段或旁挂在页面边上的功能（作品墙、分层挑战、互评……）怎么写。平台自带的组件（`components/<id>/`）与这节课自己的组件（`lessons/<id>/components/<cid>/`）是同一种东西，写法完全相同。阶段怎么写见 `docs/02-阶段模块契约.md`。

## 一、放在哪、怎么启用

- 课程组件放 `lessons/<id>/components/<cid>/`，只在这节课有效，随课程存档，升级不覆盖；以后别的课也要用，原样搬进平台 `components/` 就是平台组件。
- 生成骨架：`npm run new:component -- lessons/<id>/lesson.config.js <cid> --label "<中文名>"`（id 缺省加 `x-` 前缀，防将来与平台组件撞名）。
- 启用：`lesson.config.js` 的 `components` 里写 `'<cid>'`，或 `{ id: '<cid>', ...选项 }`（选项即 `cctx.options` / `useComponent().options`，会下发到学生端，不放密钥与答案）。
- 开在哪些段：在那些段的 `stage.config.js` **顶层**写 `'<cid>': true`（或一个对象；id 带连字符要加引号），组件自己读（与 `coach: true` 同一约定，读法见 §四）；也可以全程生效。`isEnabledFor(stageId)` 只看阶段的 `stage.config.components`（该段显示哪些组件的入口，缺省全部），不是按段开关——按段开关一律读顶层 `'<cid>'` 字段。
- 同名：平台已有的 id、`share inbox report mirror coach sandbox web-sim`、`stage student teacher classroom error component` 都不能用；与平台组件重名启动失败。

## 二、目录形状

```
<cid>/
  component.config.js    # export default { id: '<cid>', label: '<中文名>' }   【必需】id 与目录名一致
  server.js              # export function register(cctx)；可选 export function report(name, cctx)、export function http(router, cctx)
  client.jsx             # export default { slots, store }
  stageConfig.js         # useStageOn(stageId)：本段顶层 '<cid>' 字段为 true 才显示（按段开关）
  README.md              # 给 AI：是什么、开在哪些段、事件与数据形状
  __tests__/server.test.js、client.test.jsx
```

`component.config.js` 另可写（一般用不到）：

- `static: { '/前缀': '<目录>' }`：静态文件。课程组件的目录**相对课程目录**（`lessons/<id>/`，如 `'components/x-wall/assets'`），平台组件相对项目根；前缀不得是 `/`、`/teacher`，不得以 `/api`、`/socket.io`、`/assets` 开头。
- `requires: [{ path, hint }]`：启动前检查的文件，`path` **相对项目根**（平台目录，如 `vendor/…`），缺了打印 `hint` 并拒绝启动。
- `server.js` 的 `export function http(router, cctx)`：`router` 是 express 路由，挂在 `/api/c/<cid>/` 下（`router.get('/list', …)` → `GET /api/c/<cid>/list`）；鉴权由组件自己决定。客户端只从教师端调：`useComponent('<cid>').authFetch('/api/c/<cid>/list')`（自动带教师凭据；学生端调用会抛错）。学生端的数据一律走事件与 `data`。

## 三、服务端 `register(cctx)`

| cctx | 说明 |
|---|---|
| `id`、`options`、`log` | 本组件 id、lesson.config 里给的选项、日志（`log.info(msg, 对象)`，不记真名，用 `anon.code(name)`） |
| `on(event, schema, handler)` | 事件名必须 `<cid>:s-<名>`（只收学生）或 `<cid>:t-<名>`（只收教师），名只含小写字母和连字符；`schema` 用 `shape({…})`（`#kernel/server/schema.js`，规则见契约 §三）；`handler(socket, payload, actor)`，`actor = { role, name }`。组件事件不受"仅当前段"限制，要限制就自己判 `state.currentStage` |
| `reject(socket, '一句话')` | 拒绝；这句话由学生 / 教师外壳在横幅区显示几秒 |
| `data` | 本组件的数据：`get(name)` / `set(name, patch)`（到人，浅合并）/ `all()` / `getClass()` / `setClass(patch)`（到班，全员收到）/ `appendEvent(name, type, payload)`；写入后平台自动推给教师与本人，刷新后仍在 |
| `stages.list()` / `stages.data(id)` | 课程各段 `[{ id, label, config, dir }]`（`config` 是有效配置，顶层字段如 `<cid>: true` 在里面）；某段记录只读 `{ get(name), all(), getClass() }` |
| `state` | `currentStage`、`stageIndex`、`subPhase`、`students()`、`connected()`、`student(name)` |
| `hooks.onStageChange(fn({ from, to }))`、`hooks.onReset(fn)` | 换段、重置课堂时调用（清内存状态、收起弹层） |
| `anon.code(name)` | 每段稳定的匿名代号"同学 A"，给学生看别人时用 |
| `actions.append(type, payload)` | 记一条教师操作（课后导出看得到，可含真名） |
| `ai` | 调 AI 只用 `cctx.ai.chat(messages, { caller: '<cid>' })`；`ai.configured` 为 false 时照常工作、不报错（契约 §三"调 AI"） |
| `emitAll / emitTeachers / emitStudents / emitToStudent(name, …) / emitToSocket(socket, …)` | 临时广播，事件名 `<cid>:<名词>`（不带 `s-` / `t-`）；要刷新后还在的一律用 `data` |
| `teacherData` | 教师专属存储：`get(key)` / `set(key, value)` / `delete(key)` / `keys()`，见下文"教师专属存储" |

- 数据约定：`perStudent[name] = { … }`、`perClass = { … }`。`perClass` 每次 `setClass` 都会把整条班级记录发给全班、并进 `join-ok`（每个学生加入 / 刷新都收一次）——只放全班都需要、且合计 ≤ 200 KB 的内容；只给教师看的大数据（整面作品墙、全班代码）用定向发送 `emitTeachers`，教师端存进自己的切片（`store.teacher`），刷新后再请求一次。`perStudent` 单条记录也控制在几十 KB 以内。
- 身份信息（同契约 §三）：学生记录（`data.set`）不得含可识别学生身份的内容——别的学生的真名、学号、按姓名索引的逐人数据都不行（给学生看别人时用 `anon.code(name)`）；班级记录（`setClass`）只有教师主动投屏 / 展示时可带被展示学生的名字（如作品墙的 `spotlight.name`）；真名可以出现在只发教师的定向发送与 `actions` 里。
- 教师专属存储（`cctx.teacherData`）：只给教师看、刷新和服务重启后还要在的结果（如 AI 批量核对的逐人判断）放这里。`key` 匹配 `/^[a-z][a-z0-9:_-]{0,63}$/`（如 `review:<stageId>`）；`value` 须可 JSON 化，序列化后 ≤ 200 KB（UTF-8），否则 `set` 抛错——超了由组件自己截短再存。`get` 返回副本，没有返回 `undefined`；`delete` 返回是否删掉了；`keys()` 按字典序。读写同步、立即落库，各组件互相看不到。内核承诺：永不发给学生（不进 `join-ok`、`stage:my-data`、`classroom:state`），不进导出 CSV、个人报告与镜像，写入不发任何事件；教师只能经本组件自己的 `<cid>:t-` 事件取（组件回 `emitToSocket` / `emitTeachers`）。重置课堂与换课时内核整表清空，组件不用自己清。真名可以写在这里。
- 重置课堂：内核先清掉本组件的全部数据（`perStudent` 与 `perClass`，数据库里也清），再调 `hooks.onReset`；组件在 `onReset` 里只需清自己的内存状态（计时器、在途请求、缓存），需要的话写回初始的班级记录。换段不清数据，要收起的在 `onStageChange` 里自己处理。
- `report(name, cctx)`（可选）：谢幕时个人报告在各段之后为本组件加一节，标题 = `label`；返回 `[{ label, value, format? }]`，≤ 12 条、`label` ≤ 20 字、`value`（字符串 / 数字 / null）≤ 2000 字，超出截断，`format: 'code'` 显示为代码块；抛错时这一节省略。要 `report` 组件打开才生效。

## 四、客户端 `client.jsx`

```jsx
import { useComponent, Btn, Overlay } from '#kernel/client/index.js';
export default {
  slots: { studentAside: Aside, teacherToolbar: Button },
  store: { student: { initial: {}, on: { '<cid>:<名词>': (s, p) => ({ ...s, … }) } }, teacher: { initial: {}, on: {} } },
};
```

| 槽位 | 位置 | props |
|---|---|---|
| `studentAside` | 学生页段内一块：`split` 在题目栏（Side）下方，其它页面样式在主区内容下方；回看时一起锁住 | `{ stageId, isLive }` |
| `studentBanner` | 学生页顶部横幅区一行（不超过一个按钮高） | `{}` |
| `studentDock` | 学生页右侧停靠面板（宽屏）：`useDock().openDock('<cid>')` 打开、面板标题行 ✕ 或 `closeDock()` 关闭；标题写 `slots.dockTitle: '…'`（字符串，缺省用组件名），标题与 ✕ 由平台画，这里只放内容；宽度学生可拖（280–520）；窄屏不显示，组件自己改开 `studentOverlay` 里的 `<Overlay variant="drawer">` | `{}` |
| `studentOverlay` | 学生端弹层，只放 `<Overlay>` | `{}` |
| `studentCurtain` / `teacherCurtain` | 谢幕页的格子，返回若干 `<Tile>` | `{}` |
| `teacherToolbar` | 教师底部操作条左边的按钮（演示 / 统计 / 明细切换之后；窄屏收进"更多 ▾"）；几个组件都有时按 `slots.teacherToolbarOrder: 数字`（小的在前，缺省 0）排；**只放操作**——只是显示状态的东西（"已就绪 N""未配置"）不当按钮摆，放 `teacherPrelogin` 或 `teacherSidebar` | `{ stageId, isLive, viewMode }`（`viewMode`：`'demo' \| 'stats' \| 'table'`） |
| `teacherSidebar` | 教师统计视图右侧栏（明细表没有侧栏） | `{ stageId, isLive }` |
| `teacherPrelogin` | 教师课前页（二维码下面）一行状态，如"作品墙：还没有人出图"；返回 null 不占位 | `{}` |
| `teacherOverlay` | 教师端弹层，只放 `<Overlay>` | `{}` |
| `teacherMain` | 包裹教师主区（返回 `children` 或替代内容，根用 `<Fill>`） | `{ children, stageId, isLive, viewMode }` |

- 不在这张表里的名字不会显示（`check:lesson` 报错；`dockTitle` 是 `studentDock` 的标题、`teacherToolbarOrder` 是 `teacherToolbar` 的先后，都不是槽位，也认）。`useDock()`（公开入口）返回 `{ open, openDock(id), closeDock() }`：学生端宽屏才有面板，窄屏与教师端 `open` 恒为 `null`。每个槽位在不该出现的段返回 `null`：读本段顶层字段——把 `useStudentStage(stageId).stage['<cid>'] === true` 写成 `stageConfig.js` 里的一个 hook（`new:component` 骨架与 gallery 都这样，单测里 `vi.mock` 它）；`isEnabledFor` 只反映 `stage.config.components`。
- `useComponent('<cid>')` 返回：`options`、`role`（`'student' | 'teacher'`）、`me`（学生端 `{ name, … }`，教师端 null）、`lesson`、`isEnabledFor(stageId)`、`slice` / `setLocal(patch)`（本端临时状态）、`send(event, payload)`（学生端只能发 `<cid>:s-`，教师端只能发 `<cid>:t-`）、`data: { my, perStudent, perClass }`（学生端 `perStudent` 恒为 `{}`）、`stageData(stageId)`（教师端某段全班记录）、`currentStage`、`viewedStage: { id, index, isLive }`、`classEpoch`、`authFetch(path, init?)`（只限教师端：带教师凭据的 `fetch`，调本组件 `http` 路由 `/api/c/<cid>/…`；学生端调用抛错）。
- 只从 `#kernel/client/index.js` 取组件与布局（`Btn`、`Card`、`Chip`、`Overlay`、`Tiles`、`Stack`、`Row`、`CodeView` 等），样式只用 `var(--…)` 令牌（`docs/05-样式约定.md`），界面规则同阶段（`check:ui`：不写固定定位、像素高度、vh / vw、@media）。
- 模块顶层不调用平台函数（加载顺序原因），要用的都放在组件函数里。

## 五、引用规则

- 组件只 import `#kernel/server/schema.js`、`#kernel/client/index.js`、`#kernel/test-utils/…` 与自己目录里的文件；不 import 别的组件的内部文件、不碰阶段源码、不自己 `fetch` AI 接口。
- 阶段视图要读组件数据：`useComponent('<cid>')`。确需复用组件的界面件时，`.jsx` 视图可 import `@lesson-components/<cid>/index.js`（这门课的组件目录）；Node 侧（`server.js`、`stage.config.js`）不 import 课程组件——平台没有按课程映射的 `#lesson-components`。
- 课程组件之间不互相 import；要共享数据经 `data` / 事件。

## 七、做完的检查

- `npm run check:lesson`（第 13 项"课程组件"）：`component.config.js` 的 id 与目录一致、有 `label`；id 不重名不保留；`server.js` 导出 `register`、事件前缀是自己的 id；`client.jsx` 过界面规则、只用上表的槽位；缺 `README.md`、没在 `components` 里打开 → 警告。
- `npm run simulate` 不需要为组件改动（组件事件不参与门槛）。
- 范本：`examples/primitives-tour/components/gallery/`（作品墙：教师顶栏按钮 → 弹层网格 → 点一张全班放大；学生页一行提示；个人报告一节）。
