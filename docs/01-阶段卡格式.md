## 第二部分 · 教材分析、学情分析、教学目标、重难点

有教案：写'见文末"附：原教案"'或原稿路径；没有：按教师三句话写三行（教学目标 / 学情 / 教材）。只额外要求两点：

- **学情挑战中写清设备与节奏差异**（反诈课的三条：人数与设备不一要求高并发可靠；认知节奏差异要求"操作指引 / 失败诊断 / 个性化反馈"三层支撑；教师不替学生操作）
- **教学目标写到"学生在平台上能做出什么"**，而不是只写"理解 / 掌握"

## 第三部分 · 师生角色约定（内核原则，只需确认）

- 教师：节奏指挥者、关键提问者、分享策展人。**教师全程不操作学生设备。**
- 平台：数据呈现者、失败反馈者、集体战绩可视化者、报告生成者。**界面只呈现数据和操作入口，不出现教学提示文字。**
- 学生：在自己设备上独立操作，回看历史阶段只读。

## 第四部分 · 教学过程 · 阶段卡

每个阶段一张卡。**段 0 课前登录和最后一段谢幕由内核提供，教师只确认要不要个人报告。** 中间阶段逐张写。

### 阶段卡模板

```
### 段 N · <阶段名>（<起止时间>）

> 核心教学事件：一句话，学生在这段要"撞上"什么。

**A 展示**
- 大屏投什么：
- 学生屏幕看什么：
- 教师按什么按钮、在什么时点按（想在大屏上现场敲代码演示、再发给学生当起点，code / data-analysis 自带，不用写）：
- 教师是否需要看某个学生的实时画面 / 挑人上来讲：

**B 学生做什么**
- 动作是什么（选、拖、写、跑、提交）：
- 有几步，步与步之间是否有先后：
- 提交后能不能改：
- 做不对时平台给什么反馈（只说"为什么没成功"，不说"应该怎么做"）：

**C 采集**
- 记什么字段：
- 记到人、记到组、还是只记到班：
- 课后要不要回看 / 进个人报告：

**D 统计**
- 教师统计视图看哪几列：
- 什么情况要提醒教师走过去（例如连续两次失败、长时间不提交）：
- 要不要排行 / 推荐分享：

**E 推进条件**（AI 按写卡规则 5 定，不问教师）
- 教师按"下一段"时要满足：
- 不满足时：软提示（可强制推）/ 硬拦截：

**匹配原语**（AI 填，六选一，写英文名）：vote（投票）/ quiz（小测验）/ free-text（写一段话）/ code（写程序过测试）/ data-analysis（数据分析）/ 无（自写）

**页面样式**（AI 填，教师确认；五选一，样子见 docs/04-页面模板图鉴.md）：focus 聚焦一件事 / split 左右两栏 / tiles 磁贴墙 / table 表格 + 侧栏 / stack 自上而下几步

**限制说明**（仅代码类阶段，AI 照写卡规则 6 写，不问教师）：
- 测试内容学生可见：
- 测试用例来源（教师给的例子 + 正常 / 边界 / 反例）：
- 本段是否用到 turtle / tkinter / pygame 等窗口类库（不可用，需改题）：
- 题目与初始代码是否会引导学生输入真名（不得）：
- 页面内容按磁贴摆放，不指定像素位置：
```

### 写卡规则

1. **A 栏先写大屏再写学生屏**，两者不同才是互动课；两者相同说明这段不需要平台，写"本段不用平台"即可
2. **B 栏动作要能被平台记录**。"讨论""思考"不是平台动作；"提交一个选择""跑一次代码"才是
3. **C 栏只写字段名和粒度**，不写表结构。AI 会回读："我理解你要记每个人的 X、Y，对吗？"
4. **D 栏的提醒条件写具体数字**，例如"失败 2 次""3 分钟未提交"
5. **E 栏与其它机制由 AI 定，不问教师**：按 `skills/01-教学设计.md` 第 4 步 d 的规则与默认值写，记"由 AI 默认"。门槛只有两档：下一段要用到这一段每个人的结果（例：选了阵营才能调参、交了作品才能互评）→"全部在线学生<完成动作>；没到时一键继续"；其它一律无门槛。提交后能不能改、小测什么时候看对错、提醒分钟数同样取默认。只有内容类（写卡缺的补问、原语不够时怎么做、AI 助手要不要）才问教师；教师想改机制在 05 环试课时改
6. **代码类阶段（学生写 Python、跑测试、搭小网站）必须写"限制说明"**，AI 照下面几条写进卡，不逐条问教师（02 环回读时只带一句"写程序的段按平台的四条约定做"）：
   - **测试内容学生可见**：用来检查学生代码的测试会随页面发到学生设备上，学生能看到；不要把它当作保密的判分依据
   - **测试用例来源**：阶段卡里教师给的例子必须有，另补正常、边界、反例各至少一条；参考答案要能通过全部测试（`check:lesson` 会验证，写法见 `skills/参考/写测试.md`）
   - **`turtle` / `tkinter` / `pygame` 不可用**：代码在浏览器里运行，没有图形窗口；要画图改用 matplotlib，要做网页改用 Flask + 模拟浏览器
   - **题目与初始代码不要引导学生输入真名**：学生的代码、输出和报错会进记录、镜像、分享与个人报告，记录不得含身份信息
   - **页面内容按磁贴摆放，不指定像素位置**：平台固定页面框架（顶栏、标题区、内容区、底部操作条），内容只能放进所选"页面样式"的区域，不写"放在左上角 300 像素宽"之类的要求
7. **"页面样式"只能五选一**：focus（一道题、一段文字、一张图）/ split（代码 + 输出、题目 + 作答）/ tiles（多张卡片：报告、名单、选项墙）/ table（表格 + 侧栏，通常只用于教师统计）/ stack（读题 → 作答 → 结果自上而下）；教师不确定时由 AI 按 A、B 栏推荐。**选择指引**：B 栏只有一件事 → focus；要两块对照着看 → split；很多张同类卡片 → tiles；有先后顺序的几步 → stack；教师统计视图固定 table，不用选。每种样式的三种屏幕截图与"教师说法 → 模板"对照表见 [docs/04-页面模板图鉴.md](04-页面模板图鉴.md)

## 第五部分 · 评价设计

| 评价类型 | 教师回答 | 触发的组件 |
|---|---|---|
| 过程性评价 | 要不要？看哪些维度（参与度 / 熟练度 / 产出 / 协作 / 迁移）？ | 采集点汇总 + 统计视图列 |
| 结果性评价 | 要不要个人报告？报告里要不要与全班中位数对比？ | 个人报告（`report`） |
| 课后使用 | 要不要学生扫码回看？要不要导出数据？ | 报告推送 + 导出 CSV（都在 `report`） |

## 第六部分 · 教师说法 → 组件对照表（AI 用，教师不用看）

组件在 `lesson.config.js` 的 `components` 里打开，写法与上课时出现在哪里见 `template/components/README.md`。

| 教师在阶段卡里的说法 | 启用组件 |
|---|---|
| 看某个学生正在做什么 / 投一个学生的屏 | `mirror`（镜像学生画面） |
| 挑做得好的上来讲 / 展示某人的方案 | `share`：邀请回答 |
| 让做得好的帮做得差的 / 互相诊断 | `share`：邀请互助（自动配匿名困境生） |
| 平台帮我挑人 / 谁值得分享 | `share`：推荐分享（各段的 `recommend`） |
| 记每个人的尝试 / 用时 / 是否完成 | 不是组件：各段 C 栏的采集字段（原语自带，自写段写 `collect`） |
| 课后每人一份报告 / 扫码看 | `report`（个人报告） |
| 导出数据 | `report`：谢幕页"导出 CSV" |
| 某一段就是写一段话交上来 / 开放题 | 不是组件：`free-text` 原语 |
| 课上随时让学生写一句话交上来（不属于哪一段） | `inbox`（收件箱） |
| 学生写一段 Python 跑一下 / 看输出和报错 | `sandbox`：`code` 原语，或自写段 `<PyRunner>`（示例 `python-intro/01-hello`） |
| 用 pandas 处理数据 / 画个图（中文标签） | `sandbox`：`data-analysis` 原语，或 `packages` + `files` + `<PyRunner>`（示例 `02-data`） |
| 写几个函数过测试 / 全对才能交 | `sandbox`：`code` 原语的 `tests`，或 `<PyRunner>` 的测试按钮（示例 `03-tests`；测试内容学生可见） |
| 写路由 / 搭一个小网站 / 在浏览器里看效果 | `sandbox`：`flask: true` + `<PyRunner>` + `<WebSim>`（示例 `04-site`） |
| 学生卡住了能问 AI 要提示（只给提示不给答案）/ 看谁求助多还没做出来 | `coach`（AI 助手）：`components` 加 `'coach'`，要开的段在 `stage.config.js` 顶层写 `coach: true`；工作台 平台 → 设置 的"AI 接口"一节要填好（局域网里的模型服务也行） |
| 给每人一句 AI 点评 | 做成自写段，服务端调平台统一的 AI 接口（`docs/02` §三"调 AI"）；工作台 平台 → 设置 的"AI 接口"一节填好（可填局域网模型）；没配 AI 时这段要能照常上 |
| 表扬 / 颁奖 / 称号 | 底座不内置；记为"后续定制"，在个人报告基础上加 |

## 第七部分 · 门：本设计何时算"可以进入平台规格"

- 所有中间阶段的 A–D 四栏填满，E 栏已按写卡规则 5 写好
- 每张卡的"匹配原语"已填，"无（自写）"的阶段不超过总数一半（超过说明这节课离底座太远，先谈）
- 评价设计三行已写（教案写明的照教案，否则由 AI 默认）
- 教师确认过阶段卡的回读（内容对）
