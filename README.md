# 课堂互动平台 · 教师使用手册

这台平台装在教师电脑上：教师电脑投影教师端，学生用平板的浏览器加入课堂。学生不用安装任何应用。

日常操作都在**管理台**里完成：双击平台文件夹里的 `管理台.command`（Mac）或 `管理台.bat`（Windows），浏览器会自动打开管理台页面，在页面上点按钮即可。不需要输入命令，也不需要手动修改配置文件。

---

## 一、需要准备什么

- 平台的**发布包**：一个名为 `课堂互动平台-v<版本号>.zip` 的压缩包（向发给你平台的同事要，或从发布页下载）
- 一台 Mac 或 Windows 电脑作为教师机（Linux 也可以，见文末"开发者命令"）
- Node.js 22 或 24（长期支持版）：在 [Node.js 官网](https://nodejs.org/zh-cn) 下载安装包，双击安装即可
- 教师电脑和学生平板连在同一个 WiFi 上

---

## 二、第一次使用

一共三步：**下载发布包 → 解压 → 双击管理台**。

1. **解压发布包**：把 `课堂互动平台-v<版本号>.zip` 解压到"桌面"或"文稿 / 文档"文件夹（Mac 双击 zip 即可；Windows 右键 zip →"全部解压缩"），得到一个 `课堂互动平台` 文件夹，这就是**平台文件夹**。不要直接在压缩包里双击运行；以后做的课、课堂数据和备份都存在这个文件夹里，别删掉它。
2. **双击启动**：打开平台文件夹，Mac 双击 `管理台.command`，Windows 双击 `管理台.bat`。
   - 会打开一个窗口（Mac 是"终端"，Windows 是黑色的命令行窗口）。第一次会自动安装平台需要的组件，需要联网，等几分钟。
   - Mac 第一次双击如果提示"无法打开"或"无法验证开发者"：先点"完成"（或"取消"）关掉提示，打开"系统设置 → 隐私与安全性"，往下找到关于"管理台.command"的提示，点"仍要打开"，再输入电脑密码确认。之后就可以直接双击了。（macOS 15 起，右键"打开"的老办法已经不管用。）
   - Windows 第一次双击如果出现蓝色的"Windows 已保护你的电脑"：点"更多信息"，再点"仍要运行"。
   - 如果窗口里提示"请先安装 Node.js"，按提示装好 Node.js 后再双击一次。
3. **浏览器自动打开管理台**。如果没有自动打开，把窗口里显示的地址（形如 `http://127.0.0.1:3900/?t=…`）复制到浏览器里打开。
4. **接下来按首页的向导做**。平台还没启动时，首页是一张向导：左边一列是步骤（做完的打 ✓ 变灰，当前这一步是深色圆点、粗字），右边就是这一步要填的东西，**直接在这里填，不用去别的页面**。课程不需要 Python 时少一步，一共四步：
   1. **设置教师密码**：输入密码（至少 6 位，登录教师端时用），点"保存并继续"。太短会在输入框下面用红字提示。
   2. **选择课程**：下拉框里只显示课程名（例如"Python 入门"），选好点"就用这门 · 继续"。新装好的平台已经默认选了"示例课"，这一步会直接打勾，显示"当前：《示例课》· 2 个环节 · 换一门"。自己（或让 AI）做的课程显示为"我的课程（自定义）"，排在最后。如果当前的课程文件被改坏了，这一步会用红字提示"这门课程的文件有错，读不出来；请让帮你生成课程的 AI 检查后再试"，下拉框会默认选好一门能用的课。
   3. **下载 Python 运行时**（只有用到"Python 沙盒"的课程才有这一步）："这门课要用 Python，需要联网下载一次（约 40 MB）"，点"开始下载"，下面有进度条；下载完自动打勾进入下一步。中途断网再点一次会接着下载。
   4. **启动平台**：点"启动平台"。第一次启动或换了课程后要等一会儿，这时显示"正在准备（第一次或换课后要一会儿）…"和一个转圈。

   左边做完的步骤可以点：点"设置教师密码"回去改密码，点"选择课程"回去换课；还没做到的步骤是灰的，点不了。窗口较窄时，左边一列会收成一行"第 N 步 / 共 M 步 · 标题"，旁边有"改前面的步骤"，点开会列出做完的步骤，点哪个就回到哪一步。

**做新课**：在管理台"课程"页新建课程（只填课名）、上传教学设计，再点"复制开场话"，把那段话贴给帮你做课的 AI 工具，它就从这门课开始做（见下面"课程页"）。

平台启动后，向导自动收起，首页变成**上课面板**（见"三、上课"）。页面最上方的状态带：没启动时只显示"● 未启动 · 完成下方步骤后启动"（在其它标签页显示"到首页按步骤启动"）；运行中显示"● 运行中 · 学生地址（点了在新标签打开）· 停止平台 / 重启平台"。

设置页每一项下面都有样例和说明，并写明"什么时候生效"：

- **教师密码**：至少 6 位，上课时只在教师电脑输入。
- **端口**：默认 80，学生地址最短（不带数字，例如 `http://192.168.1.100/`），一般不用改；被别的程序占用时换 3001 或 8080。
- **课程**：同上面"选择课程"一步；下拉框每项只显示课程名，鼠标停在上面能看到所在目录。
- **Python 运行时**（设置页最后一节）：显示"已就绪 / 未下载 / 当前课程不需要"，按钮"检查并补全"（已下载的文件不会重复下载）。
- **AI 接口**（可以先留空）：接口地址形如 `https://api.openai.com/v1`（OpenAI 兼容接口，国内常见服务商也用这个格式）；密钥是以 `sk-` 开头的一串，只保存在本机；模型名照服务商给的填，例如 `gpt-4o-mini`。

> **请记住：那个窗口开着，平台才开着。** 上课期间不要关闭它（可以最小化）。关闭窗口 = 关闭管理台和平台。

管理台五个标签页：**首页**（上课前看这里）、**课程**（新建、上传教学设计、切换）、**设置**（密码、端口、课程、AI 接口）、**名单**（导入班级名单，学生只能从名单里选名字）、**数据**（备份、恢复、清空上一节课的数据）。每块内容标题下都有一行灰字说明用途，每个按钮把鼠标停在上面会显示它会做什么。

**课程页**：最上面是"新建课程"（只填课名，新建后它就是当前课程）和"下载教学设计模板（Word / Markdown）"（开发者直接从代码仓库运行时没有 Word 版，只显示 Markdown 版）。下面每门课一张卡片：课名、"我的课"或"示例"、"当前"标记（下次启动平台时上的课）、环节数和做课进度（示例课显示"示例课，可直接上"；自己的课显示"做到第 N 环 · 下一步：……"或"还没开始设计"）。按钮：

- **设为当前课程**：和设置页选课程一样；平台运行中换课，重启平台后生效。
- **复制开场话**（我的课）：复制一段话，例如"我要做《闰年判断》这节课。课程目录是 lessons/……/，教学设计原稿在……。请先读 skills/SKILL.md，按它做。"，贴给 AI 工具即可。浏览器不让复制时会弹出一个已选中的文本框，自己按 Ctrl+C（Mac 按 Command+C）。
- **上传教学设计**（我的课）：可以传 Word（.docx）、PDF、Markdown（.md）或纯文本（.txt），20 MB 以内；再传一次会替换，旧的自动留一份（文件名后面加 .bak；连续上传只保留最近一份 .bak）。Word 文件会另存一份纯文本给 AI 读；显示"已保存原稿，AI 读不了 Word 时请上传 txt 或 pdf"时，把教学设计另存为 txt 或 pdf 再传。示例课不能上传。
- **打开文件夹**：在电脑上打开这门课的文件夹。
- **删除这门课**（我的课，且不是当前课程；平台正在准备时要等一会儿）：确认后移到平台文件夹的 `backups/deleted-lessons/` 里，不会直接删掉，需要时可以挪回 `lessons/`。

## 三、上课

1. **启动平台**：在首页向导最后一步点"启动平台"。第一次启动或换了课程后要等一会儿（"正在准备（第一次或换课后要一会儿）…"）。看到绿色圆点和"运行中"就好了，首页变成上课面板。
2. **投影教师端**：上课面板右边"当前课程"是平台**正在上的**那门课（在设置里换了课、还没重启时，下面会多一行"已换成《……》，重启后生效"）。点"打开教师端"（会在新标签打开），输入教师密码登录，投影到大屏。
3. **学生加入**：上课面板左边"学生打开这个地址"下面是大字的学生地址（形如 `http://192.168.1.100/`），**点地址会在新标签打开**，可以先自己看看学生看到的样子；旁边的"复制"按钮复制地址（按钮上会短暂显示"已复制 ✓"），下面是它的二维码。让学生扫码或在平板浏览器里输入，选择或输入自己的姓名加入课堂。右边"已进入 N 人"每 10 秒刷新一次。电脑有多块网卡时，其余地址折叠在"其它网卡"里，一般用大字那个；学生打不开时再试其它的。
4. **下课**：点"停止平台"，或直接关闭那个窗口。

**用 AI 改完课程再测试**：平台运行中，课程文件被改动后，上课面板顶部会出现黄条"课程文件有更新，重启后生效 · 重启并应用"。点"重启并应用"，平台会重新准备页面并启动（学生进度会保留），刷新学生 / 教师页面就能看到新内容。

上课面板底部：

- "出问题了？**查看运行记录**"：从右侧打开最近 500 行运行记录，需要时可以截图发给技术同事。
- "**更多信息**"：点开才显示 Python 运行时状态（含版本）、数据库大小、最近一次备份时间、课程所在目录。备份按钮在"数据"页。

启动失败时，页面顶部会用一句话说明原因，并给出**可以直接点的下一步按钮**：

- 没设密码 →"去设置密码"；课程读不出来 →"换一门课程"；缺 Python 运行时 →"下载 Python 运行时"
- 页面准备失败或启动时平台退出 →"查看日志"（打开最近 500 行运行记录，需要时可以截图发给技术同事）
- 上课中平台意外停止（页面顶部显示"平台意外停止"）→"查看日志"或直接"启动平台"
- 端口被占用 → 见下面"常见问题"

修改了设置（密码、端口、课程等）后，页面会提示"设置有改动，重启平台后生效"，点"立即重启平台"即可。

## 四、名单

导入名单后，学生加入时从名单里选自己的名字，不会出现错字或重名。不导入名单时，学生自己输入姓名。

### 名单文件怎么准备

- 一行一个学生姓名
- 第一行可以是表头"姓名"，会被自动跳过
- 用 Excel 编辑的话，第一列放姓名，然后"另存为 CSV"；后面几列（学号等）会被忽略
- 也可以用纯文本文件（.txt），一行一个名字
- 同一个名字只保留一次；超过 16 个字的名字会被跳过

### 怎么导入

在管理台"名单"页：文本框上方有样例（一行一个名字）。把名单粘贴到文本框里（从 Excel 复制一列直接粘贴即可），或点"选择文件"选名单文件 → 点"预览名单"，页面显示解析出几个人和前 20 个名字，并问"看起来对吗？"→ 对就点"对，导入这份名单"，不对就点"不对，回去修改"。

平台运行中导入，学生端马上能看到名单；平台没运行时也可以导入，下次启动自动生效。名单保存后，重启平台不需要重新导入。也可以在教师端课前页面导入名单。

### 清空名单与解锁平板

- **清空名单**：删除名单，回到学生自由输入姓名的方式。
- **重置设备绑定**：学生第一次选好名字后，这台平板就和这个名字对应起来，防止别人冒用。如果学生换了平板、或者点错了名字，用它解除所有对应关系，学生重新打开页面再选一次即可。

## 五、备份、恢复、重置

都在管理台"数据"页，三个操作各有一句"什么时候用"。

**备份**：点"备份当前数据"，把当前课堂数据存一份。平台运行中也可以放心备份。备份文件保存在平台文件夹的 `backups` 文件夹，名字里带日期和时间，例如 `classroom_20260924_101500.db`。建议每节课下课后备份一次。备份列表里可以"下载"单个备份，拷到别处保存。

**恢复**：先停止平台，然后在备份列表里选一份点"恢复这份"，课堂数据就回到那个时刻。列表每一项写明"日期 · 大小 · 手动备份 / 恢复前自动快照 / 重置前自动快照"。

- 恢复之前，管理台会自动把当前数据再存一份（文件名以 `pre_restore_` 开头），万一恢复错了还能换回来。
- 恢复之后，学生下次进入会回到登录页，重新进入即可。

**重置**：换一个班、或者开始新一节课之前，清掉上一节课的数据。

- 平台**运行中**重置：清除学生记录、平板对应关系和各环节里学生做的内容，课堂回到第一个环节；**名单保留**。所有学生平板会回到登录页。
- 平台**没运行**时重置：删除整个课堂数据，**名单也会一起清除**，下次需要重新导入。
- 无论哪种，重置之前都会自动存一份（文件名以 `pre_reset_` 开头），需要时可以在备份列表里恢复。

恢复、重置、清空名单这类操作都会先弹出确认框，按钮上写明后果，确认后才执行。

## 六、常见问题

**提示"端口需要管理员权限"？**
Mac 和 Windows 一般不会遇到。Linux 上 1024 以下的端口（包括 80）需要管理员权限：到"设置"里把端口改成 3001 或 8080，保存后重启平台。这时学生的地址会带上端口号（例如 `http://192.168.1.100:8080/`），以管理台状态带显示的为准。

**启动时提示端口被占用？**
管理台会查出是谁占着端口，给出三种提示之一：

- "端口 80 上有一个之前没关掉的平台（进程 12345）"：通常是之前用命令行或别的窗口启动、没关掉的本平台。点"停止它并启动"，确认后管理台会结束那个旧平台再启动（正在连接那个旧平台的学生会断开，刷新页面即可重新进入）；也可以点"改用 ……"换个端口。管理台只会结束判定为**本平台文件夹**里的平台，别的程序不会动；判定不是本平台时会提示"这个进程不是本平台，管理台不能结束它"，这时改用别的端口或关掉那个程序。
- "端口 80 被「某某程序」占用，可以改用 3001……"：点"改用 3001"（数字以页面为准），管理台会把端口改好并直接启动，学生地址会跟着变；或者关掉那个程序后点"已关掉，重试"。
- "端口 80 已被别的程序占用……"（查不出是哪个程序时）：同样可以点"改用 ……"或关掉那个程序后点"已关掉，重试"。

**学生平板连不上？**
- 确认平板和教师电脑连的是同一个 WiFi（有些学校的访客网络彼此不通）
- 确认地址输对了，是管理台状态带显示的"学生"地址
- 防火墙：Mac 可能弹出"是否允许接受网络连接"，请点"允许"。Windows 第一次启动平台时会询问是否允许 Node.js 访问网络，请把"专用网络"和"公用网络"**两项都勾上**再点"允许"——学校 WiFi 常被 Windows 识别为"公用网络"，只勾"专用网络"时学生会连不上。如果当时只勾了一项，到"Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙"里，给 Node.js 把两项都勾上
- 在教师电脑上用浏览器打开同一个地址试试，如果教师电脑也打不开，说明平台没有启动成功，看状态带里的出错说明

**忘记教师密码？**
在管理台"设置"页点"显示"就能看到当前密码，也可以直接改一个新的，点"保存设置"后重启平台。

**不小心关了那个窗口？**
平台会跟着停止。重新双击 `管理台.command` / `管理台.bat`，点"启动"即可，数据都还在。

**课中需要重启平台，学生的进度会丢吗？**
不会。重启后课堂回到重启前所在的环节，学生做过的内容都保留，学生刷新页面就能继续。只有在重启前修改了课程本身（例如增删了环节），课堂才会从头开始。

**双击后提示"已经有一个管理台窗口在运行"？**
同一个平台文件夹同时只能开一个管理台。找到已经开着的那个窗口继续用，或者把提示里的地址复制到浏览器打开。如果确定没有别的管理台窗口（例如电脑刚死机重启过），按提示删除平台文件夹里的 `.manage.lock` 文件后再双击。

**浏览器里的管理台页面提示"链接已失效"？**
每次双击启动都会生成新的管理台地址。回到那个窗口，复制里面显示的地址重新打开即可。

**平板上显示不全？**
平台适配各种屏幕尺寸，横屏竖屏都能用；建议平板横屏使用。

## 附：开发者命令

以下命令在平台文件夹的终端里运行，教师日常不需要。

开发者也可以不用发布包，直接 `git clone` 平台的开发仓库：仓库里的 `template/` 就是平台文件夹（命令都在 `template/` 里执行）。在仓库根运行 `npm run pack:release`，生成发给教师的发布包 `release/课堂互动平台-v<版本号>.zip`（需要系统有 `zip`；有 `pandoc` 时包里多一份 Word 版教学设计模板）。

```
npm install              # 安装依赖（双击入口会自动做）
npm run manage           # 打开管理台（等同于双击入口；Linux 教师机用这个）
npm run dev              # 开发模式：Vite 热更新，代理到 3001 端口的服务端
npm run server           # 只启动服务端（读 .env）
npm run build            # 构建前端到 dist/
npm test                 # 全部自动测试
```

### 给 AI 的三条命令

**用 AI 做课，先完整读 `skills/SKILL.md`**：它是从教学设计到上课的整套流程，会按顺序调用下面三条命令，并把每门课的设计、规格、进度都放在 `lessons/<id>/` 里。

帮教师生成课程的 AI 按这个顺序用（教师不用碰终端：管理台启动前会自动检查，设置页也有"检查课程"按钮，结果可以"复制给 AI"）：

- `npm run new:lesson -- --id <id> --title <课名>`：在 `lessons/<id>/` 生成一门空课（`lesson.config.js`、`stages/`、`README.md`），并把 `.env` 的 `LESSON_CONFIG` 指向它（`--dir` 换目录，`--no-env` 不改 `.env`）。
- `npm run new:stage -- --lesson <lesson.config 路径> --id <id> --label <阶段名> --primitive <vote|quiz|free-text|code|data-analysis|none> [--after <已有阶段目录>]`：生成 `NN-<id>/` 阶段骨架（阶段卡 `STAGE.md` + 原语配置，或 `none` 的五个自写文件与测试）并写进课程的 `stages`，然后自动检查一遍；按阶段卡把 `TODO：` 占位填完。
- `npm run check:lesson [lesson.config 路径]`：检查课程写得对不对，每条给出 `文件:行`、一句话原因和"→ 怎么改"；有错误退出 1，`--json` 输出结构化结果。改到只剩"通过"（最多有警告）再交给教师启动。
- `npm run build:lesson -- [lesson.config 路径]`：把一门课的前端打包到系统临时目录，只为确认学生页能打开，不动管理台用的 `dist/`；末行"通过：页面能打包"或"打包失败"（退出 1），找不到配置退出 2。

- 配置保存在 `.env`（管理台自动生成与维护，不进版本库）；可选项见 `.env.example`。
- 换课程：管理台"设置"里选课程，会写入 `.env` 的 `LESSON_CONFIG`；项目根目录的 `lesson.config.js` 留给开发调试用。
- 平台输出记录在 `data/logs/server.log`（超过 5 MB 自动换新文件，旧的保留一份为 `server.log.1`）。
- `MANAGE_PORT=3920 npm run manage`：管理台改从 3920 起找空闲端口（默认 3900–3909），测试与本地验证用。
- "停止它并启动"如何判定"本平台"：占端口进程命令行里的第一个非选项参数就是脚本（其后不能再有参数）；脚本是绝对路径时必须正好是本平台文件夹下的 `kernel/server/index.js`，是相对路径时按进程工作目录解析后等于它（Mac / Linux 用 `lsof` 与 `ps` / `/proc` 查）。Windows 用一次 PowerShell（`Get-NetTCPConnection` + `Get-CimInstance Win32_Process`）查，拿不到别的进程的工作目录，只认绝对路径（管理台自己启动平台时就用绝对路径）；用 `npm run server` 启动的旧平台在 Windows 上会显示为"被「node.exe」占用"。
