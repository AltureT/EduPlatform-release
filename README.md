# 班迹

班迹（课堂互动平台）装在老师电脑上：老师投大屏，学生用平板加入；课由 AI 帮你做。

## 开始（三步）

1. 下载：发布页最新版本下面的 `EduPlatform-v<版本号>.zip`（国内用 [Gitee 那页](https://gitee.com/alture/EduPlatform-release/releases)，也可以用 [GitHub 那页](https://github.com/AltureT/EduPlatform-release/releases)）。
2. 解压到一个固定位置（例如 文稿/班迹），以后的课和课堂数据都存在这个文件夹里。
3. 双击"班迹工作台"（Mac 是 `.command`，Windows 是 `.bat`）；第一次会问要不要自动下载 Node，回车即可。

Mac 提示"无法打开"时到"系统设置 → 隐私与安全性"点"仍要打开"；Windows 出现蓝色提示时点"更多信息"再点"仍要运行"。

之后一切都在工作台里：照左边五步做——新建课程 → 上传教案 → 用 AI 做课 → 上课准备 → 启动上课。每一块末尾的"详细说明"点开有更长的说明。

## 上课时

- 第 5 步点"启动平台"，再点"打开教师端"投大屏；学生在平板浏览器输入大屏上的地址或扫码。
- 教师端底部三个视图：演示（和学生看到的一样，可以操作）、统计（全班）、明细（每个学生）。
- 想看某个学生的屏幕点"镜像"。
- 双击后弹出的那个窗口开着平台才开着，上课时别关（可以最小化）。

## 课后

- 数据：工作台"数据"页备份、恢复、重置这门课。
- 升级：工作台"平台"页点"检查更新"再点"下载并更新"；课程、数据、设置都不会丢。

## 常见问题

- 学生打不开地址 → 确认在同一个 WiFi，Windows 防火墙询问时两项都勾上；还不行换"其它网卡"里的地址试试。
- 平台没启动成功 → 看工作台页面上方的提示，按给出的按钮做；再不行到"平台"页点"查看运行记录"截图给技术同事。
- 密码忘了 → 工作台第 4 步点"改密码"重新设一个，"保存设置"后重启平台。
- 换了课程没生效 → 点"重启平台"。
- Python 下载不动 → 让同事把运行时压缩包放进平台文件夹里的 vendor 文件夹，再点一次下载。
- 想回到旧版本 → 关掉工作台窗口，重新解压旧版本覆盖平台文件夹。
