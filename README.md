# 课堂互动平台 · 教师使用手册

这台平台装在教师电脑上：教师电脑投影教师端，学生用平板的浏览器加入课堂。学生不用安装任何应用。

日常操作都在**管理台**里完成：双击平台文件夹里的 `管理台.command`（Mac）或 `管理台.bat`（Windows），浏览器会自动打开管理台页面，在页面上点按钮即可。不需要输入命令，也不需要手动修改配置文件。

---

## 一、需要准备什么

- 平台的**发布包**：从发布页下载最新版本下面的 `EduPlatform-v<版本号>.zip`。国内请用 Gitee 发布页 https://gitee.com/alture/EduPlatform-release/releases （快）；也可以用 GitHub 发布页 https://github.com/AltureT/EduPlatform-release/releases 。两边内容一样。也可以向发给你平台的同事要，同事给的可能叫 `课堂互动平台-v<版本号>.zip`，内容也一样
- 一台 Mac 或 Windows 电脑作为教师机（Linux 也可以，见文末"开发者命令"）
- Node.js 不用自己装：第一次双击管理台时，窗口里会问要不要自动下载（约 50 MB，装在平台文件夹里，不改动系统），按回车即可。电脑上已经装了 22 或 24 版的会直接用。
- 教师电脑和学生平板连在同一个 WiFi 上

---

## 二、第一次使用

一共三步：**下载发布包 → 解压 → 双击管理台**。

1. **解压发布包**：把下载到的 zip 解压到"桌面"或"文稿 / 文档"文件夹（Mac 双击 zip 即可；Windows 右键 zip →"全部解压缩"），得到一个 `课堂互动平台` 文件夹，这就是**平台文件夹**。不要直接在压缩包里双击运行；以后做的课、课堂数据和备份都存在这个文件夹里，别删掉它。
2. **双击启动**：打开平台文件夹，Mac 双击 `管理台.command`，Windows 双击 `管理台.bat`。
   - 会打开一个窗口（Mac 是"终端"，Windows 是黑色的命令行窗口）。第一次会自动安装平台需要的组件，需要联网，等几分钟。装不上时窗口里会显示"换国内源再试一次…"，自动换国内的下载源再装一次；还不行就检查网络，或者让同事把他平台文件夹里的整个 `node_modules` 文件夹拷给你，放进你的平台文件夹后再双击。
   - Mac 第一次双击如果提示"无法打开"或"无法验证开发者"：先点"完成"（或"取消"）关掉提示，打开"系统设置 → 隐私与安全性"，往下找到关于"管理台.command"的提示，点"仍要打开"，再输入电脑密码确认。之后就可以直接双击了。（macOS 15 起，右键"打开"的老办法已经不管用。）
   - Windows 第一次双击如果出现蓝色的"Windows 已保护你的电脑"：点"更多信息"，再点"仍要运行"。
   - 窗口里问"要不要自动下载 Node.js"时按回车；输入 n 就要自己装好再双击。
3. **浏览器自动打开管理台**。如果没有自动打开，把窗口里显示的地址（形如 `http://127.0.0.1:3900/?t=…`）复制到浏览器里打开。
4. **接下来照左边的五步做**。管理台的样子：
   - **最上面一条**：左边"当前课程"下拉框（只列你自己的课，选一门就换成它）和"新建"按钮；还没有课时这里显示"还没有课程 · 先新建一门"。右边是平台状态（"未启动 / 正在启动… / 运行中"），运行中时旁边是学生地址（点了在新标签打开）和"停止平台""重启平台"。
   - **左边一列五步**：① 新建课程 → ② 上传教案 → ③ 用 AI 做课 → ④ 上课准备 → ⑤ 启动上课。做完的步骤打 ✓，当前该做的那一步左边有一条蓝色竖线、字加粗，每步下面一行小字写着这一步的情况（例如"《闰年判断》""还没设密码""运行中"）。**哪一步都能点进去看、回去改**，没做到的也能先点开看看。五步下面还有"数据"（备份、恢复、重置）和"平台"（版本更新、重新构建页面、运行记录）。窗口较窄时，这一列变成页面上方一条可以左右滑动的步骤条。
   - 打开管理台时直接显示当前该做的那一步。

   各步要做的事：
   1. **新建课程**：填课名，点"新建并开始"。新建的课自动成为当前课程，页面跳到第 2 步。下面"我的课程"列出你所有的课（见下面"我的课程"）。
   2. **上传教案**（可以跳过）：标题是"《课名》的教案"。有现成的 Word / PDF / 文本就点"上传教案"传上来，AI 会先读它；没有就点"没有教案，跳过 → 去做课"。传好后提示"……，接着做第 3 步"，按钮变成"接着做第 3 步 →"。
   3. **用 AI 做课**：见下面"做新课"。
   4. **上课准备**：一页从上到下几节——**教师密码**（已设时显示"✓ 已设置 · 改密码"，点"改密码"才出输入框）、**端口**、**Python 运行时**（只有这门课用到 Python 才有这一节）、**《课名》的名单**（见"四、名单"）、**AI 接口**（下面折叠着"备用 AI 接口（可选）"）。密码、端口、AI 接口填好后点页尾的"保存设置"。
   5. **启动上课**：标题"上《课名》"，下面四行提醒：教师密码、课程检查、Python 运行时（需要时）、名单——没做好的那行带一个按钮（"去设置""查看""去下载""导入名单"），**只提醒，不拦着**。点绿色大按钮"启动平台"。第一次启动或换了课程后要等一会儿，这时显示"正在准备（第一次或换课后要一会儿）…"和一个转圈。

   第 4 步各节：
   - **教师密码**：至少 6 位，登录教师端时用，上课时只在教师电脑输入。太短会在输入框下面用红字提示。
   - **端口**：默认 80，学生地址最短（不带数字，例如 `http://192.168.1.100/`），一般不用改；被别的程序占用时换 3001 或 8080。
   - **Python 运行时**："这门课要用 Python，需要联网下载一次（约 40 MB）"，点"开始下载"，下面有进度条；中途断网再点一次会接着下载。下载时先从国内镜像（Gitee）下整个压缩包，不通再试 GitHub，最后逐个文件下载，进度条上方会写"正在从国内镜像下载…"之类。下好后显示"已就绪"，按钮变成"检查并补全"（已下载的文件不会重复下载）。都下不动时，可以让同事把运行时压缩包 `EduPlatform-runtime-v314.0.7.zip`（在 Gitee 发布页的 `runtime-v314.0.7` 下面，或者同事电脑上拷的）拷给你，放进平台文件夹里的 `vendor` 文件夹（没有就新建一个），再点一次，不用联网就能装好。学校或同事在局域网里放了一份运行时压缩包时，可以到"平台"页的"下载源（高级）"里填它的地址。
   - **AI 接口**（课程里用到 AI 时才需要；没有可留空）：接口地址形如 `https://api.openai.com/v1`（OpenAI 兼容接口，国内常见服务商也用这个格式）；密钥是以 `sk-` 开头的一串，只保存在本机，页面只显示末 4 位；模型名照服务商给的填，例如 `gpt-4o-mini`，也可以点"获取模型"从列表里选。学生的程序、运行结果和提问会发到这个地址（不含姓名）。也可以填局域网里自己电脑上的模型服务，例如 `http://192.168.1.20:11434/v1`（Ollama），这时密钥留空。
   - **备用 AI 接口（可选）**：点开折叠，再填一组地址、密钥、模型名（最好是另一家服务商）。上课时主接口超时或出错，平台会自动改用这一组，学生不会察觉；教师端统计视图右侧"求助"一行会多出"备用线路"几个字，把鼠标停在上面能看到主接口从几点起不可用。主接口恢复后，一分钟内会自动换回来。
   - **测一下**：两组接口下面各有一个"测一下"按钮，用框里填的内容发一句最短的话，旁边显示"通了 · 1.2 秒"或"没通：密钥不对"（密钥框留空时用已保存的密钥）。不用先保存，平台开着也能测；上课前点一下最放心。

**做新课**：在第 1 步新建课程（只填课名），第 2 步传教案（可以跳过），然后到第 3 步"**用 AI 做课**"。这一页标题是"用 AI 做《课名》"，下面一句写着这门课做到哪了（还没开始是"照这三步，把这门课交给 AI 来做"，做到一半是"AI 做到：……。要继续，打开开发工具、贴开场话就行"）。三步：

1. **打开 AI 开发工具**：用你平时用的那个（Claude Code、Trae、Cursor 这类能读写文件、能运行命令的都可以）。
2. **在开发工具里打开平台文件夹（不是这门课的文件夹）**：页面上显示平台文件夹在电脑上的位置；"复制位置"把它复制下来，"打开文件夹"在电脑上打开它（可以把它拖进开发工具）。
3. **复制开场话，贴给 AI**：点"复制开场话"，复制一段话，例如"我要做《闰年判断》这节课。课程目录是 lessons/……/，教学设计原稿在……。请先读 skills/SKILL.md，按它做。"，贴进开发工具的对话框发送，之后照它的问题回答就行，它会一段一段和你把课定下来。浏览器不让复制时会弹出一个已选中的文本框，自己按 Ctrl+C（Mac 按 Command+C）。

每步下面有一段说明；右上角的"**收起说明 / 展开说明**"由你决定收起还是展开，管理台会记住（还没开始做的课默认展开，做到一半的课默认收起，收起时把鼠标停在步骤标题上能看到说明）。最下面一行写着教案传了没有（"教案：已上传 ……（改 →）"或"教案：没有上传（上传 →）"，点了回到第 2 步）。

再往下是折叠的"**备课进度**"：AI 做课时会更新的一张只读表（每一段做到哪了、代码题的测试验证了没有），表下一句"要改动这节课，把想法告诉帮你做课的 AI；这张表由 AI 更新，这里不能改"和"检查课程"按钮（不用启动平台就能查这门课有没有写错的地方，结果可以"复制给 AI"）。展开还是收起，管理台也会记住。

**我的课程**（第 1 步下面的列表）：每门课一张小卡片：课名、"当前"标记、环节数和做课进度（"做到第 N 环 · 下一步：……"或"还没开始设计"）、这门课自己的数据（"名单 N 人 · 数据 M KB · 最近备份 <时间>"，还没上过、没导入过名单的课显示"还没有数据"）。卡片上的按钮：

- **继续 →**（当前课程）：去当前该做的那一步。
- **设为当前课程**（别的课）：换成这门课，和顶上的"当前课程"下拉框一样；平台运行中换课，重启平台后生效。
- **打开文件夹**：在电脑上打开这门课的文件夹。
- **删除这门课**（不是当前课程；平台正在准备时要等一会儿）：确认后移到平台文件夹的 `backups/deleted-lessons/` 里，不会直接删掉，需要时可以挪回 `lessons/`。这门课的名单、课堂数据和备份一起移过去（在那个文件夹的 `data/` 里）。

**示例课**：平台文件夹里的 `examples/` 是给 AI 照着写的范本，不是你的课，管理台的列表和下拉框里都不显示。新装的平台不默认任何课，先在第 1 步新建一门。从旧版本升级、当前课程还是示例课时，顶上下拉框里它显示为"《……》（示例，建议新建自己的课）"，换成别的课以后它就不再出现。

**平台**（左边最下面）：

- **平台版本**：显示"版本 0.x.x · 平台文件完好"。显示"有 N 处改动"说明平台自带的文件被改过（多半是 AI 做课时改错了地方）：升级时会被新版本覆盖；想恢复原样，重新解压一次发布包覆盖平台文件夹即可，课程、课堂数据和设置都不会丢。
  - **检查更新**：联网看一下有没有新版本，显示"已是最新"或"最新 v0.x.x · 有新版本"；管理台每次打开也会悄悄查一次（一天最多一次），有新版本时页面上方会多一行"有新版本 v0.x.x · 到"平台"页更新"，点它就过来。
  - **下载并更新**：有新版本时出现，点一下变成"再点一次确认"，再点才开始。更新前先停止平台；更新会自动重启管理台并重新打开页面（旧页面会提示可以关掉）；课程、课堂数据、设置、名单、备份和 Python 运行时都不动。磁盘空间不够时不会开始更新，会提示还需要大约多少空间，清理后再点。万一更新失败会自动恢复，备份在平台文件夹的 `backups/updates` 里。想退回旧版本：关掉管理台窗口，把 `backups/updates/before-v<旧版本>-<时间>/` 里的文件按原来的位置拷回平台文件夹覆盖，或者重新解压旧版本的发布包覆盖平台文件夹。更新中途被打断（关窗口、断电）时，下次打开管理台会自动恢复到更新前，页面上方会提示一句。管理台打不开时，可以让技术同事在平台文件夹里运行 `node scripts/update-platform.mjs --recover`。
- **重新构建页面**：课程改过、页面显示不对时用；先停止平台。
- **Python 运行时下载源**：折叠的"下载源（高级）"一般留空；局域网里有运行时压缩包时，把它的地址填进去点"保存下载源"，下载时最先试这个地址（保存后下次下载就用，不用重启）。
- **运行记录**：出问题时点"查看运行记录"，从右侧打开最近 500 行，可以截图发给技术同事。

> **请记住：那个窗口开着，平台才开着。** 上课期间不要关闭它（可以最小化）。关闭窗口 = 关闭管理台和平台。

每块内容标题下只有一行灰字说明用途；要看更长的说明，点这一块末尾的"详细说明"展开。每个按钮把鼠标停在上面会显示它会做什么。第 4 步的密码、端口、AI 接口都是保存后重启平台生效。

## 三、上课

1. **启动平台**：在第 5 步"启动上课"点绿色的"启动平台"。第一次启动或换了课程后要等一会儿（"正在准备（第一次或换课后要一会儿）…"）。看到绿色圆点和"运行中"就好了，这一页变成上课面板。
2. **投影教师端**：上课面板右边"当前课程"是平台**正在上的**那门课（换了课、还没重启时，下面会多一行"已换成《……》，重启后生效"）。点"打开教师端"（会在新标签打开），输入教师密码登录，投影到大屏。
3. **学生加入**：上课面板左边"学生打开这个地址"下面是大字的学生地址（形如 `http://192.168.1.100/`），**点地址会在新标签打开**，可以先自己看看学生看到的样子；旁边的"复制"按钮复制地址（按钮上会短暂显示"已复制 ✓"），下面是它的二维码。让学生扫码或在平板浏览器里输入，选择或输入自己的姓名加入课堂。右边"已进入 N 人"每 10 秒刷新一次。电脑有多块网卡时，其余地址折叠在"其它网卡"里，一般用大字那个；学生打不开时再试其它的。
4. **下课**：点"停止平台"，或直接关闭那个窗口。

**教师端怎么用**：顶部一排是这节课的各段，点哪段看哪段（往后的段要按"进入下一段"才能进）。每一段底部左边有三个按钮切换（窗口窄时显示成"演示 / 统计 / 明细"）：

- **演示视图**：这一段学生看到的那一页。老师可以直接点、写、提交给全班看（只是演示，不算进任何学生的记录）；代码题能运行，工具栏右边可以"载入参考答案""下发给学生"。
- **统计视图**：全班概况——上面一行数字（提交几人、平均分、Python 就绪几人……），下面是正确率条、投票柱状、投屏的作品；右边是求助等侧栏（AI 助手开着时，"求助"那一行可以看已答几次、暂停 / 恢复）。
- **明细表**：每个学生一行的表，点一行看他的作答；代码题、数据分析题、简答题的作答可以在这里"投到大屏"（投上去的内容显示在统计视图）。

切换按钮旁边是"镜像"（看某个学生此刻的屏幕）、"暂停更新"（只在统计视图 / 明细表出现，暂停时数字先不刷新；暂停中切到演示视图也还在，方便恢复），再往右是这一段的按钮（揭晓、显示参考答案……）。右下角是"进入下一段"。教师端和平台断开时顶部会显示"重连中…"，连上后自动消失。课前页会提示 Python 就绪人数，以及"AI 助手没配置"（没配时学生看不到求助入口）。学生页右侧可以打开"AI 助手"面板（窄屏是从底部拉出）。

**用 AI 改完课程再测试**：平台运行中，课程文件被改动后，上课面板顶部会出现黄条"课程文件有更新，重启后生效 · 重启并应用"。点"重启并应用"，平台会重新准备页面并启动（学生进度会保留），刷新学生 / 教师页面就能看到新内容。

上课面板底部：

- "出问题了？**查看运行记录**"：从右侧打开最近 500 行运行记录，需要时可以截图发给技术同事。
- "**更多信息**"：点开才显示 Python 运行时状态（含版本）、正在上的这门课的数据库大小、名单人数、最近一次备份时间、课程所在目录。备份按钮在左边的"数据"里。

启动失败时，页面顶部会用一句话说明原因，并给出**可以直接点的下一步按钮**：

- 还没有课程 →"去新建课程"；没设密码 →"去设置密码"（到第 4 步）；课程读不出来 →"换一门课程"（到第 1 步）；缺 Python 运行时 →"下载 Python 运行时"
- 页面准备失败或启动时平台退出 →"查看日志"（打开最近 500 行运行记录，需要时可以截图发给技术同事）
- 上课中平台意外停止（页面顶部显示"平台意外停止"）→"查看日志"或直接"启动平台"
- 端口被占用 → 见下面"常见问题"

平台运行中修改了设置（密码、端口、换课等）后，页面上方会提示"设置有改动，重启平台后生效"，点"立即重启平台"即可。

## 四、名单

**名单和课堂数据是每门课自己的**：每门课有自己的名单、学生记录、备份，换课不会把上一门课的学生带过来。数据存在平台文件夹的 `data/lessons/<课程 id>.sqlite`，备份在 `backups/lessons/<课程 id>/`。升级到这个版本后第一次打开管理台，原来全平台共用的那份课堂数据会自动归到它所属的那门课（页面上方提示一次"课堂数据已按课程整理"）；看不出属于哪门课的，放在"数据"里"未归类的旧数据"一节。

名单在第 4 步"上课准备"里，标题是"《课名》的名单"，**只管当前课程**；要给别的课导名单，先在顶上的"当前课程"下拉框换成那门课。这门课正在上时，导入马上生效；没在上时也可以导入，下次上这门课时自动生效。两门课要用同一个班的名单，在两门课里各导入一次即可。

导入名单后，学生加入时从名单里选自己的名字，不会出现错字或重名。不导入名单时，学生自己输入姓名。

### 名单文件怎么准备

- 一行一个学生姓名
- 第一行可以是表头"姓名"，会被自动跳过
- 用 Excel 编辑的话，第一列放姓名，然后"另存为 CSV"；后面几列（学号等）会被忽略
- 也可以用纯文本文件（.txt），一行一个名字
- 同一个名字只保留一次；超过 16 个字的名字会被跳过

### 怎么导入

在第 4 步"上课准备"的名单一节：文本框上方有样例（一行一个名字）。把名单粘贴到文本框里（从 Excel 复制一列直接粘贴即可），或点"选择文件"选名单文件 → 点"预览名单"，页面显示解析出几个人和前 20 个名字，并问"看起来对吗？"→ 对就点"对，导入这份名单"，不对就点"不对，回去修改"。

当前课正在上时导入，学生端马上能看到名单；没在上时也可以导入，下次上这门课时自动生效。名单保存后，重启平台不需要重新导入。也可以在教师端课前页面导入名单（导入到正在上的课）。

### 清空名单与解锁平板

- **清空名单**（名单一节里的按钮）：删除名单，回到学生自由输入姓名的方式。
- **重置设备绑定**（在左边"数据"页的"其它"里）：学生第一次选好名字后，这台平板就和这个名字对应起来，防止别人冒用。如果学生换了平板、或者点错了名字，用它解除所有对应关系，学生重新打开页面再选一次即可。

## 五、备份、恢复、重置

都在管理台左边的"**数据**"里，标题是"《课名》的数据"，缺省是当前课程；要看别的课，点右边的"**看别的课的数据**"，出现一个下拉框，选的课只影响这一页，不会改当前课程。三个操作各有一句说明什么时候用（"恢复"的更多说明在"详细说明"里）。

**备份**：点"备份这门课"，把这门课的课堂数据存一份。平台运行中也可以放心备份。备份文件保存在平台文件夹的 `backups/lessons/<课程 id>/` 里，名字里带日期和时间，例如 `classroom_20260924_101500.db`。建议每节课下课后备份一次。备份列表只列这门课的备份，可以"下载"单个备份，拷到别处保存。

**恢复**：在备份列表里选一份点"恢复这份"，这门课的课堂数据就回到那个时刻。这门课正在上时要先停止平台；平台在上别的课时可以直接恢复。列表每一项写明"日期 · 大小 · 手动备份 / 恢复前自动快照 / 重置前自动快照"。

- 恢复之前，管理台会自动把当前数据再存一份（文件名以 `pre_restore_` 开头），万一恢复错了还能换回来。
- 恢复之后，学生下次进入会回到登录页，重新进入即可。

**重置**：换一个班、或者开始新一节课之前，清掉上一节课的数据。

- 清除这门课的学生记录、平板对应关系和各环节里学生做的内容，课堂回到第一个环节；**名单保留**。这门课正在上时，所有学生平板会回到登录页。
- 重置之前都会自动存一份（文件名以 `pre_reset_` 开头），需要时可以在备份列表里恢复。

**未归类的旧数据**（只在有时出现）：升级前留下、看不出属于哪门课的课堂数据和旧备份。旧数据可以"备份一份"或"删除"（移到 `backups/deleted-lessons/`，不会直接删掉）；旧备份可以下载，或"恢复到"上面选中的那门课——备份原本属于另一门课时，确认框会多问一句"这份备份来自《X》，确定恢复到《Y》？"。

恢复、重置、清空名单这类操作都会先弹出确认框，按钮上写明后果，确认后才执行。

## 六、常见问题

**提示"端口需要管理员权限"？**
Mac 和 Windows 一般不会遇到。Linux 上 1024 以下的端口（包括 80）需要管理员权限：到第 4 步"上课准备"里把端口改成 3001 或 8080，保存后重启平台。这时学生的地址会带上端口号（例如 `http://192.168.1.100:8080/`），以管理台最上面显示的学生地址为准。

**启动时提示端口被占用？**
管理台会查出是谁占着端口，给出三种提示之一：

- "端口 80 上有一个之前没关掉的平台（进程 12345）"：通常是之前用命令行或别的窗口启动、没关掉的本平台。点"停止它并启动"，确认后管理台会结束那个旧平台再启动（正在连接那个旧平台的学生会断开，刷新页面即可重新进入）；也可以点"改用 ……"换个端口。管理台只会结束判定为**本平台文件夹**里的平台，别的程序不会动；判定不是本平台时会提示"这个进程不是本平台，管理台不能结束它"，这时改用别的端口或关掉那个程序。
- "端口 80 被「某某程序」占用，可以改用 3001……"：点"改用 3001"（数字以页面为准），管理台会把端口改好并直接启动，学生地址会跟着变；或者关掉那个程序后点"已关掉，重试"。
- "端口 80 已被别的程序占用……"（查不出是哪个程序时）：同样可以点"改用 ……"或关掉那个程序后点"已关掉，重试"。

**学生平板连不上？**
- 确认平板和教师电脑连的是同一个 WiFi（有些学校的访客网络彼此不通）
- 确认地址输对了，是管理台最上面显示的"学生地址"
- 防火墙：Mac 可能弹出"是否允许接受网络连接"，请点"允许"。Windows 第一次启动平台时会询问是否允许 Node.js 访问网络，请把"专用网络"和"公用网络"**两项都勾上**再点"允许"——学校 WiFi 常被 Windows 识别为"公用网络"，只勾"专用网络"时学生会连不上。如果当时只勾了一项，到"Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙"里，给 Node.js 把两项都勾上
- 在教师电脑上用浏览器打开同一个地址试试，如果教师电脑也打不开，说明平台没有启动成功，看页面上方的出错说明

**忘记教师密码？**
在第 4 步"上课准备"的教师密码一节点"改密码"，输入一个新的（点"显示"可以看到输入的内容），点页尾的"保存设置"后重启平台。

**不小心关了那个窗口？**
平台会跟着停止。重新双击 `管理台.command` / `管理台.bat`，在第 5 步点"启动平台"即可，数据都还在。

**课中需要重启平台，学生的进度会丢吗？**
不会。重启后课堂回到重启前所在的环节，学生做过的内容都保留，学生刷新页面就能继续。只有在重启前修改了课程本身（例如增删了环节），课堂才会从头开始。

**双击后提示"已经有一个管理台窗口在运行"？**
同一个平台文件夹同时只能开一个管理台。之前的管理台窗口没关、但平台已经停止时，再双击会自动关掉旧窗口换成新的（窗口里显示"检测到之前没关的管理台窗口，正在替换…"），不用管它。旧窗口正在上课时不会替换，会提示"另一个管理台窗口正在上课"：找到那个窗口继续用，或者把提示里的地址复制到浏览器打开；确实要换窗口，先在那边停止平台再双击。那个窗口正在更新平台、恢复 / 重置数据或下载运行时也不会替换，等它完成再试。如果确定没有别的管理台窗口（例如电脑刚死机重启过）还提示已在运行，按提示删除平台文件夹里的 `.manage.lock` 文件后再双击。不想自动替换的，用 `npm run manage -- --no-replace` 启动。

**浏览器里的管理台页面提示"链接已失效"？**
每次双击启动都会生成新的管理台地址。回到那个窗口，复制里面显示的地址重新打开即可。

**平板上显示不全？**
平台适配各种屏幕尺寸，横屏竖屏都能用；建议平板横屏使用。

## 附：开发者命令

以下命令在平台文件夹的终端里运行，教师日常不需要。

开发者也可以不用发布包，直接 `git clone` 平台的开发仓库：仓库里的 `template/` 就是平台文件夹（命令都在 `template/` 里执行）。在仓库根运行 `npm run pack:release`，生成发给教师的发布包 `release/课堂互动平台-v<版本号>.zip`（需要系统有 `zip`）；`npm run publish:release` 再把它发到公开发布仓库 https://github.com/AltureT/EduPlatform-release 并同步推到 Gitee 镜像 https://gitee.com/alture/EduPlatform-release （仓库内容 = 解压后的平台文件夹，Releases 里的 zip 叫 `EduPlatform-v<版本号>.zip`；Gitee 的 Release 附件要环境变量 `GITEE_TOKEN`，没有时脚本打印手动上传地址；`--no-gitee` 只发 GitHub）。Python 运行时整包：`npm run pack:runtime` 把 `template/vendor/pyodide` 打成 `release/EduPlatform-runtime-v<版本>.zip`，`npm run publish:release -- --runtime-only` 把它挂到两边的 `runtime-v<版本>` Release（`--runtime` 在发新版本时顺带做）。Gitee 推送失败时退出码 2，网络恢复后重跑 `publish:release`（内容没变）会补推 Gitee 并补建 Gitee Release；但如果 tag 已经推上 Gitee、只是建 Release 或传附件失败（或当时没设 `GITEE_TOKEN`），重跑不会再建，要按脚本打印的地址到 Gitee 网页手动上传。管理台导入运行时整包时，内核文件、包闭包的 `.whl` 与两份 lock 都按固定的 sha256 核对，`.gz` 按原文件重新生成；`wheels/` 下的 PyPI 轮子（Flask 等）只按整包自带的 manifest 校验。

`vendor/node/` 是双击入口自动下载的便携 Node（没有系统 Node 或版本低于 22 时，问过教师再装；有它就优先用它）；删掉 `vendor/node/` 就回到系统 Node。系统里没有 Node 时，终端里的命令前加 `PATH="$PWD/vendor/node/bin:$PATH"`（Windows 命令提示符先 `set "PATH=%CD%\vendor\node;%PATH%"`）。

```
npm install              # 安装依赖（双击入口会自动做；失败时会换国内源再试一次）
# 手动换国内源安装（Mac / Linux）：
#   npm_config_registry=https://registry.npmmirror.com npm_config_better_sqlite3_binary_host_mirror=https://registry.npmmirror.com/-/binary/better-sqlite3 npm install
# Windows（命令提示符）：
#   set npm_config_registry=https://registry.npmmirror.com
#   set npm_config_better_sqlite3_binary_host_mirror=https://registry.npmmirror.com/-/binary/better-sqlite3
#   npm install
npm run manage           # 打开管理台（等同于双击入口；Linux 教师机用这个）
npm run dev              # 开发模式：Vite 热更新，代理到 3001 端口的服务端
npm run server           # 只启动服务端（读 .env）
npm run build            # 构建前端到 dist/
npm test                 # 全部自动测试
npm run fetch:pyodide    # 下载 Python 运行时（同管理台里的下载按钮）：vendor/ 里的整包 → RUNTIME_ZIP_URL → Gitee 整包 → GitHub 整包 → 逐文件
npm run fetch:pyodide -- --sources   # 只列出下载来源的顺序，不下载
npm run gen:ai-entry     # 改了 scripts/lib/ai-entry.js 后重新生成各 AI 工具的入口文件（CLAUDE.md、AGENTS.md、.cursor/ 等十个，正文同源；--check 只比对）
```

发布包的 `版本.json` 带 `protected`（平台文件 → sha256，范围见 `scripts/lib/platform-files.js`）；`check:lesson` 与管理台"平台"页据它报"平台文件被改过"。开发仓库里没有 `版本.json`，不做这项检查。

### 给 AI 的三条命令

**用 AI 做课，先完整读 `skills/SKILL.md`**：它是从教学设计到上课的整套流程，会按顺序调用下面三条命令，并把每门课的设计、规格、进度都放在 `lessons/<id>/` 里。

帮教师生成课程的 AI 按这个顺序用（教师不用碰终端：管理台启动前会自动检查，第 3 步"用 AI 做课"的"备课进度"里也有"检查课程"按钮，结果可以"复制给 AI"）：

- `npm run new:lesson -- --id <id> --title <课名>`：在 `lessons/<id>/` 生成一门空课（`lesson.config.js`、`stages/`、`README.md`），并把 `.env` 的 `LESSON_CONFIG` 指向它（`--dir` 换目录，`--no-env` 不改 `.env`）。
- `npm run new:stage -- --lesson <lesson.config 路径> --id <id> --label <阶段名> --primitive <vote|quiz|free-text|code|data-analysis|none> [--after <已有阶段目录>]`：生成 `NN-<id>/` 阶段骨架（阶段卡 `STAGE.md` + 原语配置，或 `none` 的五个自写文件与测试）并写进课程的 `stages`，然后自动检查一遍；按阶段卡把 `TODO：` 占位填完。
- `npm run check:lesson [lesson.config 路径]`：检查课程写得对不对，每条给出 `文件:行`、一句话原因和"→ 怎么改"；有错误退出 1，`--json` 输出结构化结果。改到只剩"通过"（最多有警告）再交给教师启动。
- `npm run build:lesson -- [lesson.config 路径]`：把一门课的前端打包到系统临时目录，只为确认学生页能打开，不动管理台用的 `dist/`；末行"通过：页面能打包"或"打包失败"（退出 1），找不到配置退出 2。

- 配置保存在 `.env`（管理台自动生成与维护，不进版本库）；可选项见 `.env.example`。
- 换课程：管理台顶上的"当前课程"下拉框（只列 `lessons/` 下的课），会写入 `.env` 的 `LESSON_CONFIG`；项目根目录的 `lesson.config.js` 留给开发调试用（它是当前课程时下拉框里显示"我的课程（自定义）"）。新装时 `LESSON_CONFIG` 取 `lessons/` 下第一门课，没有就留空（= 还没有课程）；`examples/` 只是给 AI 照抄的范本，管理台不列它。
- 平台输出记录在 `data/logs/server.log`（超过 5 MB 自动换新文件，旧的保留一份为 `server.log.1`）。
- `MANAGE_PORT=3920 npm run manage`：管理台改从 3920 起找空闲端口（默认 3900–3909），测试与本地验证用。
- "停止它并启动"如何判定"本平台"：占端口进程命令行里的第一个非选项参数就是脚本（其后不能再有参数）；脚本是绝对路径时必须正好是本平台文件夹下的 `kernel/server/index.js`，是相对路径时按进程工作目录解析后等于它（Mac / Linux 用 `lsof` 与 `ps` / `/proc` 查）。Windows 用一次 PowerShell（`Get-NetTCPConnection` + `Get-CimInstance Win32_Process`）查，拿不到别的进程的工作目录，只认绝对路径（管理台自己启动平台时就用绝对路径）；用 `npm run server` 启动的旧平台在 Windows 上会显示为"被「node.exe」占用"。
