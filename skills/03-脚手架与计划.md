# 03 脚手架与计划（只搭空架子，不填内容）

## 进入条件

- 读 `lessons/<id>/进度.md`："环节"里有 `02 平台规格：✓`。没有 → 回 `skills/02-平台规格.md`。
- 阶段表里"骨架"是 ✓ 的段，第 1、2 步跳过；只做"骨架"恰好是 `✗` 的段（带括号的 `✗（删）` 在第 0 步处理）。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 2、6、7 条。

## 步骤

### 第 0 步：处理复盘改动（只在 06 环复盘回来时；第一次做课跳过）

- "骨架"是 `✗（删）` 的段：删掉目录 `lessons/<id>/stages/<目录>/`，再打开 `lessons/<id>/lesson.config.js`，从 `stages: [...]` 里删掉 `'<目录>'` 那一项；最后从 `进度.md` 阶段表删掉这一行。
- "目录"后写着 `（换原语）` 的段：同上删目录、删 `stages` 里那一项，再把"目录"改成空、去掉 `（换原语）`，当作新增段做第 1 步。

### 第 1 步：逐段搭骨架（按阶段表顺序，一段一条命令）

对阶段表里"骨架"是 `✗` 的每一段，按序号从小到大：

1. 先看 `lessons/<id>/stages/` 里有没有以 `-<段id>` 结尾的目录。有 → 这段上次已生成，**不跑命令**，把这个目录名写进 `进度.md`"目录"，直接去第 2 步。
2. 没有 → 跑（这段排在已有段的中间时，末尾加 ` --after <前一段的目录名>`；按顺序追加时不加）：

`npm run new:stage -- --lesson lessons/<id>/lesson.config.js --id <段id> --label "<阶段名>" --primitive <原语或自写>`

- `<原语或自写>` 照抄阶段表那一列（`vote` / `quiz` / `free-text` / `code` / `data-analysis` / `none`）。
- 完成标志：打印 `已生成 lessons/<id>/stages/NN-<段id>/`，最后一行以 `通过` 开头；中间的"警告"行都是"还有 N 处 TODO 占位"（这时正常）。
- 把实际生成的目录名 `NN-<段id>` 写进 `进度.md` 阶段表"目录"（与原来写的不一致时以实际为准）。
- 打印"new:stage 没有生成"或有"错误"行 → 照那一行说的改再跑。说"已被 <目录> 使用"或"已存在"时：先按本步第 1 条再找一次目录，确实没有这段的目录才换一个段id。

### 第 2 步：把阶段卡复制进 STAGE.md

对每一段：

1. 打开 `lessons/<id>/stages/NN-<段id>/STAGE.md`，删掉全部内容，换成 `教学设计.md` 第四部分里段号相同的那张卡：从行首是 `### 段 <教学设计段号> ·` 的那一行（段号取 `平台规格.md` 阶段表"教学设计段号"列），到下一个 `### ` 或 `## ` 开头的行之前。卡标题比阶段名长是正常的，照抄。
2. 检查三处：
   - `**A 展示**`、`**B 学生做什么**`、`**C 采集**`、`**D 统计**`、`**E 推进条件**` 五个标题一个不少；
   - `**匹配原语**：` 那一行：原语段以原语英文名开头（例 `**匹配原语**：vote`）；`none` 段以 `无（自写）` 开头；
   - 卡里写了某道题的正确答案（例"答案是 C"）→ 改成"答案见配置"（铁律 4）。
3. 完成标志：`进度.md` 阶段表这一段"骨架"改成 ✓。

### 第 3 步：自写段写计划

阶段表里每个 `none` 段写一份 `lessons/<id>/plans/<段id>.md`，不超过 60 行，固定六节，只写本段要点；引用契约只写章节号（例"见契约 §三"），不抄契约原文：

```markdown
# 计划 · 段 <N> <阶段名>（<段id>）

## 事件
- 学生发：student:<动词> { 字段: 类型 } —— 什么时候发、服务端做什么（契约 §三）
- 教师发：teacher:<动词> { … }（没有写"无"）

## 记录字段
- perStudent：<字段>（<类型>）……；perClass：<字段>……（没有写"无"）；不存学生姓名
- 个人报告条目（C 栏说进报告才写）：<中文标签> = <字段>（summarize，契约 §二）

## 视图
- Student.jsx：<Page template="<页面样式>">；Main 放……；Actions 放……（契约 §四）
- TeacherStats.jsx：表格列 = D 栏：姓名、……；提醒 alerts：……
- TeacherDemo.jsx：要 / 不要（A 栏"大屏投什么"不是统计表才要）

## 门槛
- E 栏"<原文>" → gate：<判断>；软 / 硬（契约 §二）

## 测试要点
- server.test.js：每个事件一条正向、一条被拒；gate 通过、不通过各一条（契约 §七）
- simulate.js：让每个虚拟学生<做什么>，做到门槛能过

## 素材
- 题目、数据、样本：<写全，或写"见 教学设计.md 段 <N> 的 ……"；要编的写"由 AI 编 <几条>，<要求>">
- 放在哪：<写进 stage.config.js 或 server.js 的常量 / 本段目录里的文件名>（没有写"无"）
```

完成标志：每个 `none` 段都有 `plans/<段id>.md`。

组件清单里有课程组件（`x-` 开头）→ 每个组件照 `skills/参考/课程组件.md`"搭骨架"做四步：`npm run new:component`、打开它、写 `plans/组件-x-<名>.md`（与自写段计划同形）、`进度.md` 阶段表加一行。

### 第 4 步：按组件清单调整课程设置

打开 `lessons/<id>/lesson.config.js`，只改下面几处（开 AI 助手的段还要改它的 `stage.config.js`，见第 1 条）：

1. `components:` 那一行（默认 `['mirror', 'share', 'report']`）改成 `平台规格.md`"组件清单"里的组件：
   - 清单里没有的删掉（`sandbox` 若已被第 1 步自动加上且清单里有，就留着）；
   - 要 `inbox`：照 `examples/minimal/lesson.config.js` 里 `{ id: 'inbox', questions: [...] }` 那一项的写法抄，题目改成本课的；
   - 要 `sandbox` 但它不在这一行里：照 `examples/primitives-tour/lesson.config.js` 里 `{ id: 'sandbox', packages: [...] }` 那一项抄。
   - 清单里有 `coach` → `components` 加 `'coach'`；清单那一行写的每个要开的段，打开 `new:stage` 生成的 `lessons/<id>/stages/NN-<段id>/stage.config.js`，在顶层（不是 `options` 里）加 `coach: true`。
   - 清单里的课程组件（`x-` 开头）已在上面第 3 步打开，这里不重复。
2. 登录方式选的是"学生自己输入名字"：把 `roster: { mode: 'roster' }` 改成 `roster: { mode: 'free' }`。
3. 教师给了主题色（第一部分主题色不是"沿用默认"）→ `theme: {}` 改成 `theme: { brand: '<色>' }`（颜色深浅要求见 `docs/05-样式约定.md` §四）；别的行不动。

### 第 5 步：检查

跑 `npm run check:lesson -- lessons/<id>/lesson.config.js`

- 完成标志：最后一行以 `通过` 开头（只有 TODO 警告是正常的）。
- 有"错误"行 → 照那一行"→"后面的话改，再跑。

### 第 6 步：存档

1. 跑 `git add lessons/<id>`
2. 跑 `git commit -m "<课名>：骨架"`
3. 完成标志：打印的第一行含 `<课名>：骨架`。
4. 任一条报错（不是 git 仓库、找不到 git、要求设置用户名等）→ 不修 git，跳过；在 `进度.md`"最近一次停在"写"骨架未存档（git 不可用）"。

## 完成标志

- 阶段表每段"骨架"都是 ✓；
- 每个 `none` 段有 `plans/<段id>.md`，每个课程组件有 `plans/组件-x-<名>.md`；
- 第 5 步最后一行以 `通过` 开头。

## 写进度

- "环节"：`03 脚手架与计划：✓ <日期>`；"当前环"：`04`
- 下一步：`04 第 1 段 <阶段名>`
- 最近一次停在：`03 完成，骨架已存档`（或"骨架未存档（git 不可用）"）

## 对教师说

有 `code` / `data-analysis` 段，或组件清单里有 `sandbox` 时，先对教师说：

> 对教师说：这节课要用 Python，管理台首页向导里有一步"下载 Python 运行时"，请先点"开始下载"，等它打勾（设置页最后一节显示"已就绪"也行）。

然后用 `skills/参考/选项话术.md`"去管理台看"固定句，<看什么> 换成："点'打开教师端'，用教师密码登录，应该能看到 <N> 段，每段还是占位的样子（内容下一步再做）。看到了告诉我一声"。

教师说看到了 → 打开 `skills/04-执行与审查.md`。教师说管理台报错 → 请教师点错误框里的"复制给 AI"，把内容贴给你，照着改，再请教师点一次。
