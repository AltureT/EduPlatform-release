# 改课（教师随时说"改第 N 段 / 加一段 / 删一段"）

## 什么时候用

- 教师说要改、加或删某一段：任何一环、任何时候（做课中途、试课后、上过课几周后）。
- 06 环复盘"下次改什么"有内容（`进度.md`"待办与后续定制"有 `- 复盘：…` 行）。
- 平台升级后，`平台规格.md`"后续定制"里某项现在做得到了（`docs/00-框架地图.md` 或 `components/README.md` 里出现了）。
- 不走本文件：做课中途、还没做到那段（`进度.md` 阶段表那段"内容"仍是 `✗`）→ 直接改 `教学设计.md` 那张卡与阶段表那一行即可。

## 先分类（你定，不问教师）

- **小改**：只改内容或机制——题目、选项、答案、提示、数据、门槛、提醒、交了能不能改、小测什么时候看对错。
- **大改**：换做法——换原语、原语改自写、加段 / 删段、加课程组件。
- **做不到**：要改平台本身才行 → 不改，按 `skills/SKILL.md`"做不到的时候"记后续定制，告诉教师那里那句。

## 固定步骤（小改、大改共用；大改多第 4 步）

1. `进度.md`：
   - "待办与后续定制"加 `- 改课：段 <N> <小改 / 大改> <一句话>（改课前下一步：<原"下一步："那一行冒号后的原文>）`；
   - "环节"里 01–05 改回 `进行中`（小改也可以只把 04、05 改回 `进行中`）；
   - "下一步："写 `01 第 4 步：改第 <N> 段的卡`。
2. 01 环第 4 步只做这一段（新增段按新段做；删段在卡上写"删"）：改 `教学设计.md` 那张卡，回读一次。
3. 02 环只改阶段表那一行（新增段加一行、删段删一行、序号重排）；`进度.md` 阶段表该段"内容 / 检查 / 模拟 / 审查 / 存档"改 `✗`：
   - 大改的"骨架"也改 `✗`；
   - 删段写 `✗（删）`；
   - 换原语在"目录"后加 `（换原语）`。
4. （大改）03 环第 0 步与第 1、2 步只做这一段。
5. 04 环按"进入条件"轮到这一段，三关照走（自写段仍由新对话审查）。
6. 05 环（按 05"进入条件"）：小改只追加一节、只重试试课清单里与这段有关的行；大改或复盘回来追加一节、整张清单重做。05 第 6 步收尾照跑（会重新存档并打标记）。
7. 存档信息写 `<课名>：改第 <N> 段 <一句话>`。

## 发给教师

开始时（放进你下一条消息）：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 好，改第 <N> 段：<一句话复述>。
>
> 我先改设计，再重做这一段，其它段不动；
>
> 做好了再请你试一遍这一段。

做完时：不另外请教师去工作台，按上面第 6 条走 05 环，第 3 步那条消息的清单：小改只放与这段有关的行；大改或复盘回来放整张。

## 完成标志

- `进度.md` 阶段表这一段五格全是 ✓（或按 04 环的规则带原因）；
- "待办与后续定制"里那行 `- 改课：…`（复盘来的是 `- 复盘：…`）删掉；
- "下一步："写回那行 `- 改课：…` 括号里"改课前下一步："后面的原文（删那行之前先抄出来）；上过课的写 `等下次上课：06 上课前`。
