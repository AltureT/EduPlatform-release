# 选项话术（每道门怎么问教师）

## 规则

- 每道门最多 3 个选项，推荐项放第一个，后面写"（推荐）"。
- **一次交回只发一条消息**：这一步要教师回答的门全部编号放进这一条（01 环一段一条），教师一次答完。
- 排版（教师看到的样子）：回读最多 3 行；之后每个编号独占一行，问句一行；补充说明、选项都写成它下面的子项（前面空三格加 `- `，选项再写 ①②③，例 `   - ① 要（推荐）`）；问题之间空一行；消息末尾固定加一句，独占一行：`直接回"1① 2②"这样就行；都按推荐就回"都按推荐"。`
- 一句一行，一行不超过 40 字，长句拆成两行；固定话术拆成编号步骤，一步一行。
- 每一行都得是独立的列表项或独立段落，不靠单个换行分行（聊天窗按 Markdown 显示，单个换行会被并回同一段）：不在列表里的相邻两行之间空一行，或者各写成 `- ` 列表项；一个编号下的几句话写成子项；不用纯缩进的续行。不用加粗、标题、表格，只用编号、缩进和空行。
- 发给教师时：不带"发给教师（……）："那一行，不用引用块（`>`）格式，直接当正文发；引用块里的换行、空行、缩进照原样发；只替换尖括号（`<编号>` 换成这道门在这条消息里的号）。
- 教师说"你定"或"都按推荐" → 取推荐项，记 `由 AI 默认：<推荐项>`。
- **已知的不再问**：教师说过的、教案里写明的，直接采用，在回读里带一句"照你教案是……"（或"照你刚才说的……"），不再列选项。
- 教师选了 → 01 环记进 `教学设计.md`"选择记录"，02 环以后记进 `平台规格.md`"决策记录"（门 / 选项 / 教师选择 / 日期）。记过的不再问。
- 教师的回答不在选项里 → 照原话记、照原话做；做不到按 `skills/SKILL.md`"做不到的时候"。
- 每道门下面的"记为"是给你看的，不念给教师。

## 禁用词（发给教师的话里一个都不能有）

文件、文件夹、目录、路径、命令、终端、端口、组件、原语、配置、options、JSX、事件、服务端、前端、后端、构建、进程、代码库、仓库、提交记录、git、id、TODO、对教师说、发给教师。

要表达这些意思时换成：平台、这一段、这节课、管理台、存档、大屏、平板、教师端、学生地址。

## 各道门（每道照下面的样子多行写，编号放进那条消息）

下面每道门的引用块是放进那条消息的原话：只发引用块的内容，不带引用格式；`<编号>` 换成它在这条消息里的号；两道门之间空一行。

### 登录方式（01 第 1 步）

> <编号>. 学生怎么进课堂？
>    - ① 从班级名单里点自己的名字（推荐）
>      - 没有错字和重名，上课前在管理台导入一次名单
>    - ② 学生自己输入名字

记为：① 花名册认领；② 自由起名（03 环把 `roster` 改成 `free`）。

### AI 助手（01 第 1 步，整节课问一次；有写程序 / 分析数据的段，或教师提到"求助""AI 帮学生"时才问）

> <编号>. 课上学生卡住时，要不要让他问 AI 要提示？
>    - AI 只给提示不给答案（直接要答案会被拒）
>    - 你能看到谁问了什么，随堂测验时可以一键暂停。
>    - ① 要（推荐；上课前要在管理台左边第 4 步"上课准备"填好 AI 接口）
>    - ② 不要

记为：① `lesson.config.js` 的 `components` 加 `'coach'`，写程序 / 分析数据的段 `coach: true`（教师点名别的段也要就加）；② 不加。

### 推进门槛（E 栏，拆成两问，放同一条消息）

> <编号>. 这段什么时候能进下一段？
>    - ① 七成学生<完成动作>了（推荐）
>    - ② 全部学生<完成动作>了
>    - ③ 不设，你随时进

> <编号>. 没到这个数时你点"进入下一段"：
>    - ① 提示一下，点"继续"就进（推荐）
>    - ② 要你再点一次确认才能强行进

（第一问选 ③ 就不问第二问。）

<完成动作> 按 B 栏换：交了 / 投了 / 跑通了程序 / 测试全过 / 画出了图。
记为（原语段写进 `options.gate`；指标键 = 原语 README 缺省门槛里的那个键，vote / quiz / free-text 是 `submitted`）：

| 比例 | 没到时 | `gate` 写法 |
|---|---|---|
| 七成 | 一键继续 | `{ submitted: 0.7, soft: true }` |
| 七成 | 再确认一次 | `{ submitted: 0.7, soft: false }` |
| 全部 | 一键继续 | `{ submitted: 'all', soft: true }` |
| 全部 | 再确认一次 | `{ submitted: 'all', soft: false }` |
| 不设 | — | `false` |

有对错的投票段（`vote` 且有标准答案）再加一问：

> <编号>. 要不要等你在大屏上点了"揭晓"才能进下一段？
>    - ① 不用，你自己掌握（推荐）
>    - ② 要

记为：② → 按 `skills/04-执行与审查.md`"揭晓之后才能进"写。

### 提交后能不能改（B 栏）

### 投票有没有对错（`vote` 段）

不问。卡里看得出有标准答案 → 回读带一句"你在大屏上点'揭晓'后学生才看到对错"；看得出没有对错 → 回读带一句"这题没有对错，只看大家怎么选"。实在看不出才问：

> <编号>. 这道题有标准答案吗？
>    - ① 有，你点"揭晓"后学生才看到对错
>    - ② 没有对错

### 小测结果什么时候给学生看（`quiz` 段）

### 提醒条件（D 栏）

> <编号>. 学生多久没<完成动作>要提醒你走过去看看？

推荐分钟数 M：写程序、分析数据的段 8，其它段 3。记为 D 栏"<M> 分钟未<完成动作>"。
教师说的是次数或结果（"连续 2 次没成功""验证没过"）→ 照原话记。自写段照做；原语段只能按分钟，按原话在"后续定制"记一行，这段先按分钟（教师没给分钟就用推荐）。

### 原语不够时（阶段卡"匹配原语"）

学生有动作：

> <编号>. 第 <N> 段"<教师原话>"，
>    - 平台现成的做法里没有完全一样的：
>    - ① 稍微简化成"<能直接做的做法>"，很快就能做好（推荐）
>    - ② 专门为这一段做一个页面，要多花些时间、多检查一遍
>    - ③ 这一段不用平台，课上口头进行

学生不操作、只看结果（B 栏没有学生动作）：

> <编号>. 第 <N> 段学生不用操作、只看结果：
>    - ① 专门做一个只有结果页和统计的页面（推荐）
>    - ② 这一段不用平台，课上口头进行

<能直接做的做法> 取最接近的一种：投票、小测验、写一段话、写程序、分析数据。简化后卡里"核心教学事件"那句就做不出来（或教案标了"核心"）→ 把"专门做"放第一个并标推荐，回读里带一句为什么。
记为：简化 → 改卡并写原语名；专门做 → `无（自写）：<为什么>`；不用平台 → "本段不用平台"。

## 固定句

每句放进你要发的那条消息里：只发引用块的内容，不带"发给教师（……）："那一行、不带引用格式，换行照原样。

### 去管理台看

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 请去管理台：
>
> 1. 页面上方黄条里有按钮（"重启并应用"或"立即重启平台"）就点它；
>    - 没有黄条，就点最上面的"重启平台"；
>    - 平台没在运行，就到左边第 5 步"启动上课"点"启动平台"。
>    - 管理台页面打不开，就再双击一次"管理台"。
> 2. 等看到绿点"运行中"，把已经开着的教师端、学生端页面都刷新一下。
> 3. 然后<看什么>。

<看什么> 只有一句就接在"然后"后面；有几句，就把第 3 步写成"3. 然后："，下面每句一个子项（前面空三格加 `- `）。
