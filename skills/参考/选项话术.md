# 选项话术（每道门怎么问教师）

## 规则

- 每道门最多 3 个选项，推荐项放第一个，后面写"（推荐）"。
- **一次交回只发一条消息**：这一步要教师回答的门全部编号放进这一条（01 环一段一条），教师一次答完。**回读最多 3 行，之后每个编号独占一行，选项跟在同一行**；消息末尾固定加一句，独占一行：`直接回"1① 2②"这样就行；都按推荐就回"都按推荐"。`
- 教师说"你定"或"都按推荐" → 取推荐项，记 `由 AI 默认：<推荐项>`。
- **已知的不再问**：教师说过的、教案里写明的，直接采用，在回读里带一句"照你教案是……"（或"照你刚才说的……"），不再列选项。
- 教师选了 → 01 环记进 `教学设计.md`"选择记录"，02 环以后记进 `平台规格.md`"决策记录"（门 / 选项 / 教师选择 / 日期）。记过的不再问。
- 教师的回答不在选项里 → 照原话记、照原话做；做不到按 `skills/SKILL.md`"做不到的时候"。
- 每道门下面的"记为"是给你看的，不念给教师。

## 禁用词（对教师说的话里一个都不能有）

文件、文件夹、目录、路径、命令、终端、端口、组件、原语、配置、options、JSX、事件、服务端、前端、后端、构建、进程、代码库、仓库、提交记录、git、id、TODO。

要表达这些意思时换成：平台、这一段、这节课、管理台、存档、大屏、平板、教师端、学生地址。

## 各道门（每道一行，直接编号放进那条消息）

### 登录方式（01 第 1 步）

`学生怎么进课堂？① 从班级名单里点自己的名字（推荐：没有错字和重名，上课前在管理台导入一次名单）② 学生自己输入名字`

记为：① 花名册认领；② 自由起名（03 环把 `roster` 改成 `free`）。

### 推进门槛（E 栏，拆成两问，放同一条消息）

`这段什么时候能进下一段？① 七成学生<完成动作>了（推荐）② 全部学生<完成动作>了 ③ 不设，你随时进`

`没到这个数时你点"进入下一段"：① 提示一下，点"继续"就进（推荐）② 要你再点一次确认才能强行进`（第一问选 ③ 就不问这一问）

<完成动作> 按 B 栏换：交了 / 投了 / 跑通了程序 / 测试全过 / 画出了图。
记为（原语段写进 `options.gate`；指标键 = 原语 README 缺省门槛里的那个键，vote / quiz / free-text 是 `submitted`）：

| 比例 | 没到时 | `gate` 写法 |
|---|---|---|
| 七成 | 一键继续 | `{ submitted: 0.7, soft: true }` |
| 七成 | 再确认一次 | `{ submitted: 0.7, soft: false }` |
| 全部 | 一键继续 | `{ submitted: 'all', soft: true }` |
| 全部 | 再确认一次 | `{ submitted: 'all', soft: false }` |
| 不设 | — | `false` |

有对错的投票段（`vote` 且有标准答案）再加一问：

`要不要等你在大屏上点了"揭晓"才能进下一段？① 不用，你自己掌握（推荐）② 要`

记为：② → 按 `skills/04-执行与审查.md`"揭晓之后才能进"写。

### 提交后能不能改（B 栏）

`学生交了以后还能改吗？① 能改，以最后一次为准（推荐）② 交了就不能改`

### 投票有没有对错（`vote` 段）

不问。卡里看得出有标准答案 → 回读带一句"你在大屏上点'揭晓'后学生才看到对错"；看得出没有对错 → 回读带一句"这题没有对错，只看大家怎么选"。实在看不出才问：`这道题有标准答案吗？① 有，你点"揭晓"后学生才看到对错 ② 没有对错`

### 小测结果什么时候给学生看（`quiz` 段）

`学生做完小测，什么时候看到自己对错？① 你在大屏上点"揭晓"以后（推荐：先交的学生没法告诉别人答案）② 交了马上看 ③ 不给学生看`

### 提醒条件（D 栏）

`学生多久没<完成动作>要提醒你走过去看看？① <M> 分钟（推荐）② <M+2> 分钟 ③ 不用提醒`

推荐分钟数 M：写程序、分析数据的段 8，其它段 3。记为 D 栏"<M> 分钟未<完成动作>"。
教师说的是次数或结果（"连续 2 次没成功""验证没过"）→ 照原话记。自写段照做；原语段只能按分钟，按原话在"后续定制"记一行，这段先按分钟（教师没给分钟就用推荐）。

### 过程性评价、个人报告、课后导出（第五部分，放在最后一段那条消息末尾）

`上课时你最想盯住每个学生的哪一样？① 交没交（推荐）② 做对了多少 ③ 用了多长时间`

`下课时要不要给每个学生一份个人报告（每段做了什么、和全班比怎么样），学生在平板上看？① 要（推荐）② 不要`

`课后要不要把全班每个人的作答导出成一张表格？① 要（推荐）② 不要`

### 页面样式（阶段卡）

教师没说就你定，不问。教师在意时再问：`学生平板上这一段怎么摆？① 整页只放一件事（推荐）② 左右两块对照着看 ③ 从上往下一步一步做`

记为：① `focus`；② `split`；③ `stack`。教师说"很多张卡片排开"记 `tiles`。

### 原语不够时（阶段卡"匹配原语"）

学生有动作：`第 <N> 段"<教师原话>"，平台现成的做法里没有完全一样的：① 稍微简化成"<能直接做的做法>"，很快就能做好（推荐）② 专门为这一段做一个页面，要多花些时间、多检查一遍 ③ 这一段不用平台，课上口头进行`

学生不操作、只看结果（B 栏没有学生动作）：`第 <N> 段学生不用操作、只看结果：① 专门做一个只有结果页和统计的页面（推荐）② 这一段不用平台，课上口头进行`

<能直接做的做法> 取最接近的一种：投票、小测验、写一段话、写程序、分析数据。简化后卡里"核心教学事件"那句就做不出来（或教案标了"核心"）→ 把"专门做"放第一个并标推荐，回读里带一句为什么。
记为：简化 → 改卡并写原语名；专门做 → `无（自写）：<为什么>`；不用平台 → "本段不用平台"。

## 固定句

### 去管理台看

> 对教师说：请去管理台首页：黄条上有按钮（"重启并应用"或"立即重启平台"）就点它；没有黄条就点最上面的"重启平台"；平台没在运行就点"启动平台"。管理台页面打不开，就再双击一次"管理台"。等看到绿点"运行中"，把已经开着的教师端、学生端页面都刷新一下，然后<看什么>。

### 攒几段一起看

> 对教师说：第 <几段> 做好了，先不打扰你，等<第 N 段 / 全部>做好了一起看。

<第 N 段 / 全部>：后面还有专门做的段 → 写它的段号；没有 → 写"全部"。

（教师说过"做完一起看"就连这句也不说。）

### 改法做不到时

> 对教师说：你说的"<教师原话>"这一点，平台现在做不到，我记下来留给技术同事；这段先按"<现在的做法>"，其它照你说的改。

### 存了档

> 对教师说：刚才存了档，之后改坏了也能回到这里。

### 管理台报错

> 对教师说：请点错误框里的"复制给 AI"，把复制下来的内容整段贴给我。
