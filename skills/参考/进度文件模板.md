# 进度文件模板

`lessons/<id>/进度.md` 由你建立、由你更新，照下面的格式逐字写，只替换尖括号。

- 新对话的第一件事是读它；标题下第一行"下一步："就是现在要做的事（做到哪一环也只看这一行）。
- 每做完一步就整行替换"下一步："和"最近一次停在："。
- "等老师回答："：**每次发出要教师回答的消息之前**，把那条消息里每个编号的问句摘要写成它下面的子项（一个编号一行，前面空三格加 `- `）；收到回答并处理完后删掉这些子项，只留 `- 等老师回答：`（后面空着 = 没有在等）。新对话读到它下面有子项 → 先把这几行念给教师（"上次问到：……"），教师回答后再照"下一步："继续。
- "环节"状态只用：`✗`、`进行中`、`✓ <YYYY-MM-DD>`。
- "阶段表"格子只用：`✗`、`✓`、`✓自审`（只用于原语段"审查"）、`✓自审（无新对话）`（只用于自写段"审查"：教师开不了新对话时）、`待回贴（第 <k> 轮）`（只用于"审查"：审查粘贴文本已生成、等教师贴回）、`未存档`（只用于"存档"）、`✗（<原因>）`。"要做"只看格子**恰好是 `✗`**；`✗（<原因>）` 表示已记进后续定制，不再去做。
- 教师的选择不记在这里（记在 `教学设计.md` 的"选择记录"、`平台规格.md` 的"决策记录"），这里只记做到哪了。
- 下面格式里"教学设计卡"写 `- （还没有）`、"阶段表"只有表头：新建时就这样抄，**不要**自己编样例行；01、02 环再按各自"写进度"往里加行（加第一行时删掉 `- （还没有）`；"待办"加第一行时同样删掉 `- （无）`）。

## 格式

```markdown
# 进度 · <课名>

下一步：<哪一环第几步，做什么>
最近一次停在：<一句话>

- 等老师回答：
- 课名：<课名>
- id：<id>
- 建于：<YYYY-MM-DD>

## 环节

- 00 环境与项目：✓ <YYYY-MM-DD>
- 01 教学设计：进行中
- 02 平台规格：✗
- 03 脚手架与计划：✗
- 04 执行与审查：✗
- 05 细节调整：✗
- 06 上课与课后：✗

## 教学设计卡

- （还没有）

## 阶段表

| 段 | 目录 | 原语或自写 | 骨架 | 内容 | 检查 | 模拟 | 审查 | 存档 |
|---|---|---|---|---|---|---|---|---|

## 上课

- （还没上课）

## 待办与后续定制

- （无）
```

## 示例，不要抄（加行之后大概是这样）

- 教学设计卡的一行：`- 段 1 猜一猜 已确认（原语 vote）`；不用平台的段：`- 段 2 不用平台`
- 阶段表的一行：`| 1 | 01-guess | vote | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ |`
- 课程组件的一行（03 环加在用到它的第一段之前，`skills/参考/课程组件.md`）：`| 组件 | components/x-wall | 组件 | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ |`
- "待办与后续定制"的行：`- 后续定制：段 3 / 学生选完能由老师解锁 / 投票做不了解锁`（01 环记，02 环搬进 `平台规格.md`）；`- 改课：段 2 大改 换成投票（改课前下一步：05 第 3 步：请教师试课）`（教师要改某一段时加，`skills/参考/改课.md`；括号里抄改课前"下一步："的原文，改完写回"下一步："）
- 在等教师回答时：`- 等老师回答：` 下面 `   - 1. 第 2 段：四类短信各举哪一条？`、`   - 2. AI 助手要不要`
