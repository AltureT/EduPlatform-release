# 课程组件（给这节课单独做一个功能）

平台组件清单里没有、又不只属于某一段的功能（作品墙、分层挑战、互评……），做成这节课自己的组件，放在 `lessons/<id>/components/<cid>/`，只在这节课有效。写法与平台组件完全一样，契约见 `docs/06-组件契约.md`；范本 `examples/primitives-tour/components/gallery/`（作品墙）。一段之内的事仍然做自写段，不做组件。

## 什么时候做（02 环）

- 教师要的东西不在六个平台组件里、也不是一段能装下的（要在好几段出现、或挂在页面边上、或跨段收数据）→ 用 `skills/参考/选项话术.md`"课程组件"那道门问。
- 选"做" → `平台规格.md`"组件清单"加一行 `- x-<名> —— 课程组件：<一句话是什么>；开的段：第 <N> 段…；要收：<数据>；教师端：<看到 / 点什么>；学生端：<看到 / 做什么>`，"决策记录"记一行（门 = `课程组件 x-<名>`）。
- 选"先不做" → 记进"后续定制"。

## 搭骨架（03 环）

1. 跑 `npm run new:component -- lessons/<id>/lesson.config.js <名> --label "<中文名>"`（id 会自动变成 `x-<名>`）。完成标志：打印 `已生成 lessons/<id>/components/x-<名>/`。
2. `lesson.config.js` 的 `components` 加 `'x-<名>'`；开的段在那段 `stage.config.js` **顶层**加 `'x-<名>': true`。
3. 写 `lessons/<id>/plans/组件-x-<名>.md`（≤ 60 行），节与自写段计划相同：事件（`x-<名>:s-…` 学生发 / `x-<名>:t-…` 教师发）、记录字段（perStudent / perClass；报告条目）、视图（用哪几个槽位、各显示什么、哪些段出现）、门槛（组件没有门槛，写"无"）、测试要点、素材。
4. `进度.md` 阶段表在用到它的第一段那一行之前加一行：段 = `组件`、目录 = `components/x-<名>`、原语或自写 = `组件`，其余格 `✗`（"骨架"写 ✓）。

## 做组件（04 环，按自写段流程：做 → 三关 → 存档）

1. 读四样：`plans/组件-x-<名>.md`、`docs/06-组件契约.md`、范本 `examples/primitives-tour/components/gallery/` 的 `README.md` 与 `server.js`、`docs/05-样式约定.md`。
2. 写 `server.js`：`register(cctx)` 里注册计划中的事件，数据写 `cctx.data`；换段 / 重置要收起的写 `cctx.hooks`；进报告的写 `export function report(name, cctx)`。
3. 写 `client.jsx`：只用契约里的槽位；不该出现的段返回 `null`（读那段顶层的 `'x-<名>'` 字段）；弹层只用 `<Overlay>`；样式只用令牌。
4. 写 `README.md`：是什么、开在哪些段、事件与数据形状（照范本）；把骨架里的 `TODO` 全换掉。
5. 写 `__tests__/server.test.js`（每个事件一条正向、一条被拒；钩子清空；`report`）；跑 `node --test lessons/<id>/components/x-<名>/__tests__/server.test.js`，末尾 `fail 0`。
6. 跑 `npm run build:lesson -- lessons/<id>/lesson.config.js`，最后一行 `通过：页面能打包`。
7. 阶段表这一行"内容"改 ✓。

三关：关一 `check:lesson` 没有错误、没有指向本组件的警告；关二 `simulate` 退出码 0（组件不影响门槛，只看没坏）；关三新对话审查，粘贴文本拼五块，存为 `lessons/<id>/plans/组件-x-<名>-审查.md`：

1. 一行 `平台目录：<node -e "console.log(process.cwd())" 打印的位置>`
2. `skills/参考/审查清单.md` 全文
3. 一行 `组件目录：lessons/<id>/components/x-<名>/`
4. 一行 `平台规格中本组件：` 加组件清单里那一行
5. 一行 `组件计划：` 加 `plans/组件-x-<名>.md` 全文

请教师看、请教师贴审查、回答不通过怎么改，都与自写段相同（`skills/04-执行与审查.md` 关三）。存档：`git commit -m "<课名>：<中文名>"`。

## 发给教师

- 做好后用选项话术"去管理台看"那句，<看什么> 写成教学说法，一句一项（照"去管理台看"固定句下面的说明），例如：

  > - 进第 3 段，大屏顶部多了"作品墙"按钮，点一下看看
  > - 学生平板上题目下面多了一行提示
- 不说组件、文件、事件这些词；说"这节课单独做的<中文名>"。

## 常见三种怎么拆

**作品墙**（范本 `gallery`）：教师点顶栏按钮（`teacherToolbar`）→ `x-<名>:t-open` 读出图那段的记录（`cctx.stages.data('<段id>').all()`），每人一张图，整面墙用 `cctx.emitTeachers` 只发给教师，教师端存本地切片；教师弹层（`teacherOverlay`）网格显示，点一张 → `t-spotlight` 只把这一张写进 `perClass.spotlight`，学生弹层（`studentOverlay`）全班看到放大那张；`hooks.onStageChange` 收起；`report` 写"被展示过几次"。`perClass` 每次都发给全班，只放全班都需要的一小份（≤ 200 KB）。

**分层挑战**：同一段里有基础 / 进阶 / 挑战三层题。学生页题目下方（`studentAside`）显示"当前第 N 层"与"挑战下一层"按钮 → `x-<名>:s-level-up`，服务端读这段记录判断本层是否已完成（如测试全过），通过才写 `perStudent.level = N + 1`，否则 `cctx.reject` 一句为什么；教师统计页右侧（`teacherSidebar`）按层数列出人数；题目文字放组件选项（`lesson.config.js` 里 `{ id: 'x-<名>', levels: [...] }`），答案不放选项（选项会下发到学生端）。

**互评**：交作品那段结束后，教师点按钮（`teacherToolbar`）→ `t-assign` 给每人随机分 2 份别人的作品，用匿名代号（`cctx.anon.code(name)`）写进各自 `perStudent.toReview`（只存代号与作品内容，不存对方真名）；学生弹层或题目下方显示待评作品与打分表，提交 → `s-review`，写进被评者 `perStudent.received`；`report` 写"收到的平均分、评语"；教师侧栏看谁还没评完。
