# 子代理加速（可选）

只给能"另开一个全新上下文的助手，并给它一份独立的工作副本"的 AI 工具看。你的工具没有这种能力 → 跳过本文件，按 `skills/04-执行与审查.md` 一段一段做。

## 什么能并行

- 只有自写段（阶段表"原语或自写"是 `none`）可以并行；原语段仍在主对话里一段一段做。
- 前提：03 环已完成，骨架已存档；`plans/<段id>.md` 写好后不再改。

## 怎么做

1. **派执行助手**：每个自写段一个。只给它五样：本段 `STAGE.md`、`lessons/<id>/plans/<段id>.md`、`docs/02-阶段模块契约.md`、`docs/05-样式约定.md`、范本目录 `examples/minimal/stages/02-freeform/`。不给整份 `教学设计.md`，不给别的段。
2. **给执行助手的要求**：独立工作副本的平台目录（有 `package.json` 与 `班迹工作台.command` 的那一层）里没有 `node_modules/` 就先跑 `npm install`（或把主副本的 `node_modules` 软链过去）；只改 `lessons/<id>/stages/NN-<段id>/` 里的文件；做完跑 `node --test lessons/<id>/stages/NN-<段id>/__tests__/server.test.js`（`fail 0`）和 `npm run check:lesson -- lessons/<id>/lesson.config.js`（末行以 `通过` 开头）；在自己的工作副本里存档；把两条命令的输出末尾几行交回。
3. **派审查助手**：每段另开一个新上下文，只给它 04 环生成的"审查粘贴文本"（`lessons/<id>/plans/<段id>-审查.md`）。它的回答代替教师粘贴，按 04 环"关三"第 5、6 条处理（不请教师贴，"审查"格不写 `待回贴`、"等老师回答："也不写）。派不了审查助手 → 按关三第 4 条在主对话自审，"审查"写 `✓自审（无新对话）`。
4. **合并**：一段一段把执行助手的存档合回主副本；每合一段，在主对话重跑 04 环自写段第 4 步（确认学生页能打开）和关一、关二。
5. **写进度**：只由主对话写 `进度.md`；每合并一段，更新阶段表那一行。

## 发给教师

不发消息：02 环结束时已告诉教师"开始做了"，03、04 期间不再发通知（`skills/02-平台规格.md`"发给教师"）。
