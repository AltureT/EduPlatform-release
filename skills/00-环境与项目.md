# 00 环境与项目（只在第一次做）

## 进入条件

- 这一环在建课之前，还没有 `进度.md` 可读。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 6、8 条。
- 先按 `skills/SKILL.md`"路径与命令的约定"确认当前目录是平台目录。
- 从 `skills/SKILL.md`"怎么开始"第 4 条来：那里写了从第几步做（`node_modules/` 已有、教师还没说过工作台能打开 → 只做第 3、4 步）。
- `node_modules/` 目录存在，教师也说过工作台能打开 → 本环不用做，回到 `skills/SKILL.md`"怎么开始"。

## 步骤

### 第 1 步：确认 Node.js

1. 跑 `node -v`。
2. 完成标志：打印 `v` 开头的版本号，第一个数字 ≥ 22（例 `v22.11.0`、`v24.1.0`）；或已按前缀用 `vendor/node`（见下面第 3 条）。
3. 报"找不到命令 / not found / 不是内部或外部命令"，或第一个数字 < 22：先看 `vendor/node/` 目录在不在。
   - 在 → 以后每条 `node` / `npm` 命令都按 SKILL.md"路径与命令的约定"加前缀用它，第 1 步完成。
   - 不在 →

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 这台电脑还缺平台要用的基础软件 Node.js。
>
> 你直接双击"班迹工作台"就行：它会问要不要自动下载，按回车等它装完（约 50 MB）。
>
> 装完告诉我。

   然后跳到第 3 步（请教师双击"班迹工作台"）；教师说打开了 → 回来重做第 1 步（这时 `vendor/node/` 应已存在）。

### 第 2 步：安装平台需要的依赖

1. 看 `node_modules/` 目录在不在。在 → 跳到第 3 步。
2. 不在 → 跑 `npm install`（要联网，可能几分钟）。
3. 完成标志：命令结束，`node_modules/` 目录出现。
4. 报错（退出码不是 0，或输出里有 `npm error` / `ERR!`）→ 再跑一次；还报错 → 不再跑，进第 3 步（教师双击"班迹工作台"时它会自己再装一次）。

### 第 3 步：请教师打开工作台

工作台要一直开着，所以**你不自己启动它**（你一启动，对话就会卡住）。由教师双击打开。

第 1 步没找到 Node（也没有 `vendor/node/`）时不跑 node：先跑 `open .`，报找不到命令再跑 `explorer .`；打印位置用 `pwd`（Windows 用 `cd`）。

1. 跑 `node -e "console.log(process.platform)"`，按打印结果替教师打开平台所在的文件夹窗口（这些命令弹出窗口后立刻结束，不会卡住；`explorer .` 退出码常是 1，不用管）：
   - `darwin`（Mac）→ 跑 `open .`
   - `win32`（Windows）→ 跑 `explorer .`
   - `linux` → 没有双击入口，跳到本步第 3 条。
2. 告诉教师：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 我刚在你的电脑上打开了一个窗口，里面有一个叫"班迹工作台"的图标，请双击它。
>
> 会再弹出一个小窗口，第一次要等几分钟；之后浏览器会自动打开工作台页面。
>
> 那个小窗口开着平台才开着，上课时也别关。打开了告诉我。

   教师说没看到窗口 → 跑 `node -e "console.log(process.cwd())"`，把打印的位置念给教师：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 请在电脑上打开这个位置：<打印的位置>
>
> 里面有一个叫"班迹工作台"的图标，双击它：
>
> - Mac 上它叫"班迹工作台.command"
> - Windows 上它叫"班迹工作台.bat"

3. `linux` → 跑 `node -e "console.log(process.cwd())"`，告诉教师：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 这台电脑需要请技术同事帮忙打开一次工作台。
>
> 平台在 <打印的位置>。
>
> 请他照 docs/技术同事.md 第一节最后一条在 Linux 上打开工作台。
>
> 打开后浏览器里会出现工作台页面，告诉我一声。

4. 教师说"打不开 / 提示无法验证开发者 / Windows 已保护你的电脑"：读 `docs/技术同事.md`"一、第一次打开时的系统提示与安装失败"前两条，把对应那一条（Mac 或 Windows）用自己的话转述给教师，不提文件名以外的技术词。

### 第 4 步：设好教师密码

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 工作台左边有五步。请先设好教师密码：
>
> 1. 点第 4 步"上课准备"。
> 2. 在"教师密码"一节填一个密码（至少 6 位，上课登录教师端用）。
> 3. 点页尾的"保存设置"。
>
> 其它几步先不用管，做课的时候我会告诉你什么时候点什么。

完成标志：教师说"工作台打开了"或"密码设好了"。

## 完成标志

- 第 1 步打印的版本第一个数字 ≥ 22；
- `node_modules/` 存在（或教师双击"班迹工作台"后已自动装好）；
- 教师说工作台打开了。

## 写进度

本环不建课程目录、不写 `进度.md`（还没有课）。01 环第 1 步建 `进度.md` 时，在"环节"里写 `00 环境与项目：✓ <今天日期>`。

## 发给教师

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 准备工作做好了。
>
> 接下来请你跟我说说这节课想怎么上，我们一段一段来。

然后打开 `skills/01-教学设计.md`，从第 1 步开始。
