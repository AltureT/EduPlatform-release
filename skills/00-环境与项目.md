# 00 环境与项目（只在第一次做）

## 进入条件

- 这一环在建课之前，还没有 `进度.md` 可读。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 6、8 条。
- 先按 `skills/SKILL.md`"路径与命令的约定"确认当前目录是平台目录。
- 从 `skills/SKILL.md`"怎么开始"第 4 条来：那里写了从第几步做（`node_modules/` 已有、教师还没说过管理台能打开 → 只做第 3、4 步）。
- `node_modules/` 目录存在，教师也说过管理台能打开 → 本环不用做，回到 `skills/SKILL.md`"怎么开始"。

## 步骤

### 第 1 步：确认 Node.js

1. 跑 `node -v`。
2. 完成标志：打印 `v` 开头的版本号，第一个数字 ≥ 22（例 `v22.11.0`、`v24.1.0`）。
3. 报"找不到命令 / not found / 不是内部或外部命令"，或第一个数字 < 22：

> 对教师说：这台电脑还缺一个平台要用的基础软件 Node.js。请打开 https://nodejs.org/zh-cn ，下载"长期支持版"安装包，双击一路"继续"装好，装好告诉我。

   教师说装好了 → 重新做第 1 步（装完可能要关掉再打开你所在的 AI 工具）。

### 第 2 步：安装平台需要的依赖

1. 看 `node_modules/` 目录在不在。在 → 跳到第 3 步。
2. 不在 → 跑 `npm install`（要联网，可能几分钟）。
3. 完成标志：命令结束，`node_modules/` 目录出现。
4. 报错（退出码不是 0，或输出里有 `npm error` / `ERR!`）→ 再跑一次；还报错 → 不再跑，进第 3 步（教师双击管理台时它会自己再装一次）。

### 第 3 步：请教师打开管理台

管理台要一直开着，所以**你不自己启动它**（你一启动，对话就会卡住）。由教师双击打开。

1. 跑 `node -e "console.log(process.platform)"`，按打印结果替教师打开平台所在的文件夹窗口（这些命令弹出窗口后立刻结束，不会卡住；`explorer .` 退出码常是 1，不用管）：
   - `darwin`（Mac）→ 跑 `open .`
   - `win32`（Windows）→ 跑 `explorer .`
   - `linux` → 没有双击入口，跳到本步第 3 条。
2. 对教师说：

> 对教师说：我刚在你的电脑上打开了一个窗口，里面有一个叫"管理台"的图标，请双击它。会再弹出一个小窗口，第一次要等几分钟；之后浏览器会自动打开管理台页面。那个小窗口开着平台才开着，上课时也别关。打开了告诉我。

   教师说没看到窗口 → 跑 `node -e "console.log(process.cwd())"`，把打印的位置念给教师：

> 对教师说：请在电脑上打开这个位置：<打印的位置>，里面有一个叫"管理台"的图标（Mac 上叫"管理台.command"，Windows 上叫"管理台.bat"），双击它。

3. `linux` → 跑 `node -e "console.log(process.cwd())"`，对教师说：

> 对教师说：这台电脑需要请技术同事帮忙打开一次管理台：平台在 <打印的位置>，请他看那里的 README.md（教师使用手册）最后"附：开发者命令"一节，跑 npm run manage。打开后浏览器里会出现管理台页面，告诉我一声。

4. 教师说"打不开 / 提示无法验证开发者 / Windows 已保护你的电脑"：读 `README.md`"二、第一次使用"第 2 条，把对应那一段（Mac 或 Windows）用自己的话转述给教师，不提文件名以外的技术词。

### 第 4 步：向导做到"设置教师密码"

> 对教师说：管理台首页有一张向导。请先做第一步"设置教师密码"（至少 6 位，上课登录教师端用），点"保存并继续"。后面几步先不用管，做课的时候我会告诉你什么时候点什么。

完成标志：教师说"管理台打开了"或"密码设好了"。

## 完成标志

- 第 1 步打印的版本第一个数字 ≥ 22；
- `node_modules/` 存在（或教师双击管理台后已自动装好）；
- 教师说管理台打开了。

本环不建课程目录、不写 `进度.md`（还没有课）。01 环第 1 步建 `进度.md` 时，在"环节"里写 `00 环境与项目：✓ <今天日期>`。
