# 01 教学设计（把教师的话整理成阶段卡）

## 进入条件

- 00 环做完（教师说过工作台打开了），或按 `skills/SKILL.md`"怎么开始"第 4 条可以跳过 00。
- 已有这门课的 `lessons/<id>/进度.md`：先读它，从"下一步："写的那一步继续；`进度.md`"教学设计卡"里已"已确认"的段不重问。
- 从 06 环复盘回来（"待办与后续定制"里有 `- 复盘：` 行）：只改那几段的卡（也可能新增或删掉段），改完照常走"完成标志"与"写进度"。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 1、5、7 条。

**已知的不再问**：教师第一句话里、贴来的教案里或上传的原稿里已有的——课名、分几段、每段学生做什么、教案写明的门槛与评价——直接采用，回读时带一句"照你教案是……"。"分几段"从教案推出后只请教师确认。

**只问内容，不问机制**：课时、人数、学生设备、教室网络、登录方式，每段的推进门槛、提交后能不能改、小测什么时候看对错、提醒，评价三项——都不问，按第 4 步 d 的默认写，记 `由 AI 默认：<默认>`。教师想改，到 05 环试课时一起改。

**回读与逐问**：有教案（贴来的，或 `教学设计原稿.*`）→ 第 1 步不单独发消息（课名或分段读不出来时除外），基本信息和所有段的卡在第 4 步一条回读说完，再逐问；没有教案、教师口述 → 第 1 步一条回读，第 4 步一段一条回读，每条回读后逐问。要问的一次只问一个，有提问功能就用它（`skills/参考/选项话术.md`"规则"）。

## 步骤

### 第 1 步：基本信息与分段（有教案时不单独发）

0. 先找教学设计原稿：课程目录 `lessons/<id>/` 里的 `教学设计原稿.*`（`.bak` 结尾的是旧稿，不读；同名多份时先读纯文本的那份）。用你的工具或系统自带的手段读它——不管它是什么格式：工具能直接读文件就读；不能就用系统已有的办法（例如把文件解压后读里面的文本、用系统自带的命令转成纯文本）。读到了 → 它就是教案，照"已知的不再问"处理，不再请教师贴教案。不装任何工具（不装文档库、不 pip、不 npm install）。

读不了（工具不支持这种文件、或读出来不是正文）才发：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 你上传的教案文件我这边读不了，请你：
>
> 1. 到工作台课名下面的"教案"页签；
> 2. 把教案文字粘进框里，点"保存"；
> 3. 然后告诉我"传好了"。

1. 先把已知的列出来（见上面"已知的不再问"），主题颜色不问（教师没提就"沿用默认"）（教师提了颜色就记进第一部分，03 环写进 `theme.brand`）。设备和登录方式是已知项，不问：学生一律用平板或电脑、从名单点名字进课堂（`由 AI 默认`）。
2. 没有教案时，从教师说的话里数出中间有几段；数不出就把"分几段"放进问题。
3. 有教案、课名和分段都读得出 → 不发消息，下面这段回读放到第 4 步那条回读的开头，直接去第 2 步。否则发回读，紧接着第一问"上面对吗？"（回读不超过 3 行；有提问功能就用它问，"上面对吗？"之前的当正文发）：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 我先把知道的说一遍：
>
> - 这节课叫《<课名>》
> - 学生用平板或电脑，从班级名单点名字进来
> - 中间分 <N> 段（开头登录和最后总结平台自带）：
>    - ① <一句话>
>    - ② <一句话>
>    - ……
>
> 上面对吗？
>
> - ① 对（推荐）
> - ② 有要改的
>
> 回我 ① 或 ②，或者直接说。

   教师答了（"有要改的"就请他说哪里、照改），再把还不知道的项逐个问，一次一个，上一个答了再问下一个（已知的整项删掉；课时、人数、设备、网络、登录方式不问）：课名："这节课叫什么名字？"；AI 助手：`skills/参考/选项话术.md`"AI 助手"（有写程序 / 分析数据的段才问，整节课问一次）；没有教案：照下面引用块（只放引用块的内容，不带引用格式）；分段不知道："中间分几段？每段一句话说学生在干什么"。有选项的项照选项话术的样子写；这三项没有选项，正文只发问句，让教师直接说。

> 有以前的教案就整段贴给我；没有就回答三句：
>
> - 学完能在平板上做出什么？
> - 学生之前会什么、容易卡在哪？
> - 用的哪本教材哪一课？

4. 完成标志：课名、分段都有了答案（有教案时从教案读出也算）。

### 第 2 步：建课程目录

0. 目录已存在（教师在工作台左栏"新建课程"新建的，开场话里给了 `lessons/<id>/`，里面已有 `lesson.config.js`）→ 跳过下面 1、2（不定 id、不跑 `new:lesson`；id 就是目录名，它已经是工作台的当前课程），只做 3 起的各条：建 `进度.md` 与 `教学设计.md`。
1. 定 id（你定，不问教师）：用课名的英文或拼音，小写字母开头，只含小写字母、数字、连字符，不超过 20 个字符。例：闰年判断 → `leap-year`。`lessons/<id>/` 已存在就在末尾加 `-2`。
2. 跑 `npm run new:lesson -- --id <id> --title "<课名>"`
   - 完成标志：打印 `已生成 lessons/<id>/` 与一行以 `下一步：` 开头的话（那行不用照做，按本文件往下走）。
   - 打印 `new:lesson 没有生成：……` → 按那句话换 id 或课名再跑。
   - 这条命令顺带把工作台的"当前课程"换成这门课，这是正常的。
3. 按 `skills/参考/进度文件模板.md` 建 `lessons/<id>/进度.md`："环节"里 00 写 `✓ <今天日期>`，01 写 `进行中`；"下一步："写 `01 第 3 步：写基本信息`。
4. 建 `lessons/<id>/教学设计.md`，从 `docs/01-阶段卡格式.md` 只抄骨架：
   - 第一到第五部分的 `##` 标题照抄；第三部分正文整段抄；第四部分只抄标题（卡在第 4 步逐段加）；第六、七部分不抄；
   - 第一部分、第五部分的表格：抄表头两行和每行第一列（"课题名称"……、"过程性评价"……），其余列留空；
   - 格式文件里的说明文字、括号里的提示语一律不抄。
5. 在最后加一节 `## 选择记录`，下面一行表头 `| 门 | 选项 | 教师选择 | 日期 |` 和一行 `|---|---|---|---|`。
6. 有教案时在最后加一节 `## 附：原教案`，按教案从哪来分两种：
   - 教师在对话里贴的教案 → 把原文放进去，只改一处：以 `#` 开头的行，行首加 `> `（例 `### 段 1 · 感知` 写成 `> ### 段 1 · 感知`），免得和第四部分的卡混在一起；
   - 第 1 步读的原稿文件 → 只写一行 `原稿：lessons/<id>/<读的那个文件名>`，不抄全文；后面要看教案就回去读那个文件。
7. 完成标志：`lessons/<id>/` 里有 `lesson.config.js`、`进度.md`、`教学设计.md` 三个文件。

### 第 3 步：写基本信息

1. 第 1 步的答案写进第一部分对应行的第二列：课时、人数、教材照教案或教师的话写，没有写"待定"；学生设备写"平板或电脑"；教室网络照教案写，没有写"待定"；登录方式写"花名册认领"；主题色写"沿用默认"（教师说了颜色就写颜色）。
2. "选择记录"写一行 `| 登录方式 | 从名单点名字 / 自己输入名字 | 由 AI 默认：从名单点名字 | <日期> |`（教案写明了别的就照教案）；问过 AI 助手的，AI 助手也写一行。
3. 第二部分：贴过教案 → 写一行"见文末'附：原教案'"；没有 → 写三行 `- 教学目标：<原话>`、`- 学情分析：<原话>`、`- 教材分析：<原话>`。
4. 完成标志：第一部分每行第二列都有内容。更新"下一步："为 `01 第 4 步 段 1`。

### 第 4 步：逐段写阶段卡，回读给教师

有教案：先把所有段按 a–d 写好，每张卡都先写进 `教学设计.md`（草稿卡，见 b），再按 e 发一条回读、逐问，按 f 收回答。没有教案：一段一段走 a–f，一段一条回读再逐问，同样先写草稿卡再问。草稿卡写在文件里，换了对话也不丢。

对每一段 N，按 a–f 做：

a. 读这段：教案里这段的内容，或教师那句话。写卡还缺的（例：验证标准、几类各是什么），记下来放进 e 的"补问"。
b. 按 `docs/01-阶段卡格式.md` 第四部分"阶段卡模板"写 A–D 四栏草稿，遵守"写卡规则" 1–4（C 栏写字段名与粒度，D 栏提醒条件写具体数字）。页面样式你填：原语段抄 `primitives/<原语>/primitive.config.js` 里 `layout:` 的值；自写段按"写卡规则" 7 的"选择指引"五选一（`focus` / `split` / `tiles` / `table` / `stack`）。写好（c、d 定完）就把整张卡写进 `教学设计.md` 第四部分，标题 `### 段 <N> · <阶段名>（草稿）`，卡末两行同 f。
c. 匹配原语（你定，不问教师）：按 B 栏动作查下表，再读 `primitives/<原语>/README.md`"什么时候不该用"一节，没命中就用它。

| 教师说法（B 栏） | 原语 |
|---|---|
| 投票、判断对错、从几个里选一个 / 几个 | `vote` |
| 做几道题、自动判分（单选 / 判断 / 填空） | `quiz` |
| 写一段话、写理由、反思、开放题 | `free-text` |
| 写程序、跑程序、过测试 | `code` |
| 看一份数据、算、画图 | `data-analysis` |

   查不到、命中"不该用"，或 B 栏学生不操作 → 用 `skills/参考/选项话术.md`"原语不够时"（学生不操作用第二种问法），放进 e 的逐问；机制按推荐项的做法定。
d. 机制你定、不问教师（`docs/01-阶段卡格式.md`"写卡规则" 5、6）。教案或教师已说过的照用，回读里带一句"照你教案是……"；没说过的取下面的默认：

   推进门槛（E 栏）只有两档：

| 这一段 | E 栏写法 | 原语段 `options.gate` |
|---|---|---|
| 下一段要用到这一段每个人的结果（例：选了阵营才能调参、交了作品才能互评） | 全部在线学生<完成动作>；没到时一键继续 | `{ <指标键>: 'all', soft: true }` |
| 其它 | 无门槛（教师看"已交 N / M"自己掌握） | `false` |

   <完成动作> 按 B 栏换：交了 / 投了 / 跑通了程序 / 测试全过 / 画出了图。<指标键> = 原语 README 缺省门槛里的那个键（vote / quiz / free-text 是 `submitted`）。原语的缺省门槛不是"无"，所以无门槛也要明写 `gate: false`。自写段在计划"门槛"一节照 E 栏写。"没到人数不许进"（`soft: false`）只在 05 环教师明确要时才写。

   其余机制的默认：

| 机制 | 默认（写进卡） |
|---|---|
| 有对错的投票，要不要等"揭晓"才能进 | 不拦，教师自己掌握 |
| 提交后能不能改（B 栏） | 能改，以最后一次为准 |
| 小测对错什么时候给学生看（`quiz`） | 教师在大屏点"揭晓"以后 |
| 提醒（D 栏） | 写程序、分析数据的段 8 分钟、其它段 3 分钟未<完成动作> |
| 限制说明（`code` / `data-analysis`） | 照"写卡规则" 6 的四条写进卡末"限制说明"，不问 |

   教师说的提醒是次数或结果（"连续 2 次没成功"）→ 照原话记；原语段只能按分钟，在"后续定制"记一行，这段先按分钟。
   这些都不念给教师：e 那条回读末尾一句话带过，05 环试课时列成"可调项"给教师改。
   要问的只剩内容类：

| 做法 | 要问的门 |
|---|---|
| `vote` / `quiz` / `free-text` | 卡还缺的内容（a 的补问） |
| `code` / `data-analysis` | 卡还缺的内容；整节课没问过 AI 助手时加"AI 助手"那道 |
| 原语不够（c 里要问） | "原语不够时"那道 |
| 专门做，学生有动作 | 卡还缺的内容 |
| 专门做，学生不操作 | 不问 |

   `vote` 有没有对错不问，按选项话术"投票有没有对错"在回读里带一句。教案里写的做法平台做不到（例"交齐了才能揭晓"）→ 用 SKILL"做不到的时候"那句话，放进 e 的逐问。
   课程组件：教师说的功能（对照 `docs/01-阶段卡格式.md` 第六部分"教师说法 → 组件对照表"）平台组件里没有、又不只属于某一段（例"作品墙""分层挑战"）→ 用选项话术"课程组件"那道门问，放进 e 的逐问（口述时放进说到它的那段）；只是某一段里的改动不问，按 c 定。
e. 先发回读，再逐问（回读每段不超过 3 行）。回读是正文，不是问题；回读发完，紧接着**调用提问工具**问第一问"上面对吗？"（不要把"对 / 有要改的"写进正文），教师答"对"再按 3 的顺序逐个问，每问都调用提问工具。每问之前先把这一问写进 `进度.md`"等老师回答："（只写当前这一问，`skills/参考/进度文件模板.md`）。问法照 `skills/参考/选项话术.md`"规则"：一次一个问题，有提问功能就用它（回读当正文发，"上面对吗？"用它问，选项 `对（推荐）` / `有要改的`，末尾"回我……"不发）。
   1. 有教案 → 所有段一条回读：第 1 步的回读放最前（第 1 步已发过就只写课名那一行），然后每段一项（一行说学生做什么，子项说怎么算完成、照你教案或做不到的事，最多两个子项）：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 照你的教案，这节课我是这样理解的：
>
> 《<课名>》，学生用平板或电脑，从名单点名字进来。
>
> 中间分 <N> 段（开头登录和最后总结平台自带）：
>
> - 第 1 段"<阶段名>"：学生在平板上<B 栏动作>
>    - <怎么算完成，一句>
>    - <照你教案是…… / 做不到的那句（有才写）>
> - 第 2 段……
>
> 下课时每人一份个人报告，课后能导出全班作答表。
>
> 写程序的段按平台的四条约定做；要用的环境，平台会自己准备好。
>
> 推进、提醒这些细节我都先按常规定了，做完试课时一起看，想改随时说。
>
> 上面对吗？
>
> - ① 对（推荐）
> - ② 有要改的
>
> 回我 ① 或 ②，或者直接说。

   - "下课时……"那一行：教案写明不要个人报告或不要导出 → 照教案改成"下课时没有个人报告"或"不能导出全班作答表"（第 5 步照它写）。
   - "写程序的段……"那一行只在有 `code` / `data-analysis` 段时写（四条就是卡末"限制说明"，不念）。
   - "推进、提醒……"那一行每次都写：门槛、提醒、能不能改这些"由 AI 默认"的机制不逐段念，只用这一句带过。

   2. 没有教案 → 一段一条回读：上一段按教师意见改过做法 → 放在最前、独占一行："第 <N-1> 段改成了：<一句话>"；然后：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 第 <N> 段我是这样理解的：
>
> - 大屏上投<A 栏大屏>，学生在自己平板上<B 栏动作>
> - 平台记下每个人的<C 栏字段的说法>，<怎么算完成>
> - <做不到的那句（有才写）>
>
> 上面对吗？
>
> - ① 对（推荐）
> - ② 有要改的
>
> 回我 ① 或 ②，或者直接说。

   最后一段那条回读，在"上面对吗？"之前加上有教案那条里"下课时……""写程序的段……""推进、提醒……"三行（同样的条件）。
   3. 教师答"对"（选"有要改的"→ 请他说哪里，照改，把改了的那段再回读一次问"对吗"）→ 逐个问下面这些，一次一个，上一个答了再问下一个，问题之间不夹别的内容：
      1. 补问：每段缺的内容，一问一个，写明第几段；想得出常见答案就给选项（推荐在前），想不出就正文只发问句，让教师直接说；
      2. 做法怎么选（c 里要问时）：一段一问，用选项话术"原语不够时"；
      3. AI 助手（整节课没问过、又有写程序 / 分析数据的段时）：整节课一问；
      4. 课程组件（d 里要问时）：一个功能一问。
