# 05 细节调整（上课前试一遍，顺手改细节）

## 进入条件

- 读 `lessons/<id>/进度.md`："环节"里有 `04 执行与审查：✓`。没有 → 回 `skills/04-执行与审查.md`。
- 旧课兼容：`lessons/<id>/` 里没有 `细节调整记录.md`、却有旧版 05 环留下的 `磨课记录.md` → 它就是本环的记录：跑 `git mv "lessons/<id>/磨课记录.md" "lessons/<id>/细节调整记录.md"`（git 不可用就只改名），里面的旧标题不用改；`进度.md`"环节"里 05 那一行的环名也改成"细节调整"。再按下一条走。
- 已有 `lessons/<id>/细节调整记录.md`：清单里还有"结果"不是 ✓ 的行 → 只重做这些行；清单已全是 ✓（上过课、复盘改过课回来）→ 第 2 步只把清单表作为新的一节 `## 试课清单 <YYYY-MM-DD>` 追加到文件末尾，整张重做。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 3、8 条。
- 这是整个做课过程里第一次请教师去工作台：前面各环都没请他看过（铁律 8）。

## 步骤

### 第 1 步：全程模拟

跑 `npm run simulate -- --lesson lessons/<id>/lesson.config.js --students 5`

- 完成标志：最后一行是 `=== RESULT: PASS (exit 0) ===`。
- 不是 PASS → 表格里"gate"列不是 `通过` 的段：在 `进度.md` 阶段表把它的"模拟 / 审查 / 存档"改回 `✗`，回 `skills/04-执行与审查.md` 做这一段，做完回到本步。

### 第 2 步：建细节调整记录

建 `lessons/<id>/细节调整记录.md`，照抄下面的内容（第 9 行：没有 `code` / `data-analysis` 段、也没有要跑 Python 的自写段就删掉；第 10 行：组件清单里没有 `report` 就删掉）：

```markdown
# 细节调整记录 · <课名>

日期：<YYYY-MM-DD>

## 试课清单

| # | 教师做什么 | 应该看到 | 结果 |
|---|---|---|---|
| 1 | 工作台"上课准备"页签的名单一节导入三个名字；点"打开教师端"投到大屏；两台平板一台扫码、一台输入地址，各从名单里点一个名字 | 教师端课前页出现这两个名字 | |
| 2 | 先按课前页的"进入课堂 →"，再用"进入下一段 →"把每段都走一遍，直到总结（这个按钮要点两次：第二次它变成"再点一次确认"） | 每进一段，平板上都换成这一段 | |
| 3 | 课进行中，一台平板刷新页面 | 回到当前段，做过的还在 | |
| 4 | 一台平板关掉无线网 30 秒再打开 | 自动回到当前段，做过的还在 | |
| 5 | 课进行到第 2 段时，再拿一台平板加入（迟到） | 直接进入当前段 | |
| 6 | 没到门槛时点两次"进入下一段 →"，再点"继续 →"；出现的是"强制继续"就点两次（第二次是"再点一次确认"） | 能推进到下一段 | |
| 7 | 学生在平板上点上一段回看 | 只能看，不能改 | |
| 8 | 一台平板、一台机房电脑各走一遍第 1 段 | 两台都显示完整，不用左右拖 | |
| 9 | 第一次进入写程序的那一段，数一数多久能点"运行" | 记下秒数 | |
| 10 | 到总结页点两次"生成并推送报告"（第二次是"确认生成"），平板上打开个人报告 | 每段都有一条 | |

## 发现的问题

- （无）
```

### 第 2.5 步：可调项清单

把这门课所有"由 AI 默认"的机制按教学语言列出来（从 `平台规格.md`"决策记录"与每段卡的 B、D、E 栏取），放进第 3 步那条消息、试课清单之后。教师想改就说，不想改不用答。

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 下面这些细节我先按常规定了，想改就说，不想改不用答：
>
> - 整节课：学生从名单里点名字进课堂；AI 助手<要 / 不要>
> - 第 <N> 段——进下一段：<全部交了才提示你 / 随时进>；提醒：<M> 分钟没交；<交了能改 / 交了不能改>
>    - 小测对错：你点"揭晓"后学生才看到

- 每段一项；"小测对错"那个子项只有 quiz 段写。
- "全部交了才提示你"= E 栏是"全部在线学生<完成动作>；没到时一键继续"（"交了"按 B 栏换成投了 / 跑通了 / 测试全过……）；"随时进"= 无门槛。"提醒"里的"没交"同样按 B 栏换。
- 一项超过 40 字 → 把"提醒"之后拆成它下面的子项。
- 教师说改 → 按 `skills/参考/改课.md`"小改"做（门槛、提醒、能不能改、小测什么时候看对错都是小改）；进课堂方式改成"自己输入名字"、AI 助手改要不要 → 改 `lesson.config.js` 对应那一处（`skills/03-脚手架与计划.md` 第 4 步），重跑 `check:lesson`。
- 教师要"没到人数不许进" → 那一段 `gate` 写 `soft: false`（E 栏写"没到时再确认一次才能强行进"），`平台规格.md`"决策记录"记一行。
- 改过的项在"决策记录"把 `由 AI 默认：……` 改成教师的选择；改完那一段重过 04 环三关，再请教师试那一项。

### 第 3 步：请教师试课

用 `skills/参考/选项话术.md`"去工作台看"固定句（第一行是进度，末行"每项回我……"），<看什么> 换成试课清单：清单表每行一个编号，编号那行写"教师做什么"，下面一个子项写"应该看到：……"（不念表头）。清单之后空一行，接第 2.5 步的可调项，最后是固定句的末行。

### 第 4 步：记录结果

- 教师说"好了" → 那一行"结果"写 `✓`。
- 教师说不对 → "结果"写 `✗ <教师原话>`，并在"## 发现的问题"加一行：`- 第 <N> 段：<教师原话>`（与某一段无关的写"全课"）。

### 第 5 步：修问题

对"发现的问题"里的每一条：

1. 是某一段的问题 → `进度.md` 阶段表把该段"内容 / 检查 / 模拟 / 审查 / 存档"五格一起改回 `✗`，"待办与后续定制"加一行 `- 试课：第 <N> 段 <原因>`；回 `skills/04-执行与审查.md` 做这一段，做完回到本环第 1 步，第 3 步只重试"结果"是 ✗ 的行。（教师此时提出改内容或换做法 → `skills/参考/改课.md`）
2. 是平台本身的问题（刷新、断网、迟到、回看、推进这些所有课共用的）→ 按 `skills/SKILL.md`"做不到的时候"处理，那一行"结果"改成 `✗（已记后续定制）`。

## 完成标志

- `lessons/<id>/细节调整记录.md` 存在；
- 清单"结果"列每行都是 ✓，或是 `✗（已记后续定制）` 且教师知道；
- 教师对可调项说要改的都改了（没说的不用等）。

## 写进度

- "环节"：`05 细节调整：✓ <日期>`；"当前环"：`06`
- 下一步：`06 上课前 24 小时清单`
- 最近一次停在：`05 完成，试课清单全勾`

## 发给教师

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 试课做完了，这节课可以上了。
>
> 上课前一天告诉我一声，我陪你把课前清单过一遍。

然后打开 `skills/06-上课与课后.md`。
