# 06 上课与课后

## 进入条件

- 读 `lessons/<id>/进度.md`："环节"里有 `05 细节调整：✓`（旧课这一行的环名可能是旧名，照样算，顺手改成"细节调整"）。没有 → 回 `skills/05-细节调整.md`。
- 教师说"明天上课 / 今天上课 / 刚上完课"。刚上完课 → 直接跳到"课后"。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 6、7 条。

## 上课前 24 小时

### 你做（三条命令）

1. 跑 `npm run check:lesson -- lessons/<id>/lesson.config.js`
   完成标志：最后一行是 `通过`，或以 `通过，` 开头且警告里没有 `TODO`。有错误或 TODO → 回 04 修那一段。
2. 跑 `npm run simulate -- --lesson lessons/<id>/lesson.config.js --students <班级人数>`（人数取 `教学设计.md` 第一部分，没写就用 30）
   完成标志：最后一行是 `=== RESULT: PASS (exit 0) ===`。不是 → 回 05 第 1 步。
3. 存档并打标记（git 不可用就跳过这一条）：
   - 跑 `git add lessons/<id>`，再跑 `git commit -m "<课名>：上课前"`（打印"nothing to commit / 没有要提交的"也算好）；
   - 跑 `git tag 上课-<id>-<YYYY-MM-DD>`（日期用上课那天）；
   - 完成标志：跑 `git tag -l "上课-*"`，打印里有刚才那个标记。

### 教师做（念给教师，逐项等"好了"）

在 `lessons/<id>/细节调整记录.md` 末尾加这一节（旧课还是旧文件名 → 先按 05"进入条件"第 2 条（旧课兼容）改名），教师每说一项"好了"就在那一项前写 `✓`：

```markdown
## 上课前检查 <YYYY-MM-DD>

- 工作台主区最上面的课名是《<课名>》（不是就在左栏"课程"下面点它）
- 上一节课的数据要清掉：工作台左栏"数据"里点"重置并回到第一环节"（会先自动备份；平台没运行时名单也会被清掉，所以放在导入名单之前）
- 工作台"上课准备"页签的名单一节导入本班名单
- Python 环境就绪："上课准备"页签的检查单里环境那一行是"已就绪"（没准备好就到 平台 → 环境与版本 点"重试"；这节课没有写程序的段就删掉这一项）
- 这节课用了 AI 助手或有段用 AI：平台 → 设置 的 AI 接口三项已填，点过"测一下"是通的；有条件再填一组备用接口
- 工作台左栏"数据"里点一次"备份这门课"
- 平板充好电，和教师电脑连同一个无线网
```

AI 那一项只在 `平台规格.md` 组件清单有 `coach`、或阶段表有段写了 `用 AI：是` 时留下，都没有就删掉（这句是给你的，不念给教师）。

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 上课前请按顺序做这几件事，做完一件告诉我一件：
>
> 1. 看工作台主区最上面的课名是不是《<课名>》，
>    - 不是就在左栏"课程"下面点它
> 2. 上一节课的数据还在的话，
>    - 到左栏"数据"里点"重置并回到第一环节"（它会先自动备份）
> 3. 到课名下面的"上课准备"页签，在名单一节导入本班名单
> 4. 这节课要写程序的话，
>    - 看"上课准备"页签课前检查里"Python 环境"那一行是不是"已准备好"，
>    - 不是就到左栏 平台 → 环境与版本 点"重试"
> 5. 这节课开了 AI 助手或有段用了 AI 的话，
>    - 看左栏 平台 → 设置 里 AI 接口三项是不是都填好了，
>    - 点一下"测一下"看是不是"通了"；
>    - 有条件的话再填一组备用接口（最好是另一家），
>    - 主接口出问题时会自动改用它
> 6. 到左栏"数据"里点一次"备份这门课"
> 7. 平板充好电，和你的电脑连同一个无线网。

## 上课

全程在工作台与教师端，你不参与。只在教师问时用下面这段话回答：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 上课这样走：
>
> 1. 工作台课名下面的"启动上课"页签点"启动平台"，看到绿点"运行中"
> 2. 点"打开教师端"，用教师密码登录，投到大屏
> 3. 学生点自己的名字进来，两种办法任选：
>    - 扫大屏上的二维码
>    - 在平板上输入工作台上的学生地址
> 4. 学生都进来后先按课前页的"进入课堂 →"
>    - 之后每段做完点两次"进入下一段 →"（第二次它变成"再点一次确认"）
> 5. 下课点"停止平台"。
>
> 上课时别关双击"班迹工作台"时弹出的那个小窗口。
>
> 用了 AI 助手、程序段写了要求清单的课，讲评前：
>
> - 可在统计页右侧点"AI 帮我看一遍"
> - 看全班每条要求有几人没做到（AI 的判断，只作讲评参考）

教师上课中遇到问题 → 请他看工作台页面上方的一句话说明和按钮，照按钮做；需要时点"查看运行记录"截图给你。

## 课后

1. 教师做（有个人报告时）：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 1. 下课前在教师端最后的总结页点两次"生成并推送报告"
>    - 第二次它变成"确认生成"
>    - 学生平板上就能看到自己的报告
> 2. 要全班作答表就点"导出 CSV"。
> 3. 下课后在工作台左栏"数据"里再点一次"备份这门课"。

2. 复盘三问，一次问一个，答案原样写进 `细节调整记录.md` 末尾新的一节 `## 上课复盘 <YYYY-MM-DD>`：

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 这节课哪一段学生卡住了？

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 哪一段太快或者太松了？

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 下次上这节课，你最想改什么？

3. "下次改什么"里每一条要动某一段（改、增、删段）→ `进度.md`"待办与后续定制"每条加一行 `- 复盘：段 <阶段名> <要改的>`（新增段写 `- 复盘：新增段 <一句话>`，删段写 `- 复盘：删掉段 <阶段名>`）；"下一步："写 `按 skills/参考/改课.md 改：段 <阶段名>`。

## 完成标志

`进度.md`"上课"一节有一行 `已上课 <YYYY-MM-DD>`，`细节调整记录.md` 有"上课复盘"一节。

## 写进度

- "上课"：加一行 `已上课 <YYYY-MM-DD>`
- "环节"：`06 上课与课后：✓ <日期>`
- 下一步：复盘有要改的 → `按 skills/参考/改课.md 改：段 <阶段名>`；没有 → `等下次上课：06 上课前 24 小时`
- 最近一次停在：`06 已上课 <日期>，已复盘`

## 发给教师

发给教师（只发下面引用块的内容，不带这一行、不带引用格式）：
> 这节课的复盘记下来了。
>
> 下次上课前告诉我，我们再把课前清单过一遍；想改哪一段也随时说。
