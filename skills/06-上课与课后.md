# 06 上课与课后

## 进入条件

- 读 `lessons/<id>/进度.md`："环节"里有 `05 磨课：✓`。没有 → 回 `skills/05-磨课.md`。
- 教师说"明天上课 / 今天上课 / 刚上完课"。刚上完课 → 直接跳到"课后"。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 6、7 条。

## 上课前 24 小时

### 你做（三条命令）

1. 跑 `npm run check:lesson -- lessons/<id>/lesson.config.js`
   完成标志：最后一行是 `通过`，或以 `通过，` 开头且警告里没有 `TODO`。有错误或 TODO → 回 04 修那一段。
2. 跑 `npm run simulate -- --lesson lessons/<id>/lesson.config.js --students <班级人数>`（人数取 `教学设计.md` 第一部分，没写就用 30）
   完成标志：最后一行是 `=== RESULT: PASS (exit 0) ===`。不是 → 回 05 第 1 步。
3. 存档并打标记（git 不可用就跳过这一条）：
   - 跑 `git add lessons/<id>`，再跑 `git commit -m "<课名>：上课前"`（打印"nothing to commit / 没有要提交的"也算好）；
   - 跑 `git tag 上课-<id>-<YYYY-MM-DD>`（日期用上课那天）；
   - 完成标志：跑 `git tag -l "上课-*"`，打印里有刚才那个标记。

### 教师做（念给教师，逐项等"好了"）

在 `lessons/<id>/磨课记录.md` 末尾加这一节，教师每说一项"好了"就在那一项前写 `✓`：

```markdown
## 上课前检查 <YYYY-MM-DD>

- 管理台首页"当前课程"是《<课名>》（不是就到"课程"页找到它，点"设为当前课程"）
- 上一节课的数据要清掉：管理台"数据"页点"重置并回到第一环节"（会先自动备份；平台没运行时名单也会被清掉，所以放在导入名单之前）
- 管理台"名单"页导入本班名单
- Python 运行时就绪：首页向导"开始下载"已打勾，或"设置"页最后一节显示"已就绪"（不是就点"检查并补全"；这节课没有写程序的段就删掉这一项）
- 管理台"数据"页点一次"备份当前数据"
- 平板充好电，和教师电脑连同一个无线网
```

> 对教师说：
> 上课前请按顺序做这几件事，做完一件告诉我一件：
>
> 1. 看管理台首页"当前课程"是不是《<课名>》，不是就到"课程"页找到它、点"设为当前课程"
> 2. 上一节课的数据还在的话，到"数据"页点"重置并回到第一环节"（它会先自动备份）
> 3. 到"名单"页导入本班名单
> 4. 这节课要写程序的话，看"设置"页最后一节 Python 是不是"已就绪"，不是就点"检查并补全"
> 5. 到"数据"页点一次"备份当前数据"
> 6. 平板充好电，和你的电脑连同一个无线网。

## 上课

全程在管理台与教师端，你不参与。只在教师问时用下面这段话回答：

> 对教师说：
> 上课这样走：
>
> 1. 管理台首页点"启动平台"，看到绿点"运行中"
> 2. 点"打开教师端"，用教师密码登录，投到大屏
> 3. 学生扫大屏上的二维码，或者在平板上输入管理台上的学生地址，点自己的名字进来
> 4. 学生都进来后先按课前页的"进入课堂 →"，之后每段做完点两次"进入下一段 →"（第二次它变成"再点一次确认"）
> 5. 下课点"停止平台"。
>
> 上课时别关双击管理台时弹出的那个小窗口。

教师上课中遇到问题 → 请他看管理台首页顶部的一句话说明和按钮，照按钮做；需要时点"查看运行记录"截图给你。

## 课后

1. 教师做（有个人报告时）：

> 对教师说：下课前在教师端最后的总结页点两次"生成并推送报告"（第二次它变成"确认生成"），学生平板上就能看到自己的报告；要全班作答表就点"导出 CSV"。下课后在管理台"数据"页再点一次"备份当前数据"。

2. 复盘三问，一次问一个，答案原样写进 `磨课记录.md` 末尾新的一节 `## 上课复盘 <YYYY-MM-DD>`：

> 对教师说：这节课哪一段学生卡住了？

> 对教师说：哪一段太快或者太松了？

> 对教师说：下次上这节课，你最想改什么？

3. "下次改什么"里每一条要动某一段（改、增、删段）→ 在 `进度.md`：
   - "环节"里 01 到 05 五行都改成 `进行中`（改完的课要重新磨课）；
   - "待办与后续定制"每条加一行 `- 复盘：段 <阶段名> <要改的>`（新增段写 `- 复盘：新增段 <一句话>`，删段写 `- 复盘：删掉段 <阶段名>`）；
   - "下一步："写 `01 第 4 步：按复盘改卡`。
   下次做课时依次走 `skills/01-教学设计.md`（只改这几张卡）→ `skills/02-平台规格.md`（只改这几行，把这几段的进度格子改回 `✗`）→ `skills/03-脚手架与计划.md`（第 0 步处理删段与换原语，只重抄这几段的阶段卡）→ `skills/04-执行与审查.md`。

## 完成标志

`进度.md`"上课"一节有一行 `已上课 <YYYY-MM-DD>`，`磨课记录.md` 有"上课复盘"一节。

## 写进度

- "上课"：加一行 `已上课 <YYYY-MM-DD>`
- "环节"：`06 上课与课后：✓ <日期>`
- 下一步：复盘有要改的 → `01 第 4 步：改第 <N> 段的卡`；没有 → `等下次上课：06 上课前 24 小时`
- 最近一次停在：`06 已上课 <日期>，已复盘`

## 对教师说

> 对教师说：这节课的复盘记下来了。下次上课前告诉我，我们再把课前清单过一遍；想改哪一段也随时说。
