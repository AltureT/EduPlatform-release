# 教学平台开发：从教学设计到能上课

## 这是什么

- 教师说一节课怎么上，你（AI）把它做成一个在教室局域网里跑的平台：教师电脑投影教师端，学生用平板浏览器加入。
- 教师的全流程：说教学设计 → 你开发 → 教师反复打开管理台点"重启并应用"看效果 → 上课也从管理台进。
- 教师不会代码、不开终端。命令和文件都由你做；教师只做三件事：口述、回答选项、在管理台里点按钮看效果。
- 框架地图：`docs/00-框架地图.md`（哪些能复用、哪些能自定义、哪些不能动，一页说清）。

## 八条铁律（每一环都遵守）

1. **配置优先、代码兜底**：每段先在五种原语（`vote` / `quiz` / `free-text` / `code` / `data-analysis`）里选；选不到才自写，自写必须在 `平台规格.md` 的决策记录里写一句"为什么原语不够"。自写段只用契约（`docs/02-阶段模块契约.md`）公开的入口。
2. **不改 `kernel/`、`components/`、`primitives/`、`scripts/`、`docs/`、`skills/`**：想改就说明需求超出平台，记进 `平台规格.md` 的"后续定制"，不硬改。
3. **每段做完必须过三关**：`check:lesson` 无错误 → `simulate` 退出码 0 且本段门槛通过 → 按 `skills/参考/审查清单.md` 审查（自写段必须新对话审查，原语段可自审）。任一关不过：不存档、不做下一段。
4. **答案与解析只写在 `stage.config.js` 的 `options` 里**：不写进视图、`STAGE.md`、README（题面可以出现在 `STAGE.md`）；保密由平台处理，你不自己想办法藏。
5. **每道门给选项**（`skills/参考/选项话术.md`）：最多 3 个、教学语言、推荐在前；一次交回只发一条消息，要问的门编号放在一起；教师定了写进记录，不再重问。
6. **不碰课堂数据**：`data/`、`backups/`、`.env` 不提交、不改（`.env` 只由 `new:lesson` 与管理台写）。每段过三关后 `git commit` 一次（对教师说"存了档"），上课前打 tag。git 不可用就跳过，不阻塞。
7. **每环结束写 `进度.md`**：新对话先读它再动手；不重问已记录的决定。
8. **能跑就请教师去管理台看**：骨架搭好、专门做的段做完、全部做完时（原语段做完攒着一起看），用 `skills/参考/选项话术.md`"去管理台看"那句固定句请教师重启并刷新页面看效果，不自己描述界面。

## 路径与命令的约定

- 所有命令都在**平台目录**里执行。判断方法：当前目录里同时有 `package.json` 和 `管理台.command` 两个文件 = 在平台目录。教师拿到的发布包解压出来的 `课堂互动平台/` 就是平台目录；在平台的开发仓库里，平台目录是 `template/`——当前目录是开发仓库根（里面有 `template/`）就先 `cd template`。
- 有的工具每条命令都在一个新窗口里执行（上一条的 `cd` 不保留）：那就每条都写成 `cd "<平台目录的完整位置>" && npm run …`（位置用 `node -e "console.log(process.cwd())"` 在平台目录里打印一次记下）。报"找不到 package.json / Could not read package.json"就是不在平台目录。
- 本 skill 里的路径都相对平台目录；`docs/`、`skills/` 都在平台目录里。
- `<id>` 是课程 id，`<段id>` 是阶段 id，`NN-<段id>` 是阶段目录名（例 `01-guess`，NN 是两位段号）。一门课的所有文件都在 `lessons/<id>/` 里。
- 命令原样复制，只替换尖括号（连尖括号一起换掉）；含空格或中文的值加英文双引号。
- 一步做没做完，只看这一步写的"完成标志"，不以"我觉得可以"为准。

## 流程链

| 环 | 名字 | 子文件 | 完成标志 |
|---|---|---|---|
| 0 | 环境与项目 | `skills/00-环境与项目.md` | 教师说"管理台打开了" |
| 1 | 教学设计 | `skills/01-教学设计.md` | `进度.md`"教学设计卡"每段一行"已确认"或"不用平台"，且有 `01 教学设计：✓` |
| 2 | 平台规格 | `skills/02-平台规格.md` | `平台规格.md` 阶段表行数 = 段数，教师说"对" |
| 3 | 脚手架与计划 | `skills/03-脚手架与计划.md` | `check:lesson` 末行以 `通过` 开头；阶段表每段"骨架" ✓ |
| 4 | 执行与审查 | `skills/04-执行与审查.md` | 阶段表每段"内容 / 检查 / 模拟 / 审查"都是 ✓ |
| 5 | 磨课 | `skills/05-磨课.md` | `磨课记录.md` 清单"结果"列全是 ✓ |
| 6 | 上课与课后 | `skills/06-上课与课后.md` | `进度.md` 有"已上课 <日期>" |

一环做完（完成标志出现）才进下一环。每个子文件开头有"进入条件"，结尾有"写进度"和"对教师说"。

参考件：`skills/参考/进度文件模板.md`（`进度.md` 格式）、`skills/参考/选项话术.md`（每道门怎么问）、`skills/参考/审查清单.md`（给审查者）、`skills/参考/子代理加速.md`（可选）。

## 怎么开始（每次新对话都从这里走）

0. 先看教师贴进来的东西：
   - 开头两行是 `平台目录：……` 和 `# 阶段审查清单` → 你是检查员：只按那份清单做审查，不读本文件别的部分、不做课。
   - 是一份教案（有课名、分段、教学过程）→ 记住它：01 环第 3 步不再问教案，已写明的也不再问。
   - 有一句"课程目录是 lessons/<id>/"（教师从管理台"课程"页复制的开场话）→ 这门课就是 `lessons/<id>/`，不用再按第 2 条找、也不问教师做哪门：确认平台目录（第 1 条）后，有 `lessons/<id>/进度.md` 就按第 3 条接着做；没有就按第 4 条定从哪一环开始，01 环照"目录已存在"做（跳过 `new:lesson`）。话里有"教学设计原稿在 lessons/<id>/教学设计原稿.<ext>"→ 那就是教案，01 环直接读它，不请教师贴（见 `skills/01-教学设计.md` 第 1 步）。贴了开场话 = 管理台能打开（开场话是从管理台复制的），第 4 条里按"教师说过管理台能打开"处理，跳过 00。
1. 确认当前目录是平台目录（见上面"路径与命令的约定"）。
2. 看 `lessons/` 目录：
   - 不存在，或里面没有任何子目录带 `进度.md` → 还没有课：按第 4 条。
   - 只有一个 `lessons/<id>/进度.md` → 就是这门课。
   - 有好几个 → 读每个 `进度.md` 的"课名："行，问教师：

> 对教师说：你这里已经有几门课：《<课名1>》《<课名2>》。今天接着做哪一门，还是新做一门？

3. 接着做一门已有的课：先请教师在管理台换到这门课（管理台可能开着别的课），再读它的 `进度.md`，照"下一步："那一行做（打开那一环的子文件，从写明的那一步开始）：

> 对教师说：请在管理台"课程"页找到《<课名>》，它没标"当前"就点"设为当前课程"。

4. 教师要新做一门课：
   - `node_modules/` 目录存在，**且**教师在这次对话里说过管理台能打开 → 跳过 00，从 `skills/01-教学设计.md` 第 1 步开始；
   - `node_modules/` 存在，但教师没说过 → 只做 `skills/00-环境与项目.md` 第 3、4 步，再进 01；
   - `node_modules/` 不存在 → 从 00 第 1 步开始。
   - 新建的课由 `new:lesson` 自动换成管理台的当前课程，不用教师去设置页选。
   - 教师也可以先在管理台"课程"页新建课程、上传教学设计，再把"复制开场话"那段话贴给你——那样按第 0 条走。

## 对教师说话

- 要对教师说的话用引用块 `> 对教师说：……` 标出。"对教师说："是给你看的标记，不发给教师；引用块里的换行和空行照原样发（一行一条、空行分段，不并成一段）；只替换尖括号。
- 只用教学词：段、题、选项、门槛、大屏、平板、管理台、重启并应用、存档。不说文件名、命令、端口、组件名、代码词；禁用词表在 `skills/参考/选项话术.md`。
- 一次交回只发一条消息：要教师回答的全部编号放进去，教师一次答完。给选项最多 3 个、推荐在前并写"（推荐）"。教师说"你定"或"都按推荐"就取推荐项，记"由 AI 默认"。
- 教师说过的、教案里写明的不再问，回读时带一句"照你教案是……"。
- 你整理了教师的话，就回读一遍问"对吗"，教师说"对"才算定。

## 做不到的时候

遇到下面任一种，不硬做：

- 要改 `kernel/`、`components/`、`primitives/`、`scripts/`、`docs/`、`skills/` 才能实现；
- 五种原语都不合适，自写也超出契约能做的；
- 同一个命令（或同一处错误）改了三次还失败。

做法（按顺序）：

1. 还没有 `平台规格.md`（01 环）→ 在 `进度.md`"待办与后续定制"加一行 `- 后续定制：段 <N> / <教师要的> / <为什么现在做不了>`（02 环搬成表格）。已有 `平台规格.md` → 直接在它的"后续定制"表加一行：段 / 教师要的 / 为什么现在做不了 / 日期。
2. 对教师说（放进你下一条要发的消息里，不单独发）：

> 对教师说：第 <N> 段里"<教师原话>"这一点，平台现在做不到，我记下来留给技术同事。这段先按"<简化做法>"做，其它段照常。

3. 继续做其它段，不停下来等。
