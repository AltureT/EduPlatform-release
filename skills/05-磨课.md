# 05 磨课（模拟一遍 + 教师亲手试）

## 进入条件

- 读 `lessons/<id>/进度.md`："环节"里有 `04 执行与审查：✓`。没有 → 回 `skills/04-执行与审查.md`。
- 已有 `lessons/<id>/磨课记录.md`：清单里还有"结果"不是 ✓ 的行 → 只重做这些行；清单已全是 ✓（上过课、复盘改过课回来）→ 第 2 步只把清单表作为新的一节 `## 磨课清单 <YYYY-MM-DD>` 追加到文件末尾，整张重做。
- 铁律全文见 `skills/SKILL.md`，本环最常碰到的是第 3、8 条。

## 步骤

### 第 1 步：全程模拟

跑 `npm run simulate -- --lesson lessons/<id>/lesson.config.js --students 5`

- 完成标志：最后一行是 `=== RESULT: PASS (exit 0) ===`。
- 不是 PASS → 表格里"gate"列不是 `通过` 的段：在 `进度.md` 阶段表把它的"模拟 / 审查 / 存档"改回 `✗`，回 `skills/04-执行与审查.md` 做这一段，做完回到本步。

### 第 2 步：建磨课记录

建 `lessons/<id>/磨课记录.md`，照抄下面的内容（第 9 行：没有 `code` / `data-analysis` 段、也没有要跑 Python 的自写段就删掉；第 10 行：组件清单里没有 `report` 就删掉）：

```markdown
# 磨课记录 · <课名>

日期：<YYYY-MM-DD>

## 磨课清单

| # | 教师做什么 | 应该看到 | 结果 |
|---|---|---|---|
| 1 | 管理台"名单"页导入三个名字；点"打开教师端"投到大屏；两台平板一台扫码、一台输入地址，各从名单里点一个名字 | 教师端课前页出现这两个名字 | |
| 2 | 先按课前页的"进入课堂 →"，再用"进入下一段 →"把每段都走一遍，直到总结（这个按钮要点两次：第二次它变成"再点一次确认"） | 每进一段，平板上都换成这一段 | |
| 3 | 课进行中，一台平板刷新页面 | 回到当前段，做过的还在 | |
| 4 | 一台平板关掉无线网 30 秒再打开 | 自动回到当前段，做过的还在 | |
| 5 | 课进行到第 2 段时，再拿一台平板加入（迟到） | 直接进入当前段 | |
| 6 | 没到门槛时点两次"进入下一段 →"，再点"继续 →"；出现的是"强制继续"就点两次（第二次是"再点一次确认"） | 能推进到下一段 | |
| 7 | 学生在平板上点上一段回看 | 只能看，不能改 | |
| 8 | 一台平板、一台机房电脑各走一遍第 1 段 | 两台都显示完整，不用左右拖 | |
| 9 | 第一次进入写程序的那一段，数一数多久能点"运行" | 记下秒数 | |
| 10 | 到总结页点两次"生成并推送报告"（第二次是"确认生成"），平板上打开个人报告 | 每段都有一条 | |

## 发现的问题

- （无）
```

### 第 3 步：请教师磨课

用 `skills/参考/选项话术.md`"去管理台看"固定句，<看什么> 换成："照下面这张清单一项一项试，每项告诉我'好了'或者'不对，看到了什么'"。`进度.md` 还有 `- 待教师看：` 行时，再加一句"第 <这些段号> 段你还没看过，走到时多看一眼，有要改的一起说"，然后删掉这些行。

然后把清单表的"教师做什么 / 应该看到"两列按行念给教师（每行一句，不念表头）。

### 第 4 步：记录结果

- 教师说"好了" → 那一行"结果"写 `✓`。
- 教师说不对 → "结果"写 `✗ <教师原话>`，并在"## 发现的问题"加一行：`- 第 <N> 段：<教师原话>`（与某一段无关的写"全课"）。

### 第 5 步：修问题

对"发现的问题"里的每一条：

1. 是某一段的问题 → `进度.md` 阶段表把该段"内容 / 检查 / 模拟 / 审查 / 存档"五格一起改回 `✗`，"待办与后续定制"加一行 `- 磨课：第 <N> 段 <原因>`；回 `skills/04-执行与审查.md` 做这一段，做完回到本环第 1 步，第 3 步只重试"结果"是 ✗ 的行。
2. 是平台本身的问题（刷新、断网、迟到、回看、推进这些所有课共用的）→ 按 `skills/SKILL.md`"做不到的时候"处理，那一行"结果"改成 `✗（已记后续定制）`。

## 完成标志

- `lessons/<id>/磨课记录.md` 存在；
- 清单"结果"列每行都是 ✓，或是 `✗（已记后续定制）` 且教师知道。

## 写进度

- "环节"：`05 磨课：✓ <日期>`；"当前环"：`06`
- 下一步：`06 上课前 24 小时清单`
- 最近一次停在：`05 完成，磨课清单全勾`

## 对教师说

> 对教师说：磨课做完了，这节课可以上了。上课前一天告诉我一声，我陪你把课前清单过一遍。

然后打开 `skills/06-上课与课后.md`。
